01学习方法：两层结构

上层负责全景和判断，下层负责在某一层深入。不确定先学什么时，从上层开始。

Layer 1 · 全景层

技术全景与架构选型

分层地图、语言与框架的性格、架构取舍、安全与失败模式、选型五问、产品架构拆解、AI 协作。目标：会问、会判、会验。

→
Layer 2 · 专项层

SQL · Python · Linux · Git · 算法

选定方向后，在对应的那一层深入：能动手写、能排障、能应对面试。全景层里的「不必深入」在这里变成「必须懂」。

02路线规划器

选一个方向和每周能投入的时间，自动排出一份按周的学习计划：全景模块和专项学习包按合理顺序交替，已完成的会自动划掉，绿色框是你这周该做的。

每周投入

时长是按「理解概念 + 做完演示和考核」估算的参考值；进度来自各学习包在本机浏览器里的勾选记录。

03分层地图

每一层都对应「全景模块」（先理解它是什么、怎么选）和「专项学习包」（再深入怎么用）。虚线标签表示暂未建设的专项包。

04全部学习包

进度来自各学习包在本机浏览器里保存的勾选记录（localStorage）。

提示：直接双击打开本地文件时，有的浏览器会把不同文件的本地存储隔离开，这里可能显示为 0；进入各学习包即可看到真实进度。通过同一个网站地址（例如 GitHub Pages）访问时会正常汇总。
