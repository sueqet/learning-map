# 学习地图 · Learning Map

> 我的个人学习资料库：**先建一张技术全景地图，再按方向深入某一层**。配套《职业规划网页》使用。
> 这里不是代码仓库，而是**可浏览、可勾选、可持续更新**的知识笔记站点。

## 从这里开始

用浏览器打开根目录的 **[`index.html`](index.html)**（总入口）：

- **今天**：继续上次学习、今天到期的闪卡、架构沙盘成绩。
- **路线规划器**：选方向（后端 / 数据 / AI / 运维 / 前端 / 面试冲刺 / 未定）和每周时长，自动排出按周的学习计划，已完成的自动划掉。
- **分层地图与全部学习包**：每一层对应哪些全景模块、哪些专项学习包，以及各自进度。

总入口和全景学习包都支持**深色模式**（右上角切换）。

## 学习方法：两层结构

AI 时代可以少背操作细节（函数怎么写、配置项叫什么、报错怎么改），但不能少了**系统常识和判断力**。所以仓库内容分成两层：

| 层 | 学习包 | 目标 |
| --- | --- | --- |
| **全景层**（先学） | [技术全景与架构选型](学习/技术全景与架构选型/README.md) | 听到任何技术名词，知道它在哪一层、解决什么问题、代价是什么、什么场景不该用；AI 给方案时，能**问出关键问题**并**用最小成本验证**（会问、会判、会验）。附三件工具：**技术图鉴**（111 个名词的分层地图）、**架构沙盘**（选型后「上线运行一年」并评级）、**闪卡复习**（间隔重复） |
| **专项层**（按方向深入） | SQL、Python、Linux、Git、数据结构与算法 | 在选定的那一层能动手、能排障、能应对面试 |

学习需求的来源与完整掌握清单见 [`学习需求与掌握清单.md`](学习/技术全景与架构选型/学习需求与掌握清单.md)。

## 使用方式

1. 打开根目录 `index.html`，在路线规划器里选方向，先学「技术全景与架构选型」的 01–03 模块，建立分层地图；陌生名词随时查技术图鉴。
2. 打开 `职业规划网页.html`，按「高性价比技能推荐」和目标方向，决定先深入哪一层。
3. 进入对应的 `学习/<技能名>/index.html`，按章节学习、做题、勾选进度。
4. 每个学习包都有独立的 `README.md`，说明定位、覆盖范围、维护方式和学习建议。
5. 新增学习包时，在 `学习/` 下新建同名子文件夹（结构可参考 `技术全景与架构选型/` 或 `SQL/`），并在根目录 `index.html` 的 `PACKS` / `LAYERS` 数组里登记，说明它属于地图的哪一层。
