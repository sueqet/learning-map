# 学习地图 · Learning Map

> 我的个人学习资料库——按技能的「学习地图」组织，配套《职业规划网页》使用。
> 这里不是代码仓库，而是**可浏览、可勾选、可持续更新**的知识笔记站点。

## 目录结构

```
.
├── 学习/                       # 学习资料总入口（README 见每个子目录）
│   ├── Git 版本协作/            # Git 版本控制与协作
│   ├── Linux/                  # Linux 使用（命令、脚本、系统、网络、证书等）
│   ├── Python/                 # Python 语言与工程、LeetCode 专项
│   └── 数据结构与算法/          # DSA：面试必考的底层通用能力
├── 职业规划网页.html            # 计算机专业就业方向手册（全方向/城市/薪资/技能）
└── README.md
```

## 这是什么

- **学习地图（Learning Map）**：每个技能一个子目录，内含可交互 `index.html` 主入口与 `content/` 下的分章节页面，支持勾选学习进度。
- **配套工具**：学习前可先看 `职业规划网页.html` 里的「高性价比技能推荐」，判断当前最该学哪几样，再进入对应技能目录。

## 使用方式

1. 用浏览器打开 `学习/<技能名>/index.html`，按页面章节逐点学习、勾选进度。
2. 每个技能目录都有独立的 `README.md`，说明该技能的定位、当前覆盖范围与使用建议。
3. 新增技能时，在 `学习/` 下新建同名子文件夹，结构参考 `Linux/` 的示例即可。

## 更新说明

- 本仓库随学习进度持续更新：**之后每次只推新增的学习地图**，避免大范围改动。
- 个人敏感档案（如《个人信息与技能档案》）不在此仓库内，请在本机保留。

## 说明

- 页面为纯 HTML/CSS/JS 静态资源，直接本地打开即可，无需任何服务。
- `人事`/就业数据依据公开信息整理，仅供学习参考，不构成求职建议。
