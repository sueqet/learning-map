# 学习区

> 这里集中存放学技能过程中的所有资料：笔记、交互式学习页面、练习、资源链接等。
> 总入口是仓库根目录的 `index.html`；不确定先学什么时，先学「技术全景与架构选型」。

## 两层结构

- **全景层**：`技术全景与架构选型/` —— 建立技术全景地图，学会「会问、会判、会验」。它是其它学习包的「总地图」。
- **专项层**：其余子文件夹 —— 选定方向后，在地图的某一层深入。

## 目录约定

- **每个技能一个子文件夹**，文件夹名即技能名（如 `Linux`、`Python`、`SQL`、`Git`、`Docker`…）。
- 每个子文件夹内建议放：`index.html` 学习大纲、`content/` 详解页、`README.md`（写明它在全景地图中的位置）。
- **新增技能**时，直接新建一个同名子文件夹即可，结构可参考 `技术全景与架构选型/`（共享样式与引擎、自带校验脚本）或 `SQL/`；同时在根目录 `index.html` 里登记。
