# 学习区

> 这里集中存放你在学技能过程中的所有资料：笔记、代码示例、学习计划、练习、资源链接等。

## 目录约定

- **每个技能一个子文件夹**，文件夹名即技能名（如 `Linux`、`Python`、`SQL`、`Git`、`Docker`…）。
- 每个子文件夹内建议放：学习计划、笔记、练习代码、阶段成果、参考资料。
- **新增技能**时，直接新建一个同名子文件夹即可，结构可参考 `Linux/` 里的示例。
