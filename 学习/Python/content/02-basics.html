变量与数据类型

变量是程序里给值起的名字，类型决定你能对它做什么。掌握它们，你就有了用 Python 描述数据、组织逻辑的地基。

  • 学完后，你能说出 int、float、bool、str、NoneType 五种基本类型的差异与常用场景。
  • 学完后，你能用 int()/float()/str()/bool() 做显式类型转换，用 type()/isinstance() 做类型检查。
  • 学完后，你能解释「赋值是引用绑定而非拷贝」、「== 与 is 的区别」、「可变 vs 不可变」三组核心概念。
  • 学完后，你能躲开浮点比较、列表引用共享、字符串拼接性能等常见坑，并写出更稳健的代码。

Learning Content · 学习内容

01从「给值起个名字」开始

几乎所有程序的第一步都是拿到一块数据并给它一个名字。Python 用变量完成这件事；而变量的类型与身份，决定了接下来能对它做怎样的操作。本节按「变量 → 类型 → 转换 → 可变性」四层逐步展开。

变量 · 入门变量：名字到对象的绑定动态类型 · 命名 · 多重赋值

在 Python 里，变量不是一个「存放数据的盒子」，而是一个「名字」，绑定（指向）某个对象。对象才有类型和值，名字只是引用它。因此同一个变量可以在不同时刻指向不同的对象——这就是动态类型。

flowchart LR N1["变量名 x"] -- 引用绑定 --> O1["对象：值 10
类型 int"] N2["变量名 x（改绑）"] -- 引用绑定 --> O2["对象：值 'hi'
类型 str"]
  • 命名规则：以字母或下划线 _ 开头，之后可跟字母、数字、下划线；不能以数字开头，不能含连字符 -。
  • 关键字（if、class、for、return 等）不能用作变量名；且大小写敏感：Name 与 name 是两个不同变量。
  • 多重赋值：a, b = 1, 2；交换用 a, b = b, a，无需临时变量。
  • 单个 _ 常作「占位/丢弃」的下划线，表示「这个值我不在乎」。
python
# 1) 变量 = 名字绑定到对象
age = 25                # int
name = "Ada"            # str
pi = 3.14               # float
ok = True               # bool
nothing = None          # NoneType
print(age, name, pi, ok, nothing)

# 2) 动态类型：同一变量可改绑到不同类型
x = 10
print(type(x))          # <class 'int'>
x = "hi"
print(type(x))          # <class 'str'>

# 3) 多重赋值 & 交换
a, b = 1, 2
a, b = b, a             # 交换 a 和 b
print(a, b)             # 2 1

# 4) 单下划线作占位：丢弃多余值
first, *_ = [1, 2, 3]
print(first)            # 1，_ 得到 [2, 3]
★

核心要点：变量是名字，对象才拥有类型与值；Python 动态类型 ＝ 名字可改绑到不同类型，类型在运行期才确定。学会用 type(x) 看清任意变量的实际类型。

类型 · 基础四大基本数据类型int · float · bool · str · None

Python 中最常用的「值」基础类型是整数、浮点数、布尔、字符串，再加上表示「无」的 None。理解它们在内存里的性质，是之后学习的一切根基——尤其是不可变这一点（详见下一节）。

类型字面量示例说明可变?
int42任意精度整数，没有固定上限不可变
float3.14双精度浮点，注意精度误差不可变
boolTrue / False真/假，是 int 的子类不可变
str"hello"有序、不可变文本不可变
NoneTypeNone表示「没有值 / 尚未赋值」不可变
python
# int：任意精度，无溢出
big = 2 ** 100
print(big)                 # 1267650600228229401496703205376

# float：双精度浮点
print(0.1 + 0.2)           # 0.30000000000000004  浮点误差！
print(isinstance(0.1, float))

# bool：真/假，是 int 的子类（可当作 0/1）
print(True + True)         # 2
print(issubclass(bool, int))   # True

# str：不可变文本
s = "hello"
print(s[0], len(s), s.upper())   # h 5 HELLO

# NoneType：表示「没有值」
def f(): pass
print(f())                 # None
!

浮点误差是陷阱：0.1 + 0.2 != 0.3（结果为 0.30000000000000004）。比较浮点应使用误差范围，如 abs(a - b) < 1e-9，或用 decimal.Decimal / math.isclose()。

转换 · 常用类型转换与类型检查int/float/str/bool · type/isinstance

很多坑源于「类型不对」。好在 Python 提供显式转换函数，以及 type()、isinstance() 来检查类型。转换是产生新对象，不会改掉原变量。

  • int(x)、float(x)、str(x)、bool(x) 做类型转换；int("ff", 16) 可按进制解析。
  • type(x) 返回具体类型对象；isinstance(x, T) 判断 x 是不是 T（含子类），推荐用于逻辑判断。
  • 真值判断：0、0.0、""、None、空容器为「假」，其余为「真」。
python
# 1) 类型转换（显式，产生新对象）
print(int("42"))       # 42
print(int(3.9))        # 3   截断（不是四舍五入）
print(float("3.14"))   # 3.14
print(str(100))        # '100'
print(bool(""))        # False
print(bool(0))         # False
print(bool([1, 2]))    # True

# 2) 进制转换
print(int("ff", 16))   # 255
print(bin(10), hex(255), oct(8))   # 0b1010 0xff 0o10

# 3) 类型检查
x = [1, 2, 3]
print(type(x))                       # <class 'list'>
print(isinstance(x, list))           # True
print(isinstance(5, (int, float)))   # True   元组命中任一个即真

# 4) 数值运算符
print(7 / 2)    # 3.5   除法 -> float
print(7 // 2)   # 3     整除（向下取整）
print(7 % 2)    # 1     取模
print(2 ** 3)   # 8     幂
!

注意：type(x) 与 isinstance(x, T) 并不总等价——isinstance 会考虑继承关系（例如 isinstance(True, int) 为 True），所以判断「是不是某个类型」用 isinstance 更稳。

概念 · 核心可变与不可变mutable · immutable · id · 引用

这是本节最「值钱」的概念：不可变对象一旦创建就无法修改（要改就新建对象）；可变对象可以原地修改内容。理解它，你才能正确地理解 == 与 is，以及「多个名字共享同一个对象」时的行为。

分类类型能否原地修改注意
不可变 immutableint · float · bool · str · tuple · frozenset不能「修改」其实是新建对象再重新绑定
可变 mutablelist · dict · set 及自定义对象能多个名字共享时，改一处会影响所有引用方
python
# 1) 不可变：str —— 看似修改，实为新建对象再重绑
s = "abc"
s2 = s
print(id(s), id(s2))     # 相同：指向同一对象
s = "abcd"               # 重绑定到新对象，原 "abc" 不变
print(id(s))             # 不同：新对象新地址

# 2) 可变：list —— 原地修改，共享者一起变
lst = [1, 2]
lst2 = lst               # lst2 与 lst 指向同一列表
lst.append(3)            # 原地修改
print(lst)               # [1, 2, 3]
print(lst2)              # [1, 2, 3]  引用共享，都被改了！

# 3) 想独立就拷贝
copy = lst.copy()        # 浅拷贝
copy.append(99)
print(lst)               # [1, 2, 3]
print(copy)              # [1, 2, 3, 99]

# 4) == 比较值，is 比较「是否同一个对象」
a = [1, 2, 3]
b = [1, 2, 3]
print(a == b)            # True  值相同
print(a is b)            # False 但不是一个对象
print(a is None)         # 判断 None 请用 is
!

引用共享是高频 Bug：lst2 = lst 只是让两个名字指向同一个清单，对它原地修改会「连坐」所有引用者。要独立副本用 lst.copy()；若内含嵌套对象（如 list of list），需 import copy; copy.deepcopy(lst)。

★

一句话口诀：== 比「值」，is 比「身份」，判断 None 永远用 is。不可变类型用 join 拼接、可变类型注意拷贝与深浅拷贝。
