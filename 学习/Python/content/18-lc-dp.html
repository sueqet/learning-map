算法 · 动态规划入门

掌握动态规划（DP）的三要素——状态、状态转移、边界，把「用递归硬算」升级为「把重复子问题记下来」；从一维 DP（爬楼梯、打家劫舍、零钱兑换、最长递增子序列）到二维 DP（不同路径），并用滚动数组把空间从 O(n²) 压到 O(n)——这是面试笔试最常考的算法范式。

1.1动态规划是什么状态 · 转移 · 边界

动态规划（Dynamic Programming, DP）是一种把一个大问题拆成若干重叠的子问题、把子问题的答案保存下来以便复用的解法。它和你写的递归很像，但多了一步「记忆化」——正因为把相同的子问题结果存了下来，才把暴力递归的指数级复杂度降成多项式级。

任何 DP 解都要回答三个问题（也就是三要素）：

  • 状态（State）：如何描述一个子问题？比如「dp[i] 表示爬到第 i 阶的方法数」。
  • 状态转移（Transition）：大问题的结果如何由更小的子问题推出来？如 dp[i] = dp[i-1] + dp[i-2]。
  • 边界（Base Case）：最小子问题的初值是什么？如 dp[1] = 1、dp[2] = 2。
flowchart TD A[原问题 f(n)] --> B{能不能拆成小的子问题} B -- 是 --> C[自顶向下 · 记忆化递归] C --> D[用字典/数组记住已算结果] B -- 是 --> E[自底向上 · 迭代填表] E --> D D --> G[避免重复计算：O(2^n) 降为 O(n)]
写法思路时间复杂度空间复杂度
朴素递归直接递归调用，不缓存O(2^n)O(n) 递归栈
记忆化搜索自顶向下，缓存子问题O(n)O(n)
迭代 DP自底向上，滚动保存O(n)O(1)
★

核心要点：动态规划 = 状态 + 状态转移 + 边界。能写对转移方程，这道题你就掌握了一半；另一半是「从前往后（自底向上）填表」的循环顺序与边界初值。

python · 三种写法
from functools import lru_cache

# ① 朴素递归：重复计算大量相同的子问题，O(2^n)
def fib_naive(n):
    if n < 2:
        return n
    return fib_naive(n - 1) + fib_naive(n - 2)

# ② 记忆化递归：自顶向下，结果被缓存，O(n)
@lru_cache(maxsize=None)
def fib_memo(n):
    if n < 2:
        return n
    return fib_memo(n - 1) + fib_memo(n - 2)

# ③ 迭代 DP：自底向上，只保留两个变量（滚动），O(n) 时间 / O(1) 空间
def fib_dp(n):
    if n < 2:
        return n
    a, b = 0, 1           # F(0), F(1)
    for _ in range(2, n + 1):
        a, b = b, a + b   # 状态转移
    return b
⚠

易错点：把递归翻译成递推时，最容易漏掉边界（base case）或把起始下标写偏，导致越界、死循环或答案整体偏移。写 DP 前先想清楚：dp[0] / dp[1] 到底是什么。

1.2【力扣 70】爬楼梯一维 DP · 斐波那契

题目：假设你在爬楼梯，每次可以爬 1 阶或 2 阶，问爬到第 n 阶有多少种不同的方式。

  • 状态：dp[i] ＝ 爬到第 i 阶的方法总数。
  • 转移：最后一阶的最后一步只能来自 i-1（上 1 阶）或 i-2（上 2 阶），所以 dp[i] = dp[i-1] + dp[i-2]。
  • 边界：dp[1] = 1，dp[2] = 2。
flowchart LR dp[i-1] -->|再上 1 阶| dp[i] dp[i-2] -->|再上 2 阶| dp[i]
python · 力扣 70
class Solution:
    def climbStairs(self, n: int) -> int:
        if n <= 2:
            return n
        a, b = 1, 2              # dp[1], dp[2]
        for _ in range(3, n + 1):
            a, b = b, a + b      # dp[i] = dp[i-1] + dp[i-2]（滚动用两个变量）
        return b
n12345
dp[n]12358
★

核心要点：它和斐波那契数列唯一区别只是初值（斐波那契 F(0)=0, F(1)=1；这里 dp[1]=1, dp[2]=2）。时间复杂度 O(n)，空间 O(1)（用两个变量滚动，不必开整个数组）。

♥

为什么要「滚动」：算 dp[i] 只需要 dp[i-1] 和 dp[i-2]，更早的值不再需要。因此用 a, b 两个变量来回覆盖即可把空间从 O(n) 降到 O(1)。

1.3【力扣 198】打家劫舍决策型状态 · 偷 / 不偷

题目：一排房子，每家金额 nums[i]，不能连续偷相邻两家，求能偷到的最大金额。

  • 状态：dp[i] ＝ 考虑前 i 家（下标从 0 开始）能偷到的最大金额。
  • 转移：对第 i 家，要么不偷 → 继承 dp[i-1]；要么偷 → 加上值，但必须跳过前一家，得 dp[i-2] + nums[i]。二者取较大：dp[i] = max(dp[i-1], dp[i-2] + nums[i])。
  • 边界：dp[0] = 0，初始两个哨兵 prev = cur = 0。
python · 力扣 198
from typing import List

class Solution:
    def rob(self, nums: List[int]) -> int:
        prev = cur = 0        # prev: 上一家隔一家(dp[i-2])，cur: 上一家(dp[i-1])
        for x in nums:
            prev, cur = cur, max(cur, prev + x)
            # 不偷(cur)  /  偷(prev + x)
        return cur
★

核心要点：这是最常见的「决策型状态」——每个位置都面临「选 / 不选」的分支，转移用 max 在两种选择中取值。时间复杂度 O(n)，空间 O(1)。

⚠

易错点：写 dp[i] = dp[i-1] + nums[i] 是错的——它默认每家都偷，会连着偷相邻两家。一定要保留「不偷、取上一家结果」这一分支，再和「偷」比较。

1.4【力扣 322】零钱兑换取最少 · 完全背包

题目：给定不同面额硬币 coins（数量不限）和金额 amount，求凑成该金额所需的最少硬币数；若无法凑出，返回 -1。

  • 状态：dp[x] ＝ 凑出金额 x 所需的最少硬币数。
  • 转移：对每种面额 c，若用了它，就由 x-c 递推：dp[x] = min(dp[x], dp[x-c] + 1)。
  • 边界：dp[0] = 0，其余先设为「无限大」INF（通常取 amount + 1）。
python · 力扣 322
from typing import List

class Solution:
    def coinChange(self, coins: List[int], amount: int) -> int:
        INF = amount + 1
        dp = [INF] * (amount + 1)
        dp[0] = 0
        for x in range(1, amount + 1):        # 自底向上遍历每种金额
            for c in coins:                   # 考虑每枚硬币
                if x - c >= 0:
                    dp[x] = min(dp[x], dp[x - c] + 1)
        return dp[amount] if dp[amount] < INF else -1
★

核心要点：dp[x] = min(dp[x], dp[x-c] + 1)——「先假设已有解，再尝试「用一枚 c」能不能更省」。时间复杂度 O(amount × len(coins))，空间 O(amount)。

♥

区分「完全背包」与「0/1 背包」：硬币数量不限是完全背包，内层对金额 x 从小到大遍历（让同一枚硬币能被多次用到）。若每种硬币只能用一次（如力扣 518 变式 / 0/1 背包），约定内层从大到小倒序遍历，避免重复使用。这是最常见的考点坑。

1.5【力扣 300】最长递增子序列「以 i 结尾」状态 · O(n²)

题目：给定整数数组 nums，求其中最长的「严格递增子序列」长度。（子序列可以跳着取，不必连续。）

  • 状态：dp[i] ＝ 以 nums[i] 结尾的最长递增子序列长度。注意是「以它结尾」而非「前 i 个的最长」，否则没法递推。
  • 转移：对每个 i，枚举 j < i，若 nums[j] < nums[i]，则可接在 j 后面：dp[i] = max(dp[i], dp[j] + 1)。
  • 边界：每个元素自身构成长度为 1 的子序列，故 dp[i] = 1。
python · 力扣 300（O(n²)）
from typing import List

class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        n = len(nums)
        dp = [1] * n
        for i in range(n):
            for j in range(i):
                if nums[j] < nums[i]:
                    dp[i] = max(dp[i], dp[j] + 1)
        return max(dp) if dp else 0
★

核心要点：「以 nums[i] 结尾」这个状态定义是本题能递推的关键——它保证我们只比较「结尾值」，从而能把 j 接在 i 前面。时间复杂度 O(n²)，空间 O(n)。

♥

进阶（O(n log n)）：维护一个递增的 tails 数组，用二分（bisect_left）把每个数插入到合适位置，长度即为答案，空间 O(n)。这道「贪心 + 二分」是面试常考的优化，放到「进阶挑战」里让你自己实现。

1.6【力扣 62】不同路径二维 DP · 滚动数组

题目：m × n 网格，机器人每次只能向右或向下走一步，从左上角走到右下角共有多少条不同路径？

  • 状态：dp[i][j] ＝ 到达格子 (i, j) 的路径数。
  • 转移：只能从上方 (i-1, j) 或左方 (i, j-1) 到达，所以 dp[i][j] = dp[i-1][j] + dp[i][j-1]。
  • 边界：第一行、第一列都只有一条路径，初值全为 1。
python · 力扣 62
from typing import List

# ① 二维 DP：O(m*n) 时间，O(m*n) 空间
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        dp = [[1] * n for _ in range(m)]
        for i in range(1, m):
            for j in range(1, n):
                dp[i][j] = dp[i - 1][j] + dp[i][j - 1]
        return dp[m - 1][n - 1]

# ② 滚动一维数组：O(m*n) 时间，O(n) 空间
class Solution2:
    def uniquePaths(self, m: int, n: int) -> int:
        row = [1] * n
        for _ in range(1, m):
            for j in range(1, n):
                row[j] += row[j - 1]   # 复用同一行，右边=上边+左边
        return row[-1]
★

核心要点：二维 DP 的空间优化套路是「只保留当前行 / 上一行」。因为 dp[i][j] 只依赖 dp[i-1][j] 与 dp[i][j-1]，可以把 2D 表压缩成一条 row，空间从 O(m×n) 降到 O(n)。

⚠

易错点：很多人会把二维 DP 想成「走格子时『路径数』是相乘」。这里因为不能走回头路、只能右或下，到某格的方式恰好是「上面 + 左面」相加；相乘是本格的单调性而非路径计数，注意区分。
