01字符串：索引、切片与不可变性

01索引与切片从序列里精确取出你想要的那一段

字符串本质是一个字符序列，所以它拥有和列表一致的「下标」规则：从 0 开始，负数表示从末尾倒数。切片 s[start:stop:step] 遵循左闭右开（取到 stop 之前一个就停），步长 step 可以为负从而实现反转。

python
s = "Python"

# ---- 索引：0 开始；负数从末尾倒数 ----
print(s[0])      # 'P'
print(s[5])      # 'n'
print(s[-1])     # 'n'   倒数第 1 个
print(s[-6])     # 'P'   倒数第 6 个（即第 0 个）

# ---- 切片：s[start:stop:step]，左闭右开 ----
print(s[0:3])    # 'Pyt'  取下标 0,1,2
print(s[1:4])    # 'yth'
print(s[2:])     # 'thon' 从 2 到末尾
print(s[:3])     # 'Pyt'  从开头到 2
print(s[::2])    # 'Pto'  步长 2
print(s[::-1])   # 'nohtyP'  步长 -1 = 反转

# ---- 越界切片不报错，只取到能取到的边界 ----
print(s[0:100])  # 'Python'
print(s[100:])   # ''
print(s[100:200])# ''
写法含义示例（s="Python"）结果
s[i]第 i 个字符s[1] → 'y'
s[-1]倒数第 1 个字符'n'
s[a:b]下标 a 到 b-1s[1:4] → 'yth'
s[a:]从 a 到末尾s[2:] → 'thon'
s[:b]开头到 b-1s[:3] → 'Pyt'
s[a:b:k]每 k 个取一个s[::2] → 'Pto'
s[::-1]反转'nohtyP'
★

核心要点：切片是左闭右开——s[a:b] 取得到 a、取不到 b。这让你顺手就能写出 s[:len(s)] 等于整个字符串，也意味着空切片 s[100:200] 不会报错而是返回 ''。

!

易错点：s[0] = 'X' 会抛 TypeError ——字符串不可变，任何看起来的「修改」其实都是返回一个新字符串。另外反向切片时默认方向会变：s[0:5:-1] 因为步长为负会立刻得到空串，要想反向取一段必须写 s[4:0:-1]。

02常用字符串方法去空白、拆分查找、替换与判定

字符串自带几十个方法，高频的几个你一定要记熟：去空白（strip）、拆分/连接（split / join）、查找（find / index）、判断（startswith / isdigit 等）、替换与大小写。它们是文本清洗的「瑞士军刀」。

python
s = "  Hello, Python World  "

# ---- 去空白 & 大小写 ----
print(s.strip())            # 'Hello, Python World'
print(s.lstrip())           # 只去左侧
print(s.rstrip())           # 只去右侧
print(s.lower())            # '  hello, python world  '
print(s.upper())            # 全大写
print(s.title())            # 每个单词首字母大写

# ---- 查找 / index（注意 find 与 index 的差别）----
print(s.find("Python"))     # 8   找不到返回 -1
print(s.index("Python"))    # 8   找不到抛 ValueError
print(s.count("o"))         # 统计出现次数
print(s.startswith("  He")) # True
print(s.endswith("ld  "))   # True

# ---- 判定 ----
print("12345".isdigit())    # True
print("abc".isalpha())      # True
print("abc123".isalnum())   # True
print("   ".isspace())      # True

# ---- 拆分 & 连接 ----
print(s.split())            # ['Hello,', 'Python', 'World'] 按空白拆
print("a,b,c".split(","))   # ['a', 'b', 'c']
print("-".join(["2024","01","12"]))   # '2024-01-12'  join 基于分隔符
print("a,b,c".replace(",", " / "))    # 'a / b / c'
方法作用示例
strip / lstrip / rstrip去两端 / 左 / 右空白" x ".strip() → "x"
lower / upper / swapcase大小写转换"Py".upper() → "PY"
find / index查找首次出现下标find 找不到 -1；index 找不到抛异常
count统计子串出现次数"aab".count("a") → 2
startswith / endswith判断前缀 / 后缀"hi".startswith("h") → True
split / rsplit拆分（rsplit 从右拆）"a,b,c".split(",")
join用分隔符拼接序列"-".join(["a","b"]) → "a-b"
replace替换（所有匹配）"a,b".replace(",",".")
isdigit / isalpha / isalnum字符类型判定"12".isdigit() → True
zfill左侧补零到指定位数"5".zfill(3) → "005"
★

核心要点：join 的调用者是分隔符、参数是可迭代序列："-".join(列表)。千万别写成 列表.join("-")——列表没有 join 方法，会报 AttributeError。

⚠

区分 find 与 index：两者都返回首次下标，但找不到时 find 温和地返回 -1（适合「判断是否存在」，配合 in 判断更直观），而 index 会直接抛 ValueError（适合「确定一定存在」的场景）。

03字符串格式化f-string / format / 旧式 %

把变量嵌进文本、控制小数位与对齐，是写日志、报表、提示语最常用的一步。三种写法里，f-string 最简洁、性能最好（Python 3.6+ 推荐），format 更灵活，% 是历史遗留。

python
name, age, score = "Alice", 20, 98.5

# ---- 1) f-string（最推荐）----
print(f"姓名：{name}，年龄：{age}，分数：{score:.1f}")
print(f"{3.14159:.3f}")        # '3.142'
print(f"{42:05d}")             # '00042' 补零 5 位
print(f"{name:>10}")           # 右对齐占 10 位
print(f"{name:<10}！")         # 左对齐
print(f"{1234567:,}")          # '1,234,567' 千分位

# ---- 2) str.format ----
print("{} / {}".format(name, age))           # 按顺序
print("{0} 和 {1}".format(name, age))       # 按下标
print("{:.2f}".format(score))                # 两位小数

# ---- 3) 旧式 % 格式化器（了解即可）----
print("%s 今年 %d 岁，分数 %.1f" % (name, age, score))
格式含义示例
{x}直接占位f"{age}" → "20"
{x:.2f}保留两位小数f"{3.14159:.2f}" → "3.14"
{x:05d}5 位补零整数f"{42:05d}" → "00042"
{x:>8}右对齐，宽 8f"{'a':>5}" → " a"
{x:<8}左对齐，宽 8f"{'a':<5}" → "a "
{x:^8}居中对齐，宽 8f"{'a':^5}" → " a "
{x:,}千分位f"{1234567:,}" → "1,234,567"
★

核心要点：优先用 f"..."。格式说明符语法是 {值:填充对齐宽度.精度类型}：f"{3.14159:.2f}" 的 f 表示浮点，f"{42:05d}" 的 d 表示十进制整数。字符串补零用 zfill，别拿 d 去格式化字符串。

⚠

小坑：f-string 里 : 后面出现 ..2f 是一位小数，看清是几点。另外在 f-string 内嵌表达式时别写 \ 反斜杠，它不能直接出现在 f-string 表达式中——需要转义先在外面算好。

04不可变性、in 判断与编码str 与 bytes，以及文本背后的坑

字符串不可变（immutable）是它的核心设计：一旦创建就不再改变，这使得它能作为字典 key、能被安全共享和缓存哈希。遇到「修改」需求我们要么拿到新字符串，要么把多个局部拼接成列表再用 join。同时要分清文本（str）和字节（bytes）两种类型。

python
# ---- 不可变：一切"修改"都返回新字符串 ----
s = "py"
# s[0] = "P"              # TypeError: 'str' object does not support item assignment
s2 = s.capitalize()       # 返回新字符串
print(s, s2)              # 'py'  'Py'

# ---- in / not in 判断子串 ----
print("lo" in "Hello")        # True
print("xyz" not in "Hello")   # True

# ---- 编码与解码：str <-> bytes ----
text = "你好，Python"
b = text.encode("utf-8")      # str -> bytes（字节序列）
print(type(b))                # <class 'bytes'>
print(b)                      # b'\xe4\xbd\xa0\xe5\xa5\xbd...'
print(b.decode("utf-8"))      # bytes -> str，还原为 "你好，Python"

# ---- 转义字符 & 原始字符串 ----
print("It\'s me")          # 单引号转义
print("A\tB\nC")           # 制表符 tab + 换行
print(r"C:\new\temp")      # 原始字符串（r"..."）：不转义 \n
★

核心要点：str 是文本，bytes 是字节；两者不能混用（比如 str + bytes 会报 TypeError）。写文件、走网络时用 encode 转字节，读回来用 decode；转码遇到非法 UTF-8 序列会抛 UnicodeDecodeError。

!

易错点：因为字符串不可变，s += char 在循环里每轮都新建一个长度递增的新字符串，总代价是 O(n²)。大量拼接的正确姿势是「parts.append(...) 收集到列表，最后 "".join(parts)」。

05文本处理实战套路清洗 → 拆分 → 转换 → 重组

把上面几样结合成一个可复用的四步流水线，就能优雅地处理日志、清洗数据、解析配置。下面几个都是日常高频的迷你场景。

flowchart LR A["原始字符串"] --> B["strip / rstrip 去空白"] B --> C["split 按分隔符拆分"] C --> D{"需要格式化或转换?"} D -->|是| E["lower/upper 或 f-string"] D -->|否| F["join 重组输出"] E --> F F --> G["得到干净、规整的文本"]
python
# 场景 1：读文件时去掉行尾换行
line = "hello\n"
line = line.rstrip("\n")      # 或用 line.strip()
print(line)                   # 'hello'

# 场景 2：判断回文（用切片反转 + in 判断）
word = "上海自来水来自海上"
print(word == word[::-1])     # True

# 场景 3：从邮箱中拆出用户名与域名
email = "alice@example.com"
user, domain = email.split("@")
print(user, "|", domain)      # alice | example.com

# 场景 4：把日期数字格式化成可读形式
print(f"{'20240112'[:4]}-{'20240112'[4:6]}-{'20240112'[6:]}")  # 2024-01-12

# 场景 5：拼接大量字符串的正确姿势
parts = ["Python", "is", "great"]
print(" ".join(parts))        # 'Python is great'
★

核心要点：日常文本处理几乎都是「去空白 → 拆分 → 判断/转换（lower、isdigit、f-string）→ 重组（join）」。先想清楚你想要的结构，再选对应方法，比盲目堆砌方法高效得多。
