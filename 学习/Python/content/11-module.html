模块、包与标准库

程序一变复杂，就要把代码拆成可复用的模块（.py 文件）与包（目录）。本节讲清 import 机制、包的组织，并带你熟练调用标准库——用几行代码搞定日期、随机数、统计与路径处理。

✓本节学习目标

  • 学完后，你能用 import / from / as 导入代码，并根据 sys.path 排查 ImportError。
  • 学完后，你能解释模块为何只执行一次（sys.modules 缓存），并避免在模块顶层做副作用。
  • 学完后，你能创建自己的包，用 __init__.py 统一导出，并用相对导入组织包内模块。
  • 学完后，你能用 if __name__ == "__main__" 让脚本既可被运行、又可被导入。
  • 学完后，你能熟练调用常用标准库（datetime/random/collections/pathlib/os/sys 等）完成常见任务。

01模块化结构
从单个 .py 文件到成体系的包

小节为什么需要模块与包module · package · 命名空间

在 Python 里，一个 .py 文件就是一个模块（module），一个含 __init__.py 的目录就是一个包（package）。把同一类功能抽成一个模块，就能在多个文件里复用，同时让各自的命名空间彼此隔离——这是从「写脚本」迈向「写项目」的第一步。

  • 复用：同一段逻辑（判分、格式化、发请求）只写一次，随处 import。
  • 隔离：每个模块拥有自己的命名空间，函数与变量不会互相污染、撞名。
  • 可测 & 协作：模块职责单一，便于单独测试与多人分工。
  • 组织：把相关模块收进一个包，形成清晰的目录树。
python
# 文件：mymath.py —— 这就是一个模块
def add(a, b):
    return a + b

def mul(a, b):
    return a * b

# 文件：main.py —— 在另一个文件里复用这个模块
import mymath
print(mymath.add(2, 3))   # 5
print(mymath.mul(3, 4))   # 12
flowchart LR A[一个 Python 项目] --> B[包 package
目录 + __init__.py] A --> C[单个模块 .py 文件
可直接运行] B --> D[若干模块 .py] D --> E[函数 / 类 / 变量] C --> E
★

核心要点：记住这句：模块 = .py 文件，包 = 目录。命名空间隔离是模块化最大的价值——各写各的，互不干扰。

小节import 的三种写法与 sys.pathimport · from · as · sys.path

导入模块主要有三种写法，差别在于「把多少名字带进当前作用域」。惯例是显式列出需要的名字，避免命名空间失控。

python
import mymath                 # 整模块导入，须用 模块名.名字 访问
print(mymath.add(2, 3))

from mymath import add, mul   # 只导入需要的名字，直接用
print(add(2, 3))

import mymath as m            # 起别名，常用于名字冲突或长包名
print(m.mul(3, 4))

import os, sys, datetime      # 一行导入多个模块
写法访问方式适用场景
import modulemodule.name意图清晰、不污染当前作用域，最推荐
from module import namename常用名字，省去模块前缀
import module as aliasalias.name简短、避免与同名变量/模块混淆
from module import *全部名字不推荐：把大量名字塞进当前作用域，易冲突

Python 按 sys.path 中的目录顺序查找模块，命中第一个即停。默认列表通常以 ''（代表当前目录）开头。

python
import sys
print(sys.path)      # 解释器按这些目录顺序找模块
# 常见内容: ['', '/usr/local/lib/python3.12', ...]   '' 表示当前目录

# 临时往搜索路径里加一个目录
if "/some/custom/lib" not in sys.path:
    sys.path.append("/some/custom/lib")
!

易错点：别用 from module import *——它会把你并不知道的一堆标识符导入当前作用域，出错极难排查。显式列名字或用模块前缀（module.name）最稳。

!

提醒：查找是「按顺序、命中即停」。把同名模块放在不同目录、或库安装路径不对，都会抛 ImportError；排查时先打印 sys.path 与当前工作目录（os.getcwd()）。

小节模块只执行一次：sys.modules 缓存sys.modules · 缓存 · 顶层副作用

import 一个模块时，Python 会先查缓存：若该模块已在 sys.modules，就直接返回已创建的对象，不再执行顶层代码。因此模块顶层代码只在首次导入时运行一次，重复 import 是「免费」的。

python
import sys
print("这是 mymath 的顶层，只会打印一次")

import mymath     # 第一次：执行顶层代码
import mymath     # 第二次：直接取缓存，不再执行
print(mymath in sys.modules)   # True —— 已被缓存
flowchart TD A["import mymath"] --> B{"已在 sys.modules 缓存?"} B -- 是 --> C[直接返回已创建的模块对象
不再执行顶层代码] B -- 否 --> D[按 sys.path 定位 .py 文件] D --> E[执行模块顶层代码（定义函数/类）] E --> F["把模块对象写入 sys.modules"] F --> C
★

核心要点：顶层代码只执行一次。所以
不要把副作用（大量打印、读文件、发请求）放在模块顶层——import 时会触发一次；这类副作用应放进函数或 __main__ 里。

小节包与 __init__.py、相对导入__init__.py · 相对导入 · 绝对导入

包是「装模块的目录」。只要目录里有 __init__.py（可为空），它就是一个包。这个文件可用来做统一导出（门面）——使用者只 import 一次包，就能拿到常用 API，而不必关心包内结构。

tree
myproj/
  __init__.py
  utils/
    __init__.py
    strings.py
  main.py
python
# utils/strings.py
def upper(s):
    return s.upper()

# utils/__init__.py —— 相对导入：把子模块的名字暴露出来
from .strings import upper

# myproj/main.py —— 绝对导入，从项目根出发
from myproj.utils import upper

def show():
    print(upper("hello"))

if __name__ == "__main__":
    show()

运行方式：在 myproj 的父目录执行 python -m myproj.main，这样 import myproj... 才能被找到。

!

易错点：相对导入以 .（当前包）或 ..（上一级包）开头，只在包内部有效；也不能直接运行子模块文件（如 python utils/strings.py），因为此时它已脱离包语境。要用 -m 从包外运行。

★

核心要点：用 from .xxx import name 在包内做相对导入，配合 __init__.py 把这些名字「上提一层」，外部就能一行 import 拿到，封装得很干净。

小节__name__ == "__main__"：运行 vs 导入__name__ · __main__ · 入口

直接运行时，模块的 __name__ 是 "__main__"；被 import 时则是「模块名」（如 "tools"）。利用这一区别，把演示、自测、入口代码包进 if __name__ == "__main__":，模块就既能被导入复用、又能直接运行。

python
# tools.py
def calc(a, b):
    return a * b

def main():                       # 入口函数
    print(calc(3, 4))

if __name__ == "__main__":        # 直接运行时才执行
    main()

# 别处 import tools：calc 可用，但 main() 不会自动跑
flowchart LR A[python tools.py
__name__=='__main__'] --> B[执行入口 main] C[import tools
__name__=='tools'] --> D[只定义函数/类
不执行入口]
★

核心要点：这是「可运行又可复用」脚本的关键一行。把自测/演示代码放进 if __name__ == "__main__":，既不影响被 import，也能单独跑起来验证。

import datetime
now = datetime.datetime.now()
print(now.strftime("%Y-%m-%d %H:%M:%S"))
print((now + datetime.timedelta(days=3)).strftime("%Y-%m-%d"))

import random
print(random.randint(1, 100))                 # 1~100 的整数
print(random.choice(["红", "绿", "蓝"]))       # 等概率选一个
print(random.sample(range(100), 5))           # 不重复抽 5 个
deck = ["A", "K", "Q", "J"]; random.shuffle(deck)

from collections import Counter, defaultdict, deque, namedtuple
print(Counter("hello world").most_common(3))   # 统计 + 取前 3
d = defaultdict(list); d["k"].append(1)        # 免去先初始化
dq = deque([1, 2, 3]); dq.appendleft(0)
Point = namedtuple("Point", ["x", "y"]); print(Point(1, 2).x)

from pathlib import Path
print(Path.cwd().name)                         # 当前目录名

import os, sys
print(os.getenv("PATH")[:40])                  # 读环境变量
print(sys.argv)                                # 命令行参数列表
★

核心要点：记不住所有 API 没关系，记住「每个模块一句话用途」并会查官方文档即可。用时 dir(模块) 看有哪些名字，help(模块.函数) 看用法。

!

易错点：sys.argv 的第一个元素是脚本文件名（不是第一个参数），真正取参数要从 sys.argv[1] 开始；没传参数时列表很短，用前记得判空，否则会 IndexError。
