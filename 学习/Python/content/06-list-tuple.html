PYTHON · 基础

列表与元组

一个是可以随意增删改的容器，一个是定好了就不许动的容器。学会列表的增删改查、切片、排序与推导式，再搞懂元组的不可变性与解包，你就拿下了 Python 最常用的两组序列——也终于能看懂「深浅拷贝」和「为什么列表不能当字典键」这类进阶问题。

✓本节学习目标

  • 学完后，你能用方括号 / list() 创建列表，熟练使用正向与负向索引以及 len / in / count / index 做读取与判断。
  • 学完后，你能用 append / insert / extend 增、用下标和 pop / remove / del 删改，并说清 append 与 extend、pop 与 remove 的区别。
  • 学完后，你能用切片截取、设置步长、反转列表，并准确区分 sort() 与 sorted()、reverse() 与 [::-1] 的「就地 / 返回新对象」行为。
  • 学完后，你能写出列表推导式（含条件筛选），并访问、遍历嵌套列表（矩阵）的行与列。
  • 学完后，你能解释元组为什么不可变，会用解包与 *rest，并避开「单元素元组要加逗号」这一易错点。
  • 学完后，你能区分可变与不可变、浅拷贝与深拷贝，并指出「b = a 是引用别名」导致的共享修改陷阱。
Prerequisites · 前置知识

已学过 Python 基础（变量与数据类型、int / float / str、for 循环、range），知道什么是「序列」；并理解上一节「字符串处理」里的索引与切片概念——列表只是在它基础上多了一个「可增删改」的特性。

Learning Content · 学习内容

01列表：创建、索引与读取
（可变的序列容器）

基础列表的创建、索引与读取可增删改的有序序列

列表（list）是 Python 里最灵活、最常用的序列容器：它由方括号 [...] 围起来、元素用逗号分隔，并且有序、可变、可重复。它不像 C 语言数组那样只能装同类型元素——列表里可以混装任意类型的对象（包括另一个列表）。

python
# 创建列表
nums  = [1, 2, 3, 4, 5]                      # 字面量
mix   = ["apple", 3.14, True, None]           # 可以混装不同类型
empty = []                                    # 空列表
rng   = list(range(3))                        # list() 转换 -> [0, 1, 2]
tup2  = list((10, 20))                        # 由元组转为列表 -> [10, 20]
msg   = list("hello")                         # ['h','e','l','l','o']

# 索引：从 0 开始；负数从尾部数
print(nums[0])    # 1
print(nums[-1])   # 5
print(nums[3])    # 4

# 常用读取与判断
print(len(nums))       # 5
print(3 in nums)       # True
print(nums.count(3))   # 1
print(nums.index(4))   # 3
★

核心要点：列表是有序容器——每个元素都有编号（下标），既能用下标定位，也允许重复的元素存在。它还可变，这是它与元组、字符串最本质的区别。

核心列表的增、删、改、查append / extend / pop / remove / del

「可变」的威力集中体现在这组操作上：你可以随时往列表里追加元素、插到任意位置、按值或按下标删除，并直接修改某个位置的元素。所有操作都是就地改动同一个列表对象，不会返回新的列表。

python
nums = [1, 2, 3]

# 增
nums.append(4)                # 末尾加一个元素 -> [1,2,3,4]
nums.insert(0, 0)             # 在下标 0 插入 -> [0,1,2,3,4]
nums.extend([5, 6])           # 追加整个序列 -> [0,1,2,3,4,5,6]
nums += [7]                   # 等价于 extend

# 改
nums[0] = 10                  # 按下标覆盖 -> [10,1,2,3,4,5,6,7]

# 删
x = nums.pop()                # 弹出并返回最后一个
x = nums.pop(0)               # 弹出并返回下标 0
nums.remove(6)                # 删除第一个值为 6 的元素
del nums[1:3]                 # 按切片删除一段
nums.clear()                  # 清空

# 查
print(len(nums), 5 in nums)   # 0 False
操作方法 / 语法行为注意
追加单个append(x)把 x 当作一个整体放末尾append([3,4]) 得到 [1,2,[3,4]]
追加序列extend(iter)把序列里每个元素逐个展开追加extend([3,4]) 得到 [1,2,3,4]
删除并返回pop(i)按下标删，缺省删最后一个，返回该元素下标越界抛 IndexError
按值删除remove(x)删掉第一个等于 x 的元素，无返回值不存在抛 ValueError
删除一段del list[a:b]删除切片范围，无返回值常用，也支持 del list[i]
✕

高频错误：nums.remore(6) 打错法、或用 pop() 却想「删首个等于某值的元素」。牢记：按值删用 remove，按位置删用 pop / del；且列表没有基于「值是否存在」的安全删除，值不存在时 remove 会直接抛异常。

进阶切片、排序与反转sort vs sorted · reverse vs 切片

切片是上一节字符串里学过的技能，在列表上同样适用，而且你可以在新的列表上做更多整理：抽子段、反转、排序。这里最容易混淆的是「哪些操作就地改、哪些返回新对象」。

python
nums = [5, 1, 4, 2, 3]

# 切片：list[start:stop:step]
print(nums[1:4])      # 下标 1..3 -> [1, 4, 2]
print(nums[::2])      # 隔一个取 -> [5, 4, 3]
print(nums[::-1])     # 反转（返回新列表）-> [3, 2, 4, 1, 5]

# 排序
nums.sort()                      # 就地升序，返回 None
print(nums)                      # [1, 2, 3, 4, 5]
nums.sort(reverse=True)          # 就地降序
b = sorted(nums)                 # 返回新列表，不改变 nums
b = sorted(nums, reverse=True)   # 同样的排序但不动原列表

# 反转
nums.reverse()                   # 就地反转，返回 None
c = nums[::-1]                   # 返回反转后的新列表

# 拷贝（都是浅拷贝）
a = nums.copy()                  # 或 nums[:] / list(nums)
print(a is nums)                 # False，是两份不同对象
操作写法是否就地返回什么
排升序list.sort()就地None
排升序(新)sorted(list)不动原列表新的已排序列表
反转list.reverse()就地None
反转(新)list[::-1]不动原列表新的反转列表
拷贝list.copy() / list[:]不动原列表新的浅拷贝列表
!

易错点：list.sort() 和 list.reverse() 都就地修改并返回 None，所以「x = nums.sort()」会得到 None 而非排好序的列表——这是新手最常犯的错。想要「不破坏原列表」的结果，请用 sorted(nums) 与 nums[::-1]。

进阶列表推导式与嵌套列表一行写出一个新列表

从「用 for 循环一个个 append」到「列表推导式」，是 Python 风格的重要一步。推导式把「生成 + 过滤 + 收集」压缩成一行，读起来像描述，也更快。配合嵌套列表（矩阵），几乎能完成各种数据整理。

python
squares = [x*x for x in range(6)]                  # [0,1,4,9,16,25]
evens   = [x for x in range(10) if x % 2 == 0]     # 条件过滤 -> [0,2,4,6,8]
pairs   = [(a, b) for a in [1, 2] for b in ["x", "y"]]
# -> [(1,'x'),(1,'y'),(2,'x'),(2,'y')]

# 嵌套列表（矩阵）
m = [[1, 2, 3],
     [4, 5, 6]]
print(m[1][2])                     # 第 2 行、第 3 列 -> 6

# 用推导式取「某一列」
col0 = [row[0] for row in m]       # [1, 4]

# 展平一个二维列表
flat = [n for row in m for n in row]   # [1,2,3,4,5,6]

# 条件推导式也可用三元表达式
labels = ["even" if x % 2 == 0 else "odd" for x in range(4)]
# -> ['even','odd','even','odd']
★

核心要点：推导式结构 = [表达式 for 元素 in 可迭代 if 条件]。它总是生成一个新列表，原列表不受影响；嵌套展开用两层 for，顺序是「先外层、后内层」，读起来把 for row in m for n in row 当作「逐行 -> 逐元素」即可。

核心元组：不可变的兄弟Tuple · 解包 · 多返回值

元组（tuple）长得很像列表，用圆括号 (...) 围起来，同样有序、可索引、可切片、可遍历。它的关键区别只有一个字：不可变——创建后不能增、删、改。正因为不可变，它才能做些列表做不到的事。

python
t = (1, 2, 3)               # 圆括号，可省略
one = (1,)                  # 单元素元组：必须加逗号！
t2 = tuple([1, 2, 3])       # 由列表转换成元组

# 读取与列表一致
print(t[0], t[-1])          # 1 3
print(t[0:2])               # (1, 2)
print(len(t), 2 in t)       # 3 True

# 元组不可变：不能增删改！
# t[0] = 99                 # TypeError: 'tuple' object does not support item assignment
# t.append(4)               # AttributeError: 'tuple' object has no attribute 'append'

# 解包（unpacking）
a, b, c = (1, 2, 3)
first, *rest = (1, 2, 3, 4)     # first=1, rest=[2,3,4]

# 函数返回多个值（本质是返回一个元组）
def minmax(xs):
    return min(xs), max(xs)
lo, hi = minmax([3, 1, 5])
print(lo, hi)               # 1 5
✕

高频错误：想写单元素元组却写成 t = (1)——括弧里的 1 只是数字，(1) 就是 1！单元素元组必须带逗号：(1,)。空元组用 ()。另外，元组不可变指的是元素指向不能改，若元组内部嵌套了列表，列表里的内容仍可变（叫「浅不可变」）。

关键可变 vs 不可变 · 深浅拷贝引用别名与复制是两个层面

这是本节最容易「感觉懂了却翻车」的地方。Python 里赋值 b = a 并不复制对象，只是让 b 引用同一个对象。因为列表可变，改 b 会连带着改 a。想真正复制，得用拷贝；嵌套列表还得分清浅拷贝与深拷贝。

  sa["a 变量"] --> obj["列表对象 [1, 2, 3]"]
  sb["b 变量"] --> obj
  obj -->|"b.append(4) 修改的是共享对象"| both["a 与 b 都看到 [1,2,3,4]"]
  subgraph 注意

b2 = a 只是引用别名"]

python
import copy

# 1) 引用别名：b 和 a 指向同一个对象
a = [1, 2, 3]
b = a
b.append(4)
print(a)      # [1, 2, 3, 4]  <- a 也被改！

# 2) 浅拷贝：复制最外层，嵌套对象仍共享
outer = [1, [2, 3]]
shallow = outer.copy()            # 或 outer[:] / list(outer)
shallow[1].append(4)
print(outer)      # [1, [2, 3, 4]]  <- 内层还是被改了

# 3) 深拷贝：递归复制所有层
deep = copy.deepcopy(outer)
deep[1].append(5)
print(outer)      # [1, [2, 3, 4]]（deep 的改动不影响 outer）
print(deep)       # [1, [2, 3, 4, 5]]

# 不可变对象（元组/字符串/数字）没有这个坑
t = (1, 2, 3)
# t[0] = 9        # TypeError —— 元组不可变，天然防篡改
!

易错点：copy() 是浅拷贝，只复制最外层；一旦列表里还嵌套了列表，改内层会两边一起变。只有 copy.deepcopy() 会递归复制所有层。copy.copy() 对不可变对象（如元组）几乎等于不复制——因为改不了，共享也无所谓。

顺带一提，这个「不可变 -> 可哈希」的结论，正是理解字典/集合的钥匙：列表可变、不可哈希，所以不能当字典的 key；元组不可变、可哈希，当 key 没问题。这一知识点会在「字典与集合」一节展开。
