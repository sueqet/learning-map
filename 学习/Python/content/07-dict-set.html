字典与集合

字典用键值对实现几乎恒定时间的存取，集合专管去重与关系运算——理解哈希与不可变这两条规则并会用 dict/set/defaultdict/Counter，是写出高效 Python 的关键。

✓本节学习目标

  • 学完后，你能创建并操作一个字典：新增、修改、删除、安全读取（get/setdefault）、判断键是否存在。
  • 学完后，你能说清字典与列表的区别（按下标 vs 按键），以及为什么字典的键必须可哈希、不可变。
  • 学完后，你能用keys()/values()/items()遍历字典，并用字典推导式快速构造容器。
  • 学完后，你能创建集合，并熟练使用并集、交集、差集、对称差集与子集判断完成去重和关系运算。
  • 学完后，你能用defaultdict 与 Counter 一行搞定「计数、分组」这类常见需求。
  • 学完后，你能借助哈希表原理理解为什么键查找接近 O(1)，并避开「可变对象当键」等易错点。

小节字典：键值对的核心创建 · 读取 · 增删改查

字典（dict）是键 → 值的映射：给定一个键，就能取出它对应的值，就像查字典用字找解释。键是唯一且不可变的，值可以是任意对象。

  • 读值用 d[key]；键不存在会抛出 KeyError，所以常用 d.get(key, 默认值) 做安全读取。
  • 给 d[key]=value：键已存在则覆盖，不存在则新增。
  • 删除用 del d[key] 或 d.pop(key)（后者会返回被删的值）。
  • 成员判断用 key in d，非常高效。
python
# ===== 创建字典 =====
person = {"name": "Alice", "age": 30, "city": "Beijing"}
empty = {}                          # 空字典（注意别和集合混淆）
by_ctor = dict(name="Bob", age=25)  # 用关键字参数构造

# ===== 读取 =====
print(person["name"])        # Alice
print(person.get("age"))     # 30
print(person.get("nick", "无"))   # 无（键不存在，返回默认值）
print(person["missing"])     # !!! KeyError（会报错）

# ===== 新增 / 修改 =====
person["country"] = "China"  # 新增
person["age"] = 31           # 修改（覆盖原值）

# ===== 删除 =====
del person["city"]           # 删除键值对
val = person.pop("country")  # 删除并返回该值 -> "China"

# ===== 成员判断 =====
print("name" in person)      # True
print("phone" not in person) # True

print(person)
★

核心要点：字典的「键」不能重复，后来的赋值会覆盖先前的。查找、插入、删除都是按键完成，因此很快——这归功于背后的哈希表。

小节字典常用方法与非空键视图 · 遍历 · 初始化

下面这些方法覆盖了绝大多数字典操作。注意 keys()/values()/items() 返回的是视图（view），它动态反映字典变化，常用于遍历。

方法作用示例注意
d.keys()返回所有键的视图d.keys()随字典变化实时更新
d.values()返回所有值d.values()可能有重复
d.items()返回 (键, 值) 对for k, v in d.items()遍历最常用的写法
d.get(k, 默认)读取，缺失给默认d.get("x", 0)比 d[k] 安全
d.setdefault(k, 默认)读取；不存在则写入默认d.setdefault("k", [])常用初始化默认结构
d.update(other)批量合并/更新d.update({"a": 1})同键会被覆盖
d.pop(k, 默认)删除并返回；缺失给默认d.pop("a")不传默认且缺失会 KeyError
d.clear()清空字典d.clear()原地清空
python
d = {"a": 1, "b": 2}
for k in d:              # 直接遍历 = 遍历键
    print(k)
for k, v in d.items():   # 同时取键和值
    print(k, "->", v)

# 安全读取 + 默认值
print(d.get("c", 0))     # 0

# 初始化嵌套结构：想让键存在时自动是一个空列表
scores = {}
for name in ("Tom", "Amy", "Tom"):
    scores.setdefault(name, []).append(90)
print(scores)   # {'Tom': [90], 'Amy': [90]}

# update 合并
d.update({"b": 99, "c": 100})
print(d)        # {'a': 1, 'b': 99, 'c': 100}
!

易错点：{} 创建的是空字典不是空集合；集合要用 set()。另外遍历字典时若在循环里修改字典会报 RuntimeError，请先 list(d.items()) 或复制一份。

小节推导式与一行计数字典推导式 · Counter

字典推导式写成 {key_expr: value_expr for ...}，能以极简代码从序列构造字典，常用来做「映射」或「计数」。

python
# 平方表：键是数，值是它的平方
squares = {x: x ** 2 for x in range(5)}
print(squares)   # {0:0, 1:1, 2:4, 3:9, 4:16}

# 用 get 手动统计字符频次
word = "banana"
freq = {}
for ch in word:
    freq[ch] = freq.get(ch, 0) + 1
print(freq)      # {'b':1, 'a':3, 'n':2}

# 更简洁：collections.Counter
from collections import Counter
print(Counter(word))   # Counter({'a':3, 'n':2, 'b':1})

# 反转键值
d = {"a": 1, "b": 2}
rev = {v: k for k, v in d.items()}
print(rev)       # {1:'a', 2:'b'}

# 过滤：只保留偶数键
m = {k: k * k for k in range(10) if k % 2 == 0}
print(m)         # {0:0, 2:4, 4:16, 6:36, 8:64}
★

核心要点：凡是要「统计每个东西出现了多少次」，几乎都可归结为 d[x] = d.get(x, 0) + 1，或直接用 Counter。计数问题优先想到字典。

小节集合（set）：无序且唯一创建 · 去重 · 增删

集合（set）是无序、元素唯一、元素可哈希的容器。三大特性决定了它的用途：去重、成员判断（O(1)）、关系运算（交并差）。

  • 创建：{1,2,3} 或 set(可迭代对象)；空集合只能用 set()。
  • 元素唯一：重复元素会被自动合并。
  • 增删：add/discard（不存在不报错）/remove（不存在报错）/pop（删除并返回任意一个）。
python
s = {1, 2, 3, 2}       # 重复的 2 被去重 -> {1,2,3}
print(s)               # {1,2,3}（顺序不保证）

empty = set()          # 空集合（{} 是字典！）

s.add(4)               # 添加
s.discard(3)           # 删除，不存在也不报错
s.remove(1)            # 删除，不存在会抛 KeyError
# s.remove(99)         # KeyError

print(len(s))
print(2 in s)          # 成员判断，O(1)

# 常用：用集合去重
nums = [3, 1, 4, 1, 5, 9, 2, 6, 5]
uniq = list(set(nums))
print(uniq)            # 去重后的列表（顺序不保证）

# 有序去重（保持原顺序）
seen = set(); result = []
for x in nums:
    if x not in seen:
        seen.add(x); result.append(x)
print(result)          # [3,1,4,5,9,2,6]
!

易错点：集合里不能放可变的、可哈希不了的对象，如列表、字典、集合本身（但可以放元组/字符串/数字/frozenset）。例如 s.add([1,2]) 会抛 TypeError: unhashable type: 'list'。

⚠

注意：集合没有顺序，不能用下标 s[0] 访问；如需要「有序、可重复」，请回到列表；如需要「有序且不重复」，用 dict（键即集合，Python 3.7+ 字典保序）。

小节集合运算与哈希原理交并差 · 子集 · O(1) 从哪来

集合最大的价值是关系运算：两个集合直接就能算交集、并集、差集、对称差集，一行搞定。这些运算同样基于哈希表，速度很快。

python
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

print(a & b)           # 交集 {3,4}
print(a | b)           # 并集 {1,2,3,4,5,6}
print(a - b)           # 差集 {1,2}（在 a 不在 b）
print(a ^ b)           # 对称差 {1,2,5,6}

print({1,2} <= a)       # 子集 True
print(a.isdisjoint(b)) # 是否无交集 False
print(b.issuperset(a)) # 是否包含 a False

# 常见用法：求两组人的共同好友
friends_a = {"Tom", "Amy", "Bob"}
friends_b = {"Tom", "Bob", "Eve"}
print(friends_a & friends_b)   # {'Tom','Bob'}

核心要点：哈希表把「找键」这一步变成「算一个位置」，从而把查找从 O(n) 降到平均 O(1)。代价是内存换时间，且键必须是不可变、可哈希的对象。

小节defaultdict 与 Counter把「初始化」的样板代码交给标准库

统计与分组时，我们常要「键不存在就先用一个默认结构」。defaultdict 通过一个工厂函数自动补默认值，让代码更干净；Counter 则是专为计数设计。

python
from collections import defaultdict, Counter

# 1) 用 defaultdict(list) 分组
groups = defaultdict(list)
for word in ["apple", "banana", "apricot", "blueberry"]:
    groups[word[0]].append(word)
print(dict(groups))
# {'a': ['apple', 'apricot'], 'b': ['banana', 'blueberry']}

# 2) 用 defaultdict(int) 计数
cnt = defaultdict(int)
for ch in "mississippi":
    cnt[ch] += 1
print(dict(cnt))   # {'m':1, 'i':4, 's':4, 'p':2}

# 3) Counter：直接计数，还能取最常见的
words = ["a", "b", "a", "c", "b", "a"]
c = Counter(words)
print(c.most_common(2))   # [('a', 3), ('b', 2)]

# Counter 之间也能做加减（把出现次数当"分量"）
c1 = Counter("aabbc")
c2 = Counter("abcc")
print(c1 + c2)   # Counter({'a':3, 'b':3, 'c':3})
★

核心要点：遇到「计数」用 Counter，遇到「分组 / 键默认有结构」用 defaultdict(factory)。工厂函数可以是 list/int/set/dict，分别得到对应的默认空容器。
