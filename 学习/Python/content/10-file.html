文件与路径

文件读写是程序与外部世界交互的基本方式：学会安全地打开、读取、写入文件，理解文本与二进制的区别，并用 pathlib 优雅地管理路径与遍历目录。

✓本节学习目标

  • 学完后，你能用 open() 搭配 with 安全地读写文本文件，并说明为什么推荐 with。
  • 学完后，你能区分文本模式与二进制模式，并为不同场景选择正确的编码与打开方式。
  • 学完后，你能用 pathlib 拼接路径、判断存在性、取文件名与后缀，替代过时的字符串拼接。
  • 学完后，你能遍历目录下的所有文件并按条件筛选（如按后缀、按大小、按修改时间）。
  • 学完后，你能写出健壮的读写逻辑——正确关闭文件、处理编码异常、避免路径踩坑。
Prerequisites · 前置知识

先掌握 字符串、异常处理（try/except） 与 函数/函数返回 即可。若能理解「路径是字符串、文件是字节流」这两个直觉，学习会更顺。

01文件读写模型
从「打开 → 操作 → 关闭」看本质

小节用 open() 与 with 打开文件open · with · read · write

在 Python 里打开文件要经过「打开 → 读写 → 关闭」三步。手动调用 close() 容易在异常时漏掉，导致文件句柄泄漏；推荐用 with 语句，它会在离开代码块时自动关闭文件，这是最安全、最符合习惯的写法。

python
# 只读打开文件，逐行读取
with open("data.txt", "r", encoding="utf-8") as f:
    content = f.read()            # 一次性读全部
    print(content[:200])

# 逐行迭代：适合大文件，不用一次性塞进内存
with open("data.txt", encoding="utf-8") as f:
    for line in f:                 # line 会包含行尾的 \n
        print(line.rstrip())       # 去掉行尾换行

# 写入文件（覆盖模式）
with open("out.txt", "w", encoding="utf-8") as f:
    f.write("第一行\n")
    f.write("第二行\n")

# 追加(append)模式：在文件末尾续写
with open("out.txt", "a", encoding="utf-8") as f:
    f.write("追加的一行\n")

关键参数 mode 决定打开方式：r 只读、w 覆盖写、a 追加、x 独占创建（文件已存在则报错）。完整写法还会加一个 + 表示「读写兼备」。encoding 只在文本模式下有意义，默认由平台决定，建议显式指定。

★

核心要点：永远优先用 with open(...) as f:。写文件时若忘关文件，内容可能没完全落盘；用 with 则无此顾虑。

小节文本 vs 二进制、模式对照mode · 编码 · 字节

文本模式把文件内容按字符处理，读入的是 str，需要用 encoding 解码；二进制模式（末尾加 b）读入的是 bytes，适合图片、音频、压缩包、加密数据等。

模式读到的类型是否编码典型用途
r / w / astr（文本）是（用 encoding）日志、配置、JSON、CSV
rb / wb / abbytes否图片、音频、PDF、压缩包
r+可读可写是既要读又要改
x独占创建是避免误覆盖已有文件
python
# 二进制：复制图片
with open("photo.jpg", "rb") as src, open("copy.jpg", "wb") as dst:
    dst.write(src.read())          # 分块也可，这里演示整体

# 文本模式常见编码问题
# Windows 上默认编码可能是 gbk，读取 utf-8 文件会乱码/报错
try:
    with open("notes.md", "r", encoding="utf-8") as f:
        text = f.read()
except UnicodeDecodeError as e:
    print("解码失败：", e)

# 用 errors 参数兜底：忽略无法解码的部分
with open("notes.md", "r", encoding="utf-8", errors="replace") as f:
    text = f.read()
!

易错点：读写方向搞反、或把文本文件用 rb 打开后当字符串用，会得到 b'...' 字节对象。二进制内容要 先解码（.decode()）再作字符串处理。

小节用 pathlib 管理路径Path · / · 拼接 · 属性

过去用 os.path.join() 拼路径、os.path.exists() 判断存在，写法啰嗦且要把路径当字符串处理。现代写法是 面向对象 的 pathlib.Path——用 / 运算符拼接，跨平台自动处理路径分隔符。

python
from pathlib import Path

p = Path("data") / "sub" / "file.txt"      # 跨平台拼接，不用管斜杠
print(p)                                   # data/sub/file.txt

# 常用属性
print(p.name)        # file.txt      —— 文件名
print(p.stem)        # file          —— 去掉后缀的文件名
print(p.suffix)      # .txt          —— 扩展名
print(p.parent)      # data/sub      —— 所在目录
print(p.exists())    # 是否存在
print(p.is_file())   # 是否为文件
print(p.is_dir())    # 是否为目录

# 绝对路径 / 当前目录 / 用户目录
print(Path.cwd())        # 当前工作目录
print(Path.home())       # 用户主目录
print(p.resolve())       # 解析成绝对路径

# 创建目录（可以一次建多层）
Path("out/snapshots").mkdir(parents=True, exist_ok=True)

resolve() 很适合判断「两个路径是否指向同一文件」，但要注意它依赖磁盘状态；name/stem/suffix 这些属性不触碰磁盘，可放心用在字符串处理上。

!

提醒：永远不要在 Windows 下手写 \ 拼路径——反斜杠在 Python 字符串里是转义符。用 Path 的 / 或 os.path.join，让库去做平台适配。

小节遍历目录与筛选文件iterdir · glob · 递归

处理器多文件任务（批量改名、重命名、按后缀汇总）时，需要遍历一个目录。基础是 iterdir()，用 glob() 能按模式匹配，rglob() 可递归地往下找。

python
from pathlib import Path

base = Path(".")   # 当前目录

# 遍历当前目录一层
for item in base.iterdir():
    print("文件" if item.is_file() else "目录", item.name)

# 找出所有 .py 文件（当前目录，非递归）
for f in base.glob("*.py"):
    print(f.name)

# 递归找出所有 .md
for f in base.rglob("*.md"):
    print(f)

# 按修改时间排序 + 过滤大小
files = [f for f in base.rglob("*") if f.is_file()]
big = [f for f in files if f.stat().st_size > 10**6]     # > 1MB
big.sort(key=lambda f: f.stat().st_mtime, reverse=True)
for f in big:
    print(f.stat().st_size, f)
flowchart TD A[Path 起点] --> B{"是目录?"} B -- 是 --> C[iterdir 逐项遍历] C --> D{还要扩展名筛选?} D -- 是 --> E[glob / rglob 匹配] E --> F[得到 Path 列表] D -- 否 --> F B -- 否 --> G[直接是文件, 可操作] F --> H[逐文件处理: 读/写/改名] G --> H
★

核心要点：rglob("*.txt") 一步就递归找全扩展名匹配的文件，比手写递归更简洁。配合 f.stat() 可拿到大小、修改时间等元数据用于筛选排序。

小节IO 进阶：seek、上下文与健壮读写seek · tell · with · 基准

文件对象自带一个文件指针。读完一遍后指针在末尾，想再读就得回退。用 seek() 移动指针、tell() 查看当前位置。大文件处理时要考虑分块读取，避免一次性把整文件读进内存。

python
with open("data.txt", "rb") as f:          # 用二进制便于按字节定位
    print("当前位置:", f.tell())            # 0
    f.seek(10)                             # 跳到第 10 字节
    chunk = f.read(8)                      # 读取 8 字节
    print(chunk, f.tell())                 # 当前位置变为 18
    f.seek(0)                              # 回到开头
    print(f.read(5))

# 大文件分块处理模板（避免读入全部内存）
def count_lines(path, chunk=4096):
    n = 0
    with open(path, "rb") as f:
        while True:
            buf = f.read(chunk)
            if not buf:
                break
            n += buf.count(b"\n")
    return n
!

易错点：读取完（或写入后）没 flush()/关闭就继续别处读取，可能读到旧数据或空内容。多文件同时打开时，写成 with open(a) as x, open(b) as y: 一次性管理更清晰。

小节实战：读写 JSON / CSVjson · csv · 序列化

真实项目里文件多为结构化数据。用 json 模块做序列化/反序列化，用 csv 处理表格——两者都建立在文本读写之上，是「文件与路径」最常用的落地场景。

python
import json
from pathlib import Path

data = {"name": "Ada", "lessons": ["file", "path"]}
# 写入 JSON
with open("conf.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)

# 读取 JSON
with open("conf.json", "r", encoding="utf-8") as f:
    loaded = json.load(f)
print(loaded["name"])

# --- CSV ---
import csv
with open("scores.csv", "w", newline="", encoding="utf-8") as f:
    w = csv.writer(f)
    w.writerow(["name", "score"])      # 表头
    w.writerow(["Liz", 90])
    w.writerow(["Tom", 85])

with open("scores.csv", "r", newline="", encoding="utf-8") as f:
    for row in csv.reader(f):
        print(row)
★

核心要点：写 JSON 用 ensure_ascii=False 才能保留中文；写 CSV 记得加 newline=""，否则 Excel 在 Windows 上会看到空行。
