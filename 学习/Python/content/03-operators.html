运算符与表达式

运算符是把值加工成新值的动词。这一节把 Python 的运算符家族一网打尽——算术、比较、逻辑、位、赋值与三元表达式，尤其讲清 / vs //、is vs ==、短路求值 与 优先级 这些面试必考的坑，让你写出又对又漂亮的表达式。

✓本节学习目标

  • 学完后，你能把 Python 运算符分成算术、比较、逻辑、位、赋值、三元六大类，并说出各自的返回类型。
  • 学完后，你能用 //、%、** 做整除、取余与幂运算，并解释 / 恒返回 float、// 向下取整。
  • 学完后，你能用 is 判身份、== 判值相等、in 判成员，并避开「小整数缓存」「深浅拷贝」的坑。
  • 学完后，你能利用 and/or 的短路求值写出带默认值的精炼表达式，并说明它返回的是操作数而非布尔值。
  • 学完后，你能用位运算符做掩码/标志位操作与异或交换两个数，并能解释 &、|、^、~、<<、>>。
  • 学完后，你能按优先级与结合性推导任意表达式的求值顺序，并在必要处用括号显式控制。

从算术到优先级，系统地吃透表达式的写法

算术算术运算符：/ // % ** 与字符串的 + *先掌握最常用的一类

Python 提供 7 个算术运算符：+ - * / // % **。其中 / 是真除法（恒返回 float），// 是整除（向下取整，返回 int），% 是取余，** 是幂。+ 与 * 还支持字符串：拼接与重复。

python
# 算术运算符
a, b = 10, 3
print(a + b)   # 13       加
print(a - b)   # 7        减
print(a * b)   # 30       乘
print(a / b)   # 3.3333333333333335   真除法，恒为 float
print(a // b)  # 3        整除（向负无穷取整），返回 int
print(a % b)   # 1        取余
print(a ** b)  # 1000     幂

# 负数时注意：// 向下取整、% 取余，满足 a == (a//b)*b + a%b
print(-7 // 2)   # -4      向负无穷取整
print(-7 % 2)    # 1       因为 (-4)*2 + 1 = -7

# 字符串也能用 + 和 *
print("Py" + "thon")   # Python
print("ab" * 3)        # ababab
运算符含义示例 (10, 3)返回
+加（字符串拼接）13数值 / 字符串
-减7数值
*乘（字符串重复）30数值 / 字符串
/真除法（恒 float）3.333…float
//整除（向下取整）3int
%取余1数值
**幂（右结合）1000数值
!

易错：Python 3 里 / 是真除法，即使能整除也会返回 float。10 / 2 得到 5.0，而不是 5；想要整数结果请用 //。// 是向下取整（向负无穷），所以 -7 // 2 是 -4 而不是 -3，这点常被面试考察。

比较比较运算符、身份 is 与成员 in判断关系与归属

比较运算符恒返回 bool：== != < <= > >=。另有两个极易混淆的角色：is/is not 判断是否同一个对象（比内存地址），in/not in 判断成员归属（是否在容器里）。Python 还支持链式比较，比 and 写法更省内存。

python
# 比较运算符：返回 True / False
print(5 > 3)      # True
print(5 == "5")   # False  类型不同不相等
print(5 != 3)     # True

# 链式比较：1 < x < 10  等价于 (1 < x) and (x < 10)，且 x 只求值一次
x = 5
print(1 < x < 10)   # True

# 身份 is（同一内存对象） vs 值相等 ==
a = [1, 2, 3]
b = a       # 赋值不复制，b 和 a 是同一个对象
c = a[:]    # 浅拷贝，c 是一个新对象
print(a is b)   # True
print(a == b)   # True
print(a is c)   # False  不是同一个对象
print(a == c)   # True   但值相等

# 成员 in / not in
print(2 in a)        # True
print(9 not in a)    # True
print("o" in "Hello")  # True
!

易错：is 与 == 别混用。== 比较值；is 比较是否为同一个对象。判断 None 必须用 x is None（或 is not None），不要写 x == None。判断两个内容相同的容器是否「相等」用 ==；只有关心「是不是同一个对象」时才用 is。

?

小整数驻留的坑：CPython 会缓存 -5 ~ 256 的小整数并复用，因此 a = 256; b = 256; a is b 常为 True；而 a = 257; b = 257; a is b 常为 False（超出缓存，各自创建）。这类行为高度依赖实现，不要依赖它——比较值请一律用 ==。

逻辑and / or / not 与短路求值写出精炼条件的核心

逻辑运算符有 and（且）、or（或）、not（非）。关键点：and/or 返回参与运算的操作数本身，而不是 True/False，并遵循短路求值——一旦能确定结果就不再计算后面的部分。判断真值靠「真值性」：0、0.0、""、[]、()、{}、set()、None 为假，其余为真。

python
# 真值性
print(bool(0), bool(""), bool([]), bool(None))          # False False False False
print(bool("a"), bool([1]), bool(42))                   # True True True

# and / or 返回操作数，不是 True/False
print(0 and 5)     # 0   0 为假 → 短路，返回 0
print(3 and 5)     # 5   两个都真 → 返回最后一个
print(0 or 5)      # 5   0 为假 → 返回 5
print(3 or 5)      # 3   3 为真 → 短路，返回 3
print(not 3)       # False

# 经典技巧：用 or 提供默认值（相当于 if 值 为空则用默认）
name = input("名字：") or "匿名用户"      # 输入为空字符串时取默认
print("你好，", name)

# 短路还能避免副作用
data = [] or [1, 2, 3]   # data 变成 [1, 2, 3]
print(data)
运算符含义求值规则
and逻辑与左边为假→返回左边；否则继续，返回右边。全真返回最后一个。
or逻辑或左边为真→返回左边（短路）；否则返回右边。全假返回最后一个。
not逻辑非恒返回 bool，把真值取反（not x）。
!

易错：and/or 返回的是操作数，不是 True/False。所以 0 or 5 是 5，3 and 5 是 5，而不是 True。若你需要真正的布尔值，请在外面套 bool(...)。只有 not 一定是布尔结果。

位运算位运算符：& | ^ ~ << >> 与掩码处理标志位与底层状态

位运算符按二进制位运算：按位与 &、按位或 |、按位异或 ^、按位取反 ~、左移 <<、右移 >>。它常用于权限/标志位（掩码）、低位运算性能优化，以及经典的「异或交换」。

python
#  5 -> 101   3 -> 011
print(5 & 3)   # 1   按位与   101 & 011 = 001
print(5 | 3)   # 7   按位或   101 | 011 = 111
print(5 ^ 3)   # 6   按位异或  101 ^ 011 = 110
print(~5)      # -6  按位取反  ~x = -x - 1
print(1 << 3)  # 8   左移 3 位（乘 2^3）
print(8 >> 2)  # 2   右移 2 位（整除 2^2）

# 异或交换两个数（不带临时变量）
x, y = 7, 9
x ^= y; y ^= x; x ^= y
print(x, y)    # 9 7

# 掩码：判断某一位是否为 1
flags = 0b1100
print(bool(flags & 0b0100))    # True    第 2 位（从 0 数）为 1
print(bool(flags & 0b0010))    # False   第 1 位为 0
运算符含义示例备注
&按位与5 & 3 = 1都为 1 才是 1；用于清零/取掩码
|按位或5 | 3 = 7有 1 即 1；用于置位
^按位异或5 ^ 3 = 6不同为 1；用于翻转/交换
~按位取反~5 = -6规则 ~x = -x-1
<<左移1 << 3 = 8乘 2^n
>>右移8 >> 2 = 2整除 2^n
★

核心要点：用按位与做掩码可判断某位是否置位（如 flags & 0b0100）；用按位或可把某些位置 1；用异或无需临时变量即可交换两数，也常用于「翻转」位状态。写二进制字面量可用 0b 前缀（如 0b1100）更直观。

优先级赋值、三元表达式与运算优先级写出可读表达式的最后一块拼图

赋值运算符会把算术与复合赋值合成一步（+=、-=、*=、//=、%= 等）；海象运算符 :=（Python 3.8+）允许在表达式里直接赋值；三元表达式 为真时的值 if 条件 else 为假时的值　能把简单分支压成一行。优先级决定了表达式从左到右的「谁先算」，幂 ** 右结合是典型例外。

python
# 赋值运算符
x = 5
x += 3     # 等价 x = x + 3
x //= 3    # x = x // 3
print(x)   # 2

# 多元赋值 & 解包（交换变量）
a, b, c = 1, 2, 3
a, b = b, a      # 交换
print(a, b, c)   # 2 1 3

# 海象运算符 :=（在表达式里赋值，Python 3.8+）
n = 10
if (half := n // 2) > 3:
    print("half =", half)   # half = 5

# 三元表达式：真值 if 条件 else 假值
score = 88
grade = "优秀" if score >= 85 else "良好"
print(grade)   # 优秀

# 优先级示例：** 右结合，所以 2**3**2 = 2**(3**2) = 2**9 = 512
print(2 ** 3 ** 2)   # 512
print(2 * 3 ** 2)    # 18  （先幂后乘）
print((2 * 3) ** 2)  # 36  （括号显式控制）

提醒：不要死记优先级。真正写代码时，复杂表达式就用括号显式分组，可读性和正确性远高于「我记得优先级」。唯一值得记住的例外是 ** 右结合：2 ** 3 ** 2 等于 2 ** (3 ** 2) = 512，而不是 (2 ** 3) ** 2 = 64。
