PYTHON · 基础

程序控制流

让程序学会「判断」与「重复」：用条件分支和循环，把一段逻辑变成能自己决策、反复执行的能力——这是程序从「脚本」走向「算法」的分水岭。

✓本节学习目标

  • 学完后，你能用 if / elif / else 写出按条件分流的程序，并理解「首个成立分支胜出、其余跳过」的执行顺序。
  • 学完后，你能区分真假值（falsy），并用 if not items: 安全判断容器是否为空。
  • 学完后，你能用 for 遍历字符串/列表，并用 range(start, stop, step) 生成可控的整数序列。
  • 学完后，你能用 break 跳出、continue 跳过，并说清循环 else 只有在自然结束时才执行的独特含义。
  • 学完后，你能写出不会失控的 while 循环，并规避死循环。
  • 学完后，你能用 enumerate 同时拿下标与元素、用 zip 并行遍历多个序列，写出更简洁的循环。
Prerequisites · 前置知识

学本页前，你会写变量、调用 print，并了解运算符与表达式（尤其是比较与逻辑运算、== 与 is 的区别）。建议先学完「运算符与表达式」，或至少能熟练写出 score >= 60 这类判断式。

01程序控制流
判断、重复与循环控制

01条件分支：if / elif / else

程序默认从上到下一行行执行，遇到 if 就开始「问路」：条件为真就走这个分支，否则问下一问。多个分支用 elif（else + if 的简写）串联，最后用 else 兜底。Python 用缩进而不是大括号来划分代码块，冒号 + 换行 + 缩进表示「这个块属于 if」。

python
score = 87

if score >= 90:
    grade = "优秀"
elif score >= 80:
    grade = "良好"
elif score >= 60:
    grade = "及格"
else:
    grade = "不及格"

print(grade)   # 良好
flowchart TD A[score >= 90 ?] -->|是| B[grade = 优秀] A -->|否| C[score >= 80 ?] C -->|是| D[grade = 良好] C -->|否| E[score >= 60 ?] E -->|是| F[grade = 及格] E -->|否| G[grade = 不及格] B --> H[print grade] D --> H F --> H G --> H
★

核心要点：条件从上到下依次判断，命中第一个为真的分支就执行并跳出整个判断链，后面的 elif/else 一概不看。所以判断顺序很关键：把「最严格/最靠前」的条件放上面。

⚠

易错点：把多个独立的 if 当成 elif 用——多个 if 会各自独立判断，可能一次走多个分支；只有 elif 才保证「互斥、只走一个」。

02真值判断：什么是「假值」

在 if/while 里，条件表达式会被自动转成布尔值。Python 规定一批「falsy（假值）」：它们要么是 0，要么是空、None、False。除此之外一切都为真。

类别假值 (falsy)真值 (truthy) 示例
数值0、0.0、0j1、-3、0.5
字符串"""0"、" "、"abc"
容器[]、()、{}、set()[0]、(0,)、{"a":1}
其它None、FalseTrue、任何对象
python
def judge(name, value):
    print(f"{name:8} -> {'truthy' if value else 'falsy'}")

judge("0", 0)            # falsy
judge("''", "")          # falsy
judge("[]", [])          # falsy
judge("None", None)      # falsy
judge("'0'", "0")        # truthy（非空字符串）
judge("[0]", [0])        # truthy（非空列表）
judge("0.0", 0.0)        # falsy
★

核心要点：判断「容器是否为空」用 if not items: 就够了，不必写 if len(items) == 0:——两者等价，前者更 Pythonic。

!

分清「假值」和「None」：if x: 判断的是 x 是否为假值（0、空、None、False 都算）；if x is None: 才专门判断 x 是否为 None。用 if x: 去判断 None 会在 x=0 或空容器时「误判为假」。

03for 循环与 range()

for 用于「遍历一个可迭代对象」，逐个取出元素，直到取完。要「按次数」循环，常用内置 range() 生成整数序列；而要遍历已有数据，直接遍历它们本身即可。

python
# range(stop)：0 起，到 stop-1
for i in range(3):
    print(i)               # 0 1 2

# range(start, stop, step)
for i in range(2, 10, 2):
    print(i)               # 2 4 6 8

# 遍历字符串
for ch in "abc":
    print(ch)              # a b c

# 遍历列表
for fruit in ["apple", "banana", "cherry"]:
    print(fruit)
调用生成序列说明
range(5)0,1,2,3,4从 0 起，不含终点
range(2, 5)2,3,4start 起，不含stop
range(1, 10, 3)1,4,7每次加 step
range(5, 0, -1)5,4,3,2,1负数 step 可倒序
★

核心要点：range 是半开区间——range(5) 是 0..4，永远不含终点。它返回的是惰性的 range 对象而不是列表，因此无论多大都不占内存。

!

易错点：看到循环想「从几到几」往往会 +1 或 -1 出错。牢记「终点不含在内」：想要 1 到 5，写 range(1, 6)；想要下标到 len 个，就写 range(len(a))。

04循环控制：break、continue 与循环 else

循环体内可以用控制语句改变流程：break 立刻跳出所在循环；continue 跳过本轮剩余代码、直接进入下一轮。三者里最容易被忽视的是循环的 else——它只在循环自然结束（没被 break 打断）时执行。

python
for n in range(2, 10):
    for i in range(2, n):
        if n % i == 0:
            print(f"{n} = {i} * {n // i}")
            break               # 找到因子，跳出内层循环
    else:
        print(f"{n} 是质数")      # 只有内层没被 break 才执行
python
for i in range(6):
    if i % 2 == 0:
        continue        # 跳过偶数，不执行下面
    print(i)            # 1 3 5
⚠

易错点：循环 else 与 if 的 else 语义不同。if-else 一定二选一；for/while-else 的 else 仅在没有被 break 打断时才运行——一旦 break，else 直接跳过。这是「判断循环是否提前退出」的经典写法。

★

使用场景：「在集合里找东西，找到就 break」最适合用循环 else 表达是否找到（找到→break→不进 else；没找到→自然结束→进 else）。

05while 循环与循环安全

for 适合「知道要数多少次」；而"不知道什么时候停下来，只知道一个继续条件"的情形，用 while。每轮先判断条件，为真就执行一次循环体，然后回到条件继续判断。循环体里必须让条件有朝一日变假，否则就是死循环。

python
n = 0
while n < 5:          # 条件
    print(n)
    n += 1            # 关键：让 n 慢慢逼近 5，否则死循环

# 伪代码：直到用户输入 quit 才退出
text = input("输入内容，quit 退出：")
while text.strip().lower() != "quit":
    print("你输入了：", text)
    text = input("继续输入，quit 退出：")
循环适合场景常见写法
for已知范围 / 遍历容器 / 次数确定for x in items:、range(...)
while条件驱动、次数不定（用户输入、事件等待）while cond: + 内部更新
⚠

易错点：死循环是 while 最常见的坑——忘了 n += 1，或条件永远为真。写 while 时先确保循环体内一定会修改条件变量；无法保证时，用 break 做兜底退出。

!

提示：能用 for 表达的场景尽量用 for，它更简洁、不易失控；while 留给「次数未知」的循环。

06循环技巧：enumerate() 与 zip()

有时既要元素又要它的下标——手写 i = 0; i += 1 太累且易错。enumerate 直接返回「(下标, 元素)」对；要并行遍历多个序列，用 zip 把它们按位配对。

python
names = ["张", "李", "王"]
for idx, name in enumerate(names, start=1):
    print(idx, name)     # 1 张 / 2 李 / 3 王

# 并行遍历两个序列
a = [10, 20, 30]
b = ["x", "y", "z"]
for x, y in zip(a, b):
    print(x, y)          # 10 x / 20 y / 30 z
★

核心要点：enumerate(seq, start=1) 返回惰性的「(下标, 元素)」配对迭代器，start 控制下标起点（默认 0）。zip(a, b, ...) 按最短序列停止——多出的元素被丢弃。

!

易错点：若要和下标搭配，习惯用 enumerate 而非 range(len(...))——前者同时拿到下标和值，可读性更好。注意 enumerate 返回的是元组，可拆包成两个变量。
