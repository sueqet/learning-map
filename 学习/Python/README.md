# Python 学习区

专门存放学习 Python 的资料：基础语法、核心数据结构、进阶特性、数据结构与算法（力扣）、数据科学与工程化。

## 🚀 交互式学习包（从这里开始）

本目录是一套**可交互的 Python 学习页面**，按「技能要求」与其它学习内容（Git / Linux / 数据结构与算法）统一格式制作：

- **`index.html`**：学习大纲（21 个知识点，可打勾记录进度，浏览器本地保存，点标题进详解页）。
- **`content/NN-*.html`**：每个知识点一份独立详解页（学习目标 + 讲解 + **可运行的 Python 代码** + 练习考核 + 进阶挑战）。
- 第 4 部分「数据结构与算法」每个都标注了**力扣题号**并给出**完整可运行代码**，方便边学边刷。

> **用法**：双击 `index.html` 用浏览器打开即可开始。勾选/打勾进度存于本机浏览器（`localStorage`，key 为 `learn:python:done`），刷新、换页都不丢。

## 目录结构

- `index.html`：学习大纲。
- `content/`：各知识点详解页（DSA 结构，`NN-slug.html`）。
- `_template.html`：详解页模板，新增知识点时可复制它并替换内容。

## 学习路径（对应 index.html 的 21 个知识点）

1. **语言基础**（01–05）：环境与运行、变量与数据类型、运算符、控制流、字符串。
2. **核心数据结构**（06–08）：列表与元组、字典与集合、函数。
3. **进阶语言特性**（09–13）：异常、文件、模块与标准库、面向对象、迭代器/生成器/装饰器。
4. **数据结构与算法（力扣）**（14–19）：数组与字符串、哈希、栈与队列、链表、动态规划、排序与二分。
5. **数据科学与工程化**（20–21）：NumPy/Pandas 入门、脚本 / requests / FastAPI。
