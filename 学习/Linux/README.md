# Linux 学习区

专门存放学习 Linux 的资料：命令速查、脚本、环境配置、练习与实验记录。

## 🚀 交互式学习包（从这里开始）

本目录已生成一套**可交互的 Linux 学习页面**，覆盖命令行、文件权限、Shell 编程、文件系统、进程与信号、systemd、软件包、网络与防火墙、SSH、证书等主题：

- **`index.html`**：学习大纲（19 个知识点，可打勾记录进度，浏览器本地保存，点标题进详解页）。
- **`NN-*.html`**：每个知识点一份独立详解页（学习目标 + 讲解 + 练习考核 + 进阶挑战）。
- **`勘误与正确性说明.html`**：整理朋友笔记时发现并修正的问题（如 `>>` 追加/覆盖、`/var/run → /run` 方向、`update-ca-trust` 标准做法）。

> **用法**：双击 `index.html` 用浏览器打开即可开始。勾选/打勾的进度存于本机浏览器（`localStorage`，key 为 `learn:linux:done`），刷新、换页都不丢。

## 目录结构

- `linux笔记（朋友的）/`：朋友提供的原始笔记（**未改动**），是学习包内容的来源。
- `_template.html`：详解页模板，新增知识点时可复制它并替换内容。

## 建议放哪些文件

- **学习计划与进度**：`学习计划.md`，列阶段目标和完成情况（可结合 `index.html` 的进度记录）。
- **练习/实验**：`练习/` 子文件夹放脚本与小实验。
- **资源链接**：`资源.md`，记常用教程、手册、练习平台。

## 阶段建议（对应学习包知识点）

1. 命令行基础：`ls/cd/cat/grep/find/管道/重定向`（`01`、`10`）
2. 文件与权限：`chmod/chown/ln`（`02`、`09`）
3. 用户与进程：`ps/top/kill/信号/core dump`（`11`、`12`、`13`）
4. Shell 脚本：变量、判断、循环、函数（`03`–`07`）
5. 服务与软件包：`systemctl`、`dnf/rpm`、软件源（`14`、`15`）
6. 网络与部署：网络配置、防火墙、`ssh`、证书（`16`–`19`）

> 学习包内容已**逐篇核对并修正**朋友笔记中的错误；若发现可补充的主题，可随时告诉我去生成/完善某个知识点页面。
