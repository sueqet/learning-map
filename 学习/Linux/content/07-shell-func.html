LINUX · Shell

Shell 函数

把一段反复用到的逻辑封装成函数，传参、取回结果、局部作用域一次讲清——这是让脚本从「能跑」走向「好维护」的关键一步。

✓本节学习目标

  • 学完后，你能用两种写法（function 关键字可省略）定义一个 Shell 函数并在脚本中调用。
  • 学完后，你能在函数内用 $1、$2、$#、$@ 接收参数，并说明它和脚本自身参数相互独立。
  • 学完后，你能用 local 声明局部变量，避免污染脚本的全局作用域。
  • 学完后，你能区分 return（只返回 0~255 退出码）与 echo（返回结果），并用命令替换 $( ) 取回函数返回值。
  • 学完后，你能将判断、计算等重复逻辑封装为函数，写出结构清晰、可复用的脚本。
Prerequisites · 前置知识

你需要会终端基本操作、熟知 $() 命令替换与 $(( )) 算术，并了解脚本参数变量（$0/$#/$@）；能看懂简单的 if 与 && 判断会更轻松。

Learning Content · 学习内容

01如何让脚本「可复用」
—— 用函数组织逻辑

01定义与调用

函数把一段逻辑包起来、给它个名字，之后只要喊名字就能反复执行。Shell 里定义函数的两种写法都合法，差别仅在于要不要写 function 关键字。

  • 写法一：function greet(){ ... }——显式带上关键字，老式 bash 风格。
  • 写法二：greet(){ ... }——省略 function，更简洁，推荐。
  • 函数体用 { ... } 包裹；{ 后面必须有一个空格（它是 shell 的一个普通命令，不是语法括号）。
  • 调用时直接写函数名：greet "world"，不加括号。
shell · 函数定义与调用
# 写法一：显式 function 关键字
function greet() {
  echo "Hello, $1"
}

# 写法二：省略 function（推荐，更简洁）
greet() {
  echo "Hello, $1"
}

# 调用：直接写名字，不加括号
greet "world"      # 输出: Hello, world
★

核心要点：定义用 (){ }，调用直接写函数名。函数体 { 后的空格不是可有可无，少写会报语法错。

02参数传递与位置参数

函数内部用 $1、$2…接收传给该函数的参数。注意：函数内看到的这些位置参数，是调用函数时传进来的那组，和脚本自身启动时的参数是两套独立的空间。

变量在函数里的含义说明
$1 $2 …传给函数的第 1、2…个参数与脚本参数独立，只在函数体内生效
$#传给函数的参数个数在函数内 = 该函数的参数个数
$@全部参数（逐个分开）遍历时需要「每个参数一个词」时用它
$*全部参数（合并成一个字符串）通常只在确实要整体当字符串时用
$? $!上一条命令的退出码 / 后台进程 PID也适用于函数内，帮你判断逻辑
shell · 参数与返回
sum.sh
-----
#!/usr/bin/env bash
add() {
  local result=$(( $1 + $2 ))   # local + 算术替换
  echo $result                  # 通过 echo 输出结果
}

sum=$(add 3 5)                  # 用命令替换捕获返回值
echo $sum                       # 输出 8

# 用 $# 看传入参数个数；脚本参数与本函数参数相互独立
show() {
  echo "本函数收到 $# 个参数：$@"
}
show a b c                      # 本函数收到 3 个参数：a b c
!

易错点：函数里的 $1 是函数自己的参数，不是脚本的 $1。若脚本是 ./s.sh hello，函数内不传参时 $1 为空，而不是 hello。

03局部变量与作用域

函数内用 local 声明的变量只在该函数内可见，函数返回后即被销毁；不写 local 的赋值默认是全局变量，会污染（甚至在函数外也能读到）脚本作用域。

shell · 局部与全局
foo() {
  local x=10      # 局部变量：只在 foo 函数内可见
  y=20            # 全局变量：函数外也能读到
}

foo
echo "$x"         # 输出空（未设置），x 是局部的
echo "$y"         # 输出 20，y 是全局的
★

核心要点：凡是函数内部用到的临时变量，一律加 local。这既避免意外覆盖外层同名变量，也让函数更「自包含」、可安全复用。

04返回值：echo 输出结果 vs return 退出码

这是函数部分最容易混淆的一点。return 只用来设置退出状态码（只能是 0~255 的整数），它不适合传递计算结果；要想把值「拿」回调用处，用 echo 输出，再用 $( ) 命令替换捕获。

手段产生什么可取回方式适用场景
echo $result输出到 stdout 的值r=$(func …)传递任意结果（数字、字符串）
return 0 / 1退出码（0~255 整数）func && … 或 $?只表示「成功 / 失败」等布尔判断
shell · return 用作布尔判断
# return 表达「是否偶数」，配合 && / || 短路判断
is_even() {
  (( $1 % 2 == 0 )) && return 0 || return 1
}

is_even 4 && echo "even" || echo "odd"   # even
is_even 7 && echo "even" || echo "odd"   # odd
✕

不要这样写：用 return 返回「值」是错误的理解。例如 result=$(add 3 5) 若让函数 return $sum，得到的是退出码而非 8；且超过 255 会取模截断。传「值」请用 echo + $( )。

05函数工作流程

把「定义 → 调用 → 取回结果」串成一张图，看清楚 echo 与 return 各走哪条路。

flowchart TD A[定义函数
fn() { ... }] --> B[调用
fn 参数] B --> C{函数体内要做什么?} C --> D[读取参数 $1 $2 $# $@] C --> E[局部变量 local 防止污染] E --> F{需要返回什么?} F -->|把参数值交给调用者| G[echo 结果] F -->|只判断成功/失败| H[return 0 / 1] G --> I[调用处用 $() 命令替换捕获
sum = fn 3 5] H --> J[调用处用 && 或 || 判断退出码] I --> K[拿到具体数值/字符串] J --> L[拿到退出码, 决定分支]
★

一句话总结：要「值」用 echo + $( )；要「成败」用 return + &&/||。
