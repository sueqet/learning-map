Shell 循环

把重复劳动交给机器：用 for / while / until 让同一段代码反复执行，用 break 与 continue 精确控制跳转。

✓本节学习目标

  • 学完后，你能写出 C 风格的 for ((...)) 计数循环，并说明它为什么是 bash 专属。
  • 学完后，你能用 while 做条件循环、逐行读取文件，并写出无限循环。

Learning Content · 学习内容

01循环：重复执行同一段逻辑

总览循环的执行流程所有的循环都共用这一骨架

无论 for、while 还是 until，本质都是「判断 → 执行 → 再判断」的循环：只要条件成立（或还有元素），就反复执行循环体，直到条件不成立才退出。理解了这张图，三种循环就都能看懂。

flowchart TD A([开始]) --> B[进入循环] B --> C{条件还满足吗?
for 还有元素吗?} C -- 是 --> D[执行循环体] C -- 否 --> Z[退出循环] D --> H{遇到 continue?} H -- 是 --> C H -- 否 --> K{遇到 break?} K -- 是 --> Z K -- 否 --> C
★

核心要点：循环的核心是「退出条件」。写循环前先想清楚什么时候停下来，否则容易写出无限循环。

01for：遍历列表对一组东西做同样的操作

for 循环最适合处理「已知的一批东西」——数字序列、脚本参数、或目录里的文件。常见形式：for 变量 in 列表; do 循环体; done，每轮把列表中的一个值赋给变量。

shell
# 遍历显式列表
for i in 1 2 3; do
  echo $i
done
# 输出：1 2 3

# 遍历脚本参数（$@ 代表所有位置参数）
for i in "$@"; do
  echo $i
done
!

易错点：遍历参数时建议写成 for i in "$@"（加引号），而不是 for i in $@。加引号能让每个参数作为整体传递，避免含空格的参数被拆分。

02for 进阶：文件与 C 风格通配符展开 + bash 专属计数循环

除了显式列表，for 还会自动把通配符（*、?）和命令替换展开成列表。另外 bash 还支持类似 C 语言的计数循环 for ((...))。

shell
# 遍历目录下所有 .conf 文件（通配符自动展开）
for f in /etc/*.conf; do
  echo "$f"
done

# C 风格计数循环（bash 专属，别处可能不支持）
for ((i=0; i<5; i++)); do
  echo $i
done
# 输出：0 1 2 3 4
写法适用场景可移植性
for i in 1 2 3显式列表 / 数字序列POSIX sh 均可
for f in /etc/*.conf遍历匹配某个模式的文件通配符展开，sh/bash 均可
for i in "$@"遍历脚本的位置参数均可，建议加引号
for ((i=0; i<5; i++))精确计数 / 下标循环仅 bash/zsh，非 POSIX
!

易错点：当目录里一个匹配都没有时，通配符（如 /etc/*.conf）会保持原文、原样作为列表元素，导致循环体处理一个不存在的文件名。写脚本时可用 shopt -s nullglob（bash）让无匹配时展开为空。

03while：条件为真时执行逐行读文件 · 无限循环

while 在条件为真时反复执行循环体，每轮都会重新判断条件。它非常适合「读到文件末尾为止」和「直到某进程退出」这类场景。

shell
# 数值递增：i 从 0 打印到 9
i=0
while [ $i -lt 10 ]; do
  echo $i
  ((i++))        # 算术运算，等价于 let i=i+1
done

# 逐行读取文件（最常用！）
while read line; do
  echo "$line"
done < file.txt

# 无限循环：一直运行，直到 Ctrl+C 或 break
while true; do
  echo "running"
  sleep 1
done
★

核心要点：read 读到文件末尾时返回非零退出码，while 的条件因此变为假，循环自动结束——不用自己写跳出逻辑。这也是「读文件」用 while read 而非 for 的原因。

!

易错点：在 while 循环体内记得改变条件变量（如 ((i++))），否则条件永远为真，会变成无限循环。

04until：条件为假时执行与 while 恰好相反

until 与 while 互为镜像：while 在条件为真时执行，until 在条件为假时执行、直到条件为真才退出。表达「等到某件事发生」时，until 往往更自然。

shell
# 直到 i 大于等于 5 才退出；i 从 0 打印到 4
i=0
until [ $i -ge 5 ]; do
  echo $i
  ((i++))
done
# 输出：0 1 2 3 4
循环执行条件何时退出典型场景
while [ 条件 ]条件为真时执行条件变假时退出处理固定范围内的值、读文件
until [ 条件 ]条件为假时执行条件变真时退出等待某条件成立，如等进程退出
★

核心要点：while [ 条件 ] 换成 until [ ! 条件 ] 往往等价；同理 while ! 命令 也可用 until 命令 表达。选择哪种主要看语义是否通顺。

05循环控制：break 与 continue精确跳转 · 嵌套循环

循环体内可以随时主动改变流程：break 立刻跳出整个循环，continue 只跳过本轮剩下的语句、继续下一轮。数字可以指定跳出几层嵌套。

shell
break        # 跳出当前这一层循环
continue     # 跳过本次迭代，继续下一次
break 2      # 一次跳出 2 层嵌套循环

# 示例：遇到 3 就跳过，遇到 5 就结束
for i in 1 2 3 4 5 6; do
  [ "$i" -eq 3 ] && continue
  [ "$i" -eq 5 ] && break
  echo $i
done
# 输出：1 2 4
关键字作用对循环的影响
break跳出当前层循环直接退出，不再执行后续轮次
continue跳过本轮剩余语句回到条件判断，进入下一轮
break N跳出 N 层嵌套循环一次退出多层，如 break 2
!

易错点：break 与 continue 都只能作用于所在层的循环；想跳出外层，用 break N 或借助标志位。别把 continue 误当成「继续执行」——它是跳过本轮。
