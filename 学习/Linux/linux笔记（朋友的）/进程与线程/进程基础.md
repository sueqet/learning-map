# 进程基础

## 进程状态

| 状态 | 缩写 | 含义 |
|------|------|------|
| Running | R | 正在运行或在运行队列中等待 |
| Sleeping | S | 可中断睡眠，等待某个事件（如 I/O） |
| Uninterruptible Sleep | D | 不可中断睡眠，通常在等待磁盘 I/O，kill 无效 |
| Stopped | T | 被暂停（如 Ctrl+Z 或调试器） |
| Zombie | Z | 已退出但父进程未回收，占用进程表项 |

## 优先级（PR 与 NI）

- **PR（Priority）**：内核动态调整的实际调度优先级，范围 0~39，值越小优先级越高。
- **NI（Nice Value）**：用户可调整的优先级偏移，范围 -20~19。
  - **值越小**：优先级越高，越"不友好"，独占更多 CPU 资源。
  - **值越大**：优先级越低，越"友好"，主动让出 CPU 资源给其他进程。
  - PR = 20 + NI（普通进程）

```bash
nice -n 10 ./my_program       # 以 nice 值 10 启动程序
renice -n -5 -p <PID>         # 修改运行中进程的 nice 值（需 root 才能降低 nice 值）
```
