# 服务单元配置文件编写

服务单元配置文件（`.service`）是 systemd 管理服务的核心配置，存放路径：

- `/etc/systemd/system/`：用户自定义服务（优先级最高）
- `/usr/lib/systemd/system/`：系统安装的服务

## 基本结构

```ini
[Unit]
# 服务元数据和依赖关系

[Service]
# 服务运行参数和执行命令

[Install]
# 服务安装配置（enable/disable 时使用）
```

---

## [Unit]

定义服务的元数据和依赖关系。

```ini
[Unit]
Description=服务描述信息
Documentation=https://example.com/docs
After=network.target docker.service    # 在这些服务启动之后再启动
Before=some.service                    # 在这些服务启动之前启动
Wants=syslog.target                    # 弱依赖（缺失不影响主服务）
Requires=network.target                # 强依赖（缺失则主服务无法启动）
```

---

## [Service]

定义服务的运行参数。

```ini
[Service]
Type=simple                     # 服务类型
ExecStart=/usr/bin/myapp        # 启动命令（必须绝对路径）
ExecStop=/usr/bin/myapp stop    # 停止命令（可选）
ExecReload=/bin/kill -HUP $MAINPID  # 重载命令（可选）
Restart=on-failure              # 重启策略
RestartSec=5                    # 重启前等待秒数
User=www-data                   # 运行用户
Group=www-data                  # 运行用户组
WorkingDirectory=/opt/myapp     # 工作目录
Environment=ENV=production      # 环境变量
EnvironmentFile=/etc/myapp.env  # 从文件加载环境变量
LimitNOFILE=65536               # 最大文件描述符数
TimeoutStartSec=30              # 启动超时秒数
```

### Type 取值

| 值         | 说明                                           |
|-----------|----------------------------------------------|
| `simple`  | 默认值，`ExecStart` 直接是主进程                       |
| `exec`    | 类似 simple，但等待 exec 成功后才认为启动完成（较新 systemd 推荐） |
| `forking` | 适用于传统守护进程，主进程 fork 后退出（如 httpd、nginx）        |
| `oneshot` | 一次性任务，配合 `RemainAfterExit=yes` 使用            |
| `notify`  | 服务启动后主动通知 systemd（如 Docker、BuildKit）         |

### Restart 取值

| 值             | 说明                    |
|---------------|-----------------------|
| `no`          | 默认值，不自动重启             |
| `always`      | 无论何种原因停止都重启           |
| `on-failure`  | 仅在异常退出（非零退出码）时重启      |
| `on-abnormal` | 信号终止、超时等异常时重启（不含正常退出） |

---

## [Install]

定义 `systemctl enable/disable` 的行为。

```ini
[Install]
WantedBy=multi-user.target   # 多用户模式下启用（绝大多数服务用这个）
WantedBy=graphical.target    # 图形界面模式下启用
Alias=myapp.service          # 服务别名
```

---

## 示例：Nginx

```ini
[Unit]
Description=The NGINX HTTP Server
Documentation=https://nginx.org/en/docs/
After=network.target

[Service]
Type=forking
ExecStart=/usr/sbin/nginx -c /etc/nginx/nginx.conf
ExecReload=/usr/sbin/nginx -s reload
ExecStop=/usr/sbin/nginx -s stop
Restart=on-failure
User=nginx
Group=nginx
WorkingDirectory=/var/www/html
LimitNOFILE=1048576

[Install]
WantedBy=multi-user.target
```

---

## 最佳实践

1. `ExecStart` 等命令必须使用绝对路径
2. 环境变量用 `EnvironmentFile` 单独管理，不要硬编码在 unit 文件里
3. 生产环境建议 `Restart=on-failure` 或 `Restart=always`
4. 修改后必须执行 `systemctl daemon-reload` 才能生效

> 常用管理命令见 [systemctl](../../命令大全/systemctl.md)
