# 基础概念

Shell 是命令行解释器，接收用户命令并调用操作系统内核执行，将结果返回给用户。

```shell
echo $SHELL         # 查看当前使用的 shell
echo $0             # 查看当前执行的脚本名称
cat /etc/shells     # 查看系统支持的所有 shell
```

## 执行脚本

```shell
bash script.sh      # 不需要执行权限
./script.sh         # 需要执行权限（chmod +x script.sh）
```

脚本首行声明解释器（shebang）：

```shell
#!/bin/bash
#!/bin/sh
```

- `#!/bin/bash`：使用 bash 执行，支持 bash 特有语法（`[[]]`、`(())`、数组等）
- `#!/bin/sh`：使用系统默认 sh，兼容性更好但功能较少
