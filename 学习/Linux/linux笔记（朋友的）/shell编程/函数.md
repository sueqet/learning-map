# 函数

## 定义与调用

```shell
# 写法一
function greet() {
  echo "Hello, $1"
}

# 写法二（更简洁）
greet() {
  echo "Hello, $1"
}

# 调用
greet "world"
```

## 参数与返回值

函数内部使用 `$1`、`$2` 等接收参数（与脚本参数独立）。

```shell
add() {
  local result=$(( $1 + $2 ))
  echo $result          # 通过 echo 输出结果
}

sum=$(add 3 5)          # 用命令替换获取返回值
echo $sum               # 输出 8
```

`return` 只能返回 0~255 的整数（作为退出码），不适合传递计算结果，推荐用 `echo` 输出。

```shell
is_even() {
  (( $1 % 2 == 0 )) && return 0 || return 1
}

is_even 4 && echo "even" || echo "odd"
```

## 局部变量

函数内用 `local` 声明局部变量，避免污染全局作用域。

```shell
foo() {
  local x=10      # 局部变量，函数外不可见
  y=20            # 全局变量，函数外可见
}
```
