# 变量

## 普通变量与环境变量

| 类型   | 作用范围            | 说明            |
|------|-----------------|---------------|
| 普通变量 | 当前 shell / 当前脚本 | 不传递给子进程       |
| 环境变量 | 当前 shell 及所有子进程 | 用 `export` 声明 |

```shell
name="hello"        # 定义普通变量
export name         # 转为环境变量
export age=18       # 定义并同时导出
echo $name          # 使用变量
unset name          # 删除变量
```

> `export` 声明的变量是临时的，退出 shell 后销毁。

## 永久生效

将 `export` 写入 shell 初始化配置文件：

| 文件                | 级别  | 触发时机                                   |
|-------------------|-----|----------------------------------------|
| `/etc/profile`    | 系统级 | 登录式 shell（会执行 `/etc/profile.d/` 下所有脚本） |
| `/etc/bashrc`     | 系统级 | 非登录式 shell                             |
| `~/.bash_profile` | 用户级 | 登录式 shell（会调用 `~/.bashrc`）             |
| `~/.bashrc`       | 用户级 | 非登录式 shell                             |

推荐写入 `~/.bashrc`。

## 特殊变量

```shell
echo $#     # 传递给脚本的参数个数
echo $?     # 上一条命令的退出码（0 成功，非 0 失败）
echo $*     # 所有参数，合并为一个字符串
echo $@     # 所有参数，每个参数保持独立（for 循环推荐用此）
echo $$     # 当前 shell 的进程 ID
echo $!     # 最后一个后台进程的 PID
echo $0     # 当前脚本名称
echo $1     # 第一个参数
echo $2     # 第二个参数（不存在时为空，不报错）
```

`$*` 与 `$@` 的区别：

```shell
for arg in "$*"; do echo $arg; done   # 只循环一次，所有参数是一个整体
for arg in "$@"; do echo $arg; done   # 逐个循环每个参数（推荐）
```

## 变量替换

```shell
${var:-default}     # var 未定义或为空时使用 default
${var:=default}     # var 未定义或为空时赋值为 default
${var:?message}     # var 未定义或为空时打印 message 并退出
${#var}             # 获取变量字符串长度
${var#prefix}       # 删除最短前缀匹配
${var##prefix}      # 删除最长前缀匹配
${var%suffix}       # 删除最短后缀匹配
${var%%suffix}      # 删除最长后缀匹配
${var/old/new}      # 替换第一个匹配
${var//old/new}     # 替换所有匹配
```
