# 条件判断

## if 语句

```shell
if <condition>; then
  echo "in if"
elif <condition>; then
  echo "in elif"
else
  echo "in else"
fi

# 单行写法
if <condition>; then echo "yes"; fi
```

## 条件表达式

| 语法      | 说明                              |
|---------|---------------------------------|
| `[ ]`   | 基本条件测试，POSIX 兼容                 |
| `[[ ]]` | 扩展测试，支持 `&&`、`\|\|`、正则等，bash 专属 |
| `(( ))` | 数值表达式，支持算术运算和比较                 |

### 文件判断

```shell
[ -f file ]     # 是普通文件且存在
[ -d dir ]      # 是目录且存在
[ -e path ]     # 路径存在（文件或目录均可）
[ -r file ]     # 文件可读
[ -w file ]     # 文件可写
[ -x file ]     # 文件可执行
[ -s file ]     # 文件存在且大小不为 0
[ -L file ]     # 是符号链接
```

### 字符串判断

```shell
[ -z "$str" ]           # 字符串为空
[ -n "$str" ]           # 字符串不为空
[ "$a" = "$b" ]         # 字符串相等（= 或 ==）
[ "$a" != "$b" ]        # 字符串不相等
[[ "$str" =~ ^[0-9]+$ ]] # 正则匹配（bash 专属）
```

### 数值比较

```shell
[ $a -eq $b ]   # 等于
[ $a -ne $b ]   # 不等于
[ $a -gt $b ]   # 大于
[ $a -ge $b ]   # 大于等于
[ $a -lt $b ]   # 小于
[ $a -le $b ]   # 小于等于
(( a > b ))     # 数值比较（更直观）
```

### 逻辑组合

```shell
[ cond1 ] && [ cond2 ]      # 与
[ cond1 ] || [ cond2 ]      # 或
[[ cond1 && cond2 ]]        # bash 扩展写法
! [ cond ]                  # 非
```

## case 语句

```shell
case $var in
  "a")
    echo "is a"
    ;;
  "b"|"c")
    echo "is b or c"
    ;;
  *)
    echo "other"
    ;;
esac
```
