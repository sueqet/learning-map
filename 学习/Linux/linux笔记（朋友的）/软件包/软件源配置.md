# 软件源配置

## repo 文件格式

软件源配置文件存放在 `/etc/yum.repos.d/`，每个 `.repo` 文件可定义一个或多个软件源。

```ini
[repo-id]                           # 软件源唯一标识
name=描述名称
baseurl=https://mirror.example.com/path/  # 软件源地址
enabled=1                           # 1 启用，0 禁用
gpgcheck=1                          # 1 校验 GPG 签名，0 跳过
gpgkey=https://mirror.example.com/RPM-GPG-KEY  # GPG 公钥地址
```

## Rocky Linux 配置 163 国内源

```shell
cd /etc/yum.repos.d
# 备份原有 repo 文件
for repo in rocky*.repo; do mv "$repo" "$repo.backup"; done

# 写入 163 镜像源
repos=(BaseOS AppStream extras)
version=9
url=https://mirrors.163.com
file=/etc/yum.repos.d/mirror.repo
rm -f ${file}
for repo in "${repos[@]}"; do
echo -e "[rocky-$repo]\nname=Rocky Linux \$releasever - $repo\nbaseurl=${url}/rocky/\$releasever/$repo/\$basearch/os/\nenabled=1\ngpgcheck=1\ngpgkey=${url}/rocky/RPM-GPG-KEY-Rocky-$version\n\n" >> ${file}
done
unset repos version url file

# 更新缓存
dnf makecache
```

还原备份（如需）：
```shell
for repo in *.repo.backup; do mv "$repo" "${repo%.backup}"; done
```
