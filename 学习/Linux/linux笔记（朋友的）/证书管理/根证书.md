# 根证书

## 系统根证书存储

- 默认路径：`/etc/ssl/certs/`（Linux）或 `/etc/pki/tls/certs/`（RHEL系）。
- 包含权威 CA（如 Let's Encrypt、DigiCert）的公钥证书。

## 信任自签证书

### Harbor

```shell
file_name=harbor-selfsigned.crt
com=core.harbor.domain
# 获取自签证书
openssl s_client -connect $com:443 -showcerts </dev/null 2>/dev/null | openssl x509 -outform PEM > $file_name
# 信任证书
content=$(cat $file_name)
echo -e "# $com\n$content" >> /etc/pki/ca-trust/extracted/pem/tls-ca-bundle.pem
unset file_name content com
```

测试：
```shell
curl -v https://core.harbor.domain
```
