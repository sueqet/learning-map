# 网络配置

## nmcli 配置静态 IP

NetworkManager 的命令行工具，适用于 CentOS/RHEL/Rocky 等使用 NetworkManager 的发行版。

```shell
# 查看网络连接
nmcli connection show
nmcli device status

# 配置静态 IP
nmcli connection modify <device-name> \
  connection.autoconnect yes \
  ipv4.method manual \
  ipv4.addresses 192.168.20.11/24 \
  ipv4.gateway 192.168.20.1 \
  ipv4.dns 192.168.20.1

# 应用配置
nmcli connection up <device-name>

# 改回 DHCP
nmcli connection modify <device-name> ipv4.method auto
nmcli connection up <device-name>
```

## 两台主机直连共享网络

适用场景：网线直连两台电脑，借助一台电脑的 VPN 让另一台访问外网。

**有 VPN 的主机**：在网络设置中将 VPN 网卡的流量共享给以太网网卡，并设置以太网的网段和网关地址。

**另一台主机**：配置静态 IP，网关指向有 VPN 的主机：

```shell
nmcli connection modify <device-name> \
  connection.autoconnect yes \
  ipv4.method manual \
  ipv4.addresses 192.168.20.11/24 \
  ipv4.gateway 192.168.20.1 \
  ipv4.dns 192.168.20.1

nmcli connection up <device-name>
```
