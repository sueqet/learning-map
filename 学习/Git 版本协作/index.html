📖 使用说明

  • 点击知识点后的「去学习 →」或标题，进入对应详解页。
  • 勾选左侧方框即标记学会，进度保存在本机浏览器（localStorage），刷新/关闭不丢。
  • 详解页末尾有「本节考核」，做完可回到大纲在 index.html 打勾。
  • 建议每个知识点都动手敲一遍命令，再做题巩固。
