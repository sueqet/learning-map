# Git 版本协作 学习区

> **Git** 是版本控制工具，用来记录代码每次改动、多人协作不冲突、方便回滚；**GitHub/GitLab** 是托管平台。几乎所有开发岗位都用它，且**学习成本极低**——属于“随手就会、但人人必备”的技能。

## 主入口：交互式学习大纲

用浏览器打开 **`index.html`** 开始学习：

- **10 个知识点**，从「安装配置」到「团队协作工作流」循序渐进。
- **可打勾记录进度**：学会一个勾一个，进度保存到本机浏览器（localStorage），刷新不丢。
- **可跳转**：每个知识点点「去学习 →」或标题，进入对应的**详解网页**。
- 在大纲或任意详解页勾选「已学会」，**进度互相同步**。

## 每个详解网页包含

- **本节学习目标**：可验证的「学完后你能…」。
- **学习内容**：命令讲解（附可复制示例）、概念对照表、Mermaid 图解、易错点提示。
- **本节考核 · 练习**：选择答案提交自动判分，含解析与「面试延伸」题。
- **进阶挑战**：需要动手或思考的延伸任务。
- **「我已学会本节」**：一键标记，与大纲进度同步。

## 交互式分支模拟器

- 文件：**`sim-branches.html`**，也可从 `index.html` 的「🛠 交互式分支模拟器」按钮、或「04 分支与切换」页顶部进入。
- 用按钮模拟 `commit` / `branch` / `switch` / `merge` / `delete`，提交图（SVG）实时更新，并给出 fast-forward、三方合并等反馈。
- 支持撤销上一步、一键「示例：分支+合并」、重置；纯前端、单文件，离线可用。

## 如何维护

- 新增/修改知识点：改 `index.html` 的 `MODULES` 数组，再复制 `_template.html` 创建对应的 `NN-slug.html`。
- 详解页只改 `<script>` 里的 `CONFIG` 与 `QUZ` 以及正文；**不要改动 `_template.html` 的 `<style>`、进度同步逻辑与答题引擎**，保证全站一致。

## 学习建议

按「单机基础 → 分支合并 → 远程协作 → 进阶整理 → 团队实战」顺序推进；每个知识点都**动手敲一遍命令**，再做题巩固。可自己建一个练习仓库实操，再模拟一次多人协作（分支、合并、冲突、PR）。

> 与网页配套：属于通用基本功，趁早会，不占太多时间。
