Git 分支模拟器

不动真实仓库，动手体验 commit / branch / checkout / merge 如何让提交图流动。分支是一条指向某个提交的可移动指针，HEAD 指向当前所在分支——在这里把这个模型玩明白。

💡 小提示：默认从 main 上手。试着「新建分支 → 切过去提交几下 → 切回 main → 合并」，观察快进合并和三方合并的区别。

对照要点：branch 只是给当前提交贴个标签；fast-forward 是直接把当前分支移到对方提交；当两边都有新提交时，才会出现三方合并（merge commit，两个父节点）。

🎮 玩法建议

  1. 在 main 上点几次「提交」，建立主历史。
  2. 「新建分支」输入 feature1，再「切换」到它，提交两三次（会产生分叉）。
  3. 「切换」回 main，再提交一次（让两边都有新提交）。
  4. 「合并」feature1 到 main——此时会出现一个有两个父节点的合并提交。
  5. 再试「重置」，这次只新建分支后立即合并——会看到 fast-forward（不产生合并提交）。
