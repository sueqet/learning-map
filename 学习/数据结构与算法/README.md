# 数据结构与算法（DSA）学习区

> **DSA = Data Structures and Algorithms**。几乎所有计算机技术岗的笔试/面试必考，是「能不能过简历+技术面」的通用敲门砖。

## 主入口：交互式学习大纲

用浏览器打开 **`index.html`** 开始学习：

- **可交互勾选进度**：每个知识点一个方框，学完打勾，进度自动保存到本机浏览器（localStorage），刷新不丢。
- **可搜索**：按知识点 / 模块关键词过滤。
- **可跳转**：每个知识点点「去学习 →」跳到对应的**详解网页**。
- 大纲按 **基础篇 → 数据结构篇 → 算法思想篇** 三阶段组织，共 17 个模块、约 100 个知识点。

## 每个详解网页包含

- **本节学习目标**：可验证、可考核的「学完你能…」。
- **知识点讲解**：定义与思想、示例代码、复杂度、易错点。
- **本节考核 · 答题**：选择正确答案提交，自动判分与解析（含「面试延伸」题）。
- **进阶挑战**：需要独立思考的延伸题目。
- **「我已掌握本节」**：本页可一键标记掌握（保存在本机浏览器）；大纲里每个知识点的**打勾**则是独立记录，学完回到大纲再勾一下即可。

## 如何维护

- 想**新增/修改知识点**：改 `index.html` 里的 `MODULES` 数组，再在 `content/` 新建或编辑对应详解页。
- 详情页只改 `<script>` 里的 `CONFIG` 与 `QUZ`，以及正文；**不要改动 `_template.html` 的 `<style>` 与答题引擎**，以保证所有页面风格与功能一致。

## 学习建议

先会一门语言（建议 Python 或 C++），按「基础 → 数据结构 → 算法思想」推进；核心是先啃懂**复杂度分析**与常用结构，再攻**排序、搜索、动态规划**。每个模块学完→做题→在详解页考核→回到大纲打勾。
