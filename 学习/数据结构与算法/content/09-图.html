MODULE 09 · 数据结构与算法

图

图（Graph）是最贴近现实关系的数据结构：社交网络、地图导航、课程依赖、任务调度都能建模成图。本节你将掌握图的存储、DFS/BFS 遍历、最短路径、最小生成树、拓扑排序与连通性，并读懂常见面试/笔试背后的算法本质。

✓本节学习目标

  • 学完后你能说清图的基本术语：有向/无向、出度/入度、路径/环、连通/权，并会用握手定理论证度数。
  • 学完后你能判断何时用邻接矩阵、何时用邻接表、何时用链式前向星，并比较它们的空间与操作复杂度。
  • 学完后你能手写 DFS（去重）与 BFS（队列 + visited），并解释 BFS「层数」的距离语义。
  • 学完后你能实现 Dijkstra 的小顶堆优化版本并说明其正确性前提与为何不能处理负权。
  • 学完后你能写出 Prim（加点）与 Kruskal（加边 + 并查集）、Floyd（DP）、Bellman-Ford（负权），以及 Kahn/DFS 拓扑排序判环。

01图的定义与术语
从「关系」出发理解图

graph-basic图的定义与术语有向 / 无向、度、连通、权

图（Graph）由顶点集 V（Vertex）和边集 E（Edge）构成，记作 G = (V, E)。它比树更自由：树是「无环连通」的特例，而图允许环、允许孤立点。建模时，顶点是对象（人、城市、课程），边是关系（好友、道路、依赖）。

  • 有向图 / 无向图：无向图的边 (u,v) 不分方向；有向图用 u→v 表示，方向有意义（如「A 依赖 B」「车流单向」）。
  • 度：无向图顶点度数 = 关联的边数；有向图分入度（指向它的边数）与出度（它发出的边数）。
  • 路径 / 环：路径是「首尾相接的顶点序列」；若路径起点与终点相同则成环（cycle）。
  • 权值（Weight）：边上的开销/距离/成本，带权图称「加权图」，是 Dijkstra、最小生成树的舞台。
  • 连通：无向图任意两点都有路径则连通；连通分量 = 极大连通子图；有向图对应强连通（任意两点互相可达）。
  • 握手定理：无向图所有顶点度数之和 = 2|E|（每条边贡献 2 度）；有向图入度和 = 出度和 = |E|。
graph_basic.py
# 用 Python 表示一个简单图，并验证握手定理
# 邻接表：键 node -> 邻接节点集合（无向）
graph = {
    'A': {'B', 'C'},
    'B': {'A', 'D'},
    'C': {'A', 'D'},
    'D': {'B', 'C'},
}
# 顶点数与边数
V = len(graph)
E = sum(len(neigh) for neigh in graph.values()) // 2   # 无向：每个边被数两次
print("顶点", V, "边", E)

# 验证握手定理：所有顶点度数之和 == 2*E
deg_sum = sum(len(neigh) for neigh in graph.values())
assert deg_sum == 2 * E, "握手定理成立：度数之和 = 2*边数"
print("度数之和 =", deg_sum, "== 2E =", 2 * E)

# 有向图：分别统计入度/出度
edges = [('A','B'), ('B','C'), ('C','A'), ('A','C')]  # 有向边
indeg, outdeg = {}, {}
for _u, _v in edges:
    outdeg[_u] = outdeg.get(_u, 0) + 1      # 出度 +1
    indeg[_v] = indeg.get(_v, 0) + 1        # 入度 +1
print("入度和", sum(indeg.values()), "出度和", sum(outdeg.values()), "== |E|", len(edges))
★

核心要点：图三要素是「顶点 + 边 +（可选）权」。做图算法题第一步永远是明确建图方式（有向/无向、是否带权、顶点编号从 0 还是 1 开始），这决定了后面所有细节，也是面试时最容易踩的坑。

!

易错点：无向图加边要「双向」，即 g[u] 和 g[v] 都要记录；漏掉一条会导致遍历/最短路全部出错。另外顶点编号若从 1 开始，记得把数组开成 n+1 的大小。

核心要点：稠密图（E≈V²）用邻接矩阵，稀疏图（E≈V）用邻接表。最短路、生成树的通用做法是邻接表 + 堆/并查集；只有题目需要 O(1) 判边（如判重边、floyd 的 DP 表）时矩阵才更合适。

graph-traverse图的遍历 DFS 与 BFSvisited 去重 + 距离语义

深度优先搜索（DFS，Depth-First Search）一路走到底再回溯；广度优先搜索（BFS，Breadth-First Search）按层向外扩散。两者都要visited 标记防止重复访问——因为图有环，不像树那样天然无环。

  • DFS：递归/栈，适合求连通分量、路径、染色、拓扑序（后序）。
  • BFS：队列，层层扩展，层数 = 从起点经过的边数，因此在「无权图」上 BFS 可求最短路径。
  • visited 时机：BFS 在入队时就应该标记，否则同层重复入队会指数膨胀；DFS 在进入时标记。
graph_traverse.py
from collections import deque
g = defaultdict(list)
for u,v in [(0,1),(0,2),(1,3),(2,3),(3,4)]:
    g[u].append(v); g[v].append(u)    # 无向

# ---------- DFS（递归 + visited 去重）----------
def dfs(u, visited=None):
    if visited is None: visited = set()
    visited.add(u)
    print(u, end=' ')
    for v in g[u]:
        if v not in visited:          # 关键：跳过已访问，防成环死循环
            dfs(v, visited)
print("DFS:"); dfs(0)

# ---------- BFS（队列 + 层数 = 最短边数）----------
def bfs(start):
    dist = {start: 0}
    q = deque([start])
    while q:
        u = q.popleft()
        for v in g[u]:
            if v not in dist:         # 首次遇到即最短（无权图）
                dist[v] = dist[u] + 1  # 距离 = 层数 = 经过的边数
                q.append(v)
    return dist
print("\nBFS dist:", bfs(0))          # 如 0->4 距离为 2（0-2-4 或 0-1-3-4 最短边数 2）
★

核心要点：BFS 在无权图/单位权图上，首次弹出某节点的「层数」就是最短路径长度（LeetCode 547/695/200、127 单词接龙）。带权图必须用 Dijkstra，BFS 不再成立——这是最常被问的陷阱。

!?

易错点：（1）BFS 一定要在入队时标记 visited，否则同一节点被反复入队导致 O(2^V) 甚至超时；（2）DFS 要用「if v not in visited」判断后再递归，别先递归再判断；（3）「visited 于弹出时标记」是按层处理某些问题的写法，但会多走重复节点，务必区分。

02最短路径
从贪心到动态规划

graph-dijkstra最短路径 · Dijkstra（小顶堆优化）O(E log V)，不能处理负权

Dijkstra（迪杰斯特拉）是典型的贪心算法：维护一个 dist[]（起点到各点的当前最短距离），每次从未确定集合里选「当前距离最小」的顶点 u 设为确定，再用 u 松弛它的出边。用小顶堆取代线性扫描即可把「找最小」从 O(V) 优化到 O(log V)。

★

正确性前提：所有边权 非负。因为一旦某个顶点从堆里弹出（出堆即确定），它将不再被更新；若存在负权边，后续可能找到更短路径，从而破坏「出堆即最优」的前提。贪心能成立的内在原因是——距离当前最短的顶点，之后不可能通过「加一条非负边」变得更短。

dijkstra.py
import heapq
INF = float('inf')
def dijkstra(g, start, n):
    dist = [INF]*n
    dist[start] = 0
    pq = [(0, start)]                 # (当前距离, 顶点) 小顶堆
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:               # 关键：跳过已过时的堆节点
            continue
        for v, w in g[u]:             # 松弛 u 的所有出边
            nd = d + w
            if nd < dist[v]:
                dist[v] = nd
                heapq.heappush(pq, (nd, v))
    return dist

# 建图：邻接表，带权
g = defaultdict(list)
for u,v,w in [(0,1,4),(0,2,1),(2,1,2),(1,3,1),(2,3,5)]:
    g[u].append((v,w)); g[v].append((u,w))
print(dijkstra(g, 0, 4))   # [0, 3, 1, 4]：0->2(1)->1(2)->3(1) = 4
!

易错点：（1）堆中会残留「过时节点」，一定要判断 if d > dist[u]: continue，否则结果错误；（2）Dijkstra 是单源最短路径，只能求「一个起点」到其余点；（3）C++ 用 priority_queue + pair<int,int>，注意默认是大顶堆，要重载为小顶堆（或入负数）。

graph-other最短路径 · Floyd 与 Bellman-Ford（负权）动态规划 + 多源/负权

Floyd（弗洛伊德）求所有点对最短路径，用动态规划做中转松弛：外层 k 表示「允许用前 k 个点作中转」。递推式 dp[i][j] = min(dp[i][j], dp[i][k] + dp[k][j])，三维压成二维原地更新。它天然支持负权边（但不能有负权环）。Bellman-Ford 是单源最短路，能处理负权并检测负环：松弛 n-1 轮后若还能再松弛，说明存在负环。

floyd_bellman.py
INF = float('inf')

# ---------- Floyd：所有点对最短路（DP）----------
def floyd(g, n):                        # g 为邻接矩阵
    dist = [[INF]*n for _ in range(n)]
    for i in range(n):
        dist[i][i] = 0
    for u,v,w in g:                     # 初始边
        dist[u][v] = w                  # 有向
    for k in range(n):                  # 外层：允许以 k 为中转
        for i in range(n):
            for j in range(n):
                if dist[i][k] + dist[k][j] < dist[i][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]   # 松弛
    return dist

# ---------- Bellman-Ford：单源，含负权，判负环 ----------
def bellman_ford(edges, start, n):
    dist = [INF]*n
    dist[start] = 0
    for _ in range(n-1):                # 最多松弛 n-1 轮
        for u,v,w in edges:
            if dist[u] != INF and dist[u]+w < dist[v]:
                dist[v] = dist[u]+w
    for u,v,w in edges:                 # 再松弛一轮
        if dist[u] != INF and dist[u]+w < dist[v]:
            return None                 # 仍能更新 => 存在负权环
    return dist

edges = [(0,1,-2),(1,2,3),(0,2,5)]
print("Bellman-Ford:", bellman_ford(edges, 0, 3))   # [0,-2,1]
# SPFA 是 Bellman-Ford 的队列优化，平均更快但最坏仍可能退化，需格外小心。
★

核心要点：看到「所有点对最短路」或顶点数小（V≤几百）→ Floyd（O(V³)）；看到「可能出现负权边」→ Bellman-Ford / SPFA（O(VE)）；边权非负 → Dijkstra（O(E log V)，最快）。分清「单源 vs 多源」「负权 vs 非负」是选算法的第一原则。

!?

易错点：（1）Floyd 外层循环 k 必须放最外层，若把 i/j 放外层会破坏正确性（因为中转点要「从小到大逐步引入」）；（2）Floyd 用邻接矩阵，初始化对角为 0、无边为 INF；（3）Bellman-Ford 判负环必须在第 n 轮再检查能否更新，只有一轮判定不够。

graph-mst最小生成树 · Prim / Kruskal加点 + 加边 + 并查集

最小生成树（MST，Minimum Spanning Tree）在连通带权无向图中选 n-1 条边使总权最小（结果必须是树：连通且无环）。两种经典思路：Prim 是「加点」——从一个点出发，每次把「连接已生成树与外部的最小边」连紧；Kruskal 是「加边」——按边权从小到大选边，用并查集判断是否会成环。

mst.py
INF = float('inf')

# ---------- Prim（加点，O(V²)，可用堆优化到 O(E log V)）----------
def prim(g, n):
    in_mst = [False]*n
    d = [INF]*n
    d[0] = 0
    total = 0
    for _ in range(n):
        u = -1
        for i in range(n):                 # 选未入树且距离最小的点
            if not in_mst[i] and (u==-1 or d[i] < d[u]):
                u = i
        in_mst[u] = True
        total += d[u]
        for v,w in g[u]:                   # 松弛：到树外的最近边
            if not in_mst[v] and w < d[v]:
                d[v] = w
    return total

# ---------- Kruskal（加边 + 并查集判环，O(E log E)）----------
parent = list(range(6)); rank = [0]*6
def find(x):
    while parent[x]!=x:
        parent[x] = parent[parent[x]]      # 路径压缩
        x = parent[x]
    return x
def union(a,b):
    ra,rb = find(a),find(b)
    if ra==rb: return False
    if rank[ra]
★

核心要点：Prim 适合稠密图（顶点多、边多，O(V²) 或堆优化）；Kruskal 适合稀疏图（边少，O(E log E)）。两者都基于「切分定理」：任何时刻，连接已选集合与外部的最小边必然属于某棵 MST——这是两者正确性的共同根基。

!

易错点：（1）MST 应用于无向带权连通图，有向图不适用；（2）Kruskal 选边前要排序，union 返回 False 说明成环，必须跳过；（3）Prim 的 d[] 是「到树的最短边权」，不是到起点的路径距离，别和 Dijkstra 搞混——两者代码很像，但语义完全不同。

graph-topo拓扑排序与判环Kahn / DFS，判环

拓扑排序（Topological Sort）只针对有向无环图（DAG），给出一个线性序列使每条边 u→v 中 u 都在 v 之前。它天然对应「依赖关系」：先修课程、任务调度、编译依赖。若无法生成完整序列（剩下节点入度不为 0 / DFS 发现后向边），则说明存在环。

  • Kahn 法：不断把「入度为 0」的顶点入队、删除，并更新邻居入度。最终序列长度 = 顶点数则无环。
  • DFS 法：用三色状态（0 未访问 / 1 访问中 / 2 已结束）。回溯时遇到「访问中」的节点 → 存在环。
topo.py
from collections import deque
# ---------- Kahn 法（入度为 0 逐点消除）----------
def topo_kahn(g, indeg, n):
    q = deque([i for i in range(n) if indeg[i]==0])
    order = []
    while q:
        u = q.popleft()
        order.append(u)
        for v in g[u]:
            indeg[v] -= 1                 # 删除 u 后，邻居入度 -1
            if indeg[v] == 0:
                q.append(v)
    return order if len(order) == n else None   # None => 有环

# ---------- DFS 三色判环（LeetCode 207 课程表核心）----------
state = [0]*n    # 0 未访问 / 1 访问中 / 2 已完成
def has_cycle(u):
    state[u] = 1                        # 进入递归栈
    for v in g[u]:
        if state[v] == 1: return True   # 发现"访问中"节点 => 后向边 => 有环
        if state[v] == 0 and has_cycle(v): return True
    state[u] = 2                        # 离开，标记完成
    return False
def is_dag():
    for i in range(n):
        if state[i]==0 and has_cycle(i): return False
    return True   # 无环（DAG）
★

核心要点：拓扑排序只对 DAG 有意义；「序列长度 < n → 有环」是 Kahn 判环的黄金结论（LeetCode 207 / 210 课程表）。DFS 三色判环里「访问中（state=1）状态是检测环的关键——它能捕捉到同一条递归路径上的"回指边"，而简单的 visited 布尔标记做不到。

!?

易错点：（1）Kahn 要对原点计算入度，不要把「出度为 0」当入队条件；（2）拓扑排序不唯一（可能存在多个合法序列，按字典序最小需用优先队列）；（3）无环判定要用序列长度，不能只看队列是否为空；（4）DFS 判环三色中「访问中」与「已完成」必须区分，否则有环时可能误判。

04连通性进阶
选学：并查集、桥、强连通

graph-conn连通性：并查集、桥与强连通（选学）union-find / bridge / SCC

连通性问题是图的高级主题。并查集（Union-Find / DSU）用「树 + 路径压缩 + 按秩合并」维护等价类，近乎 O(α(n))，擅长判断「两点是否连通」「合并集合」；割边/桥与强连通分量（SCC）常用 Tarjan 算法，借助 DFS 的 dfn[]（发现时间）与 low[]（能回溯到的最早祖先）判定。

unionfind.py
# ---------- 并查集：路径压缩 + 按秩合并 ----------
parent = list(range(5)); rank = [0]*5
def find(x):
    if parent[x] != x:                  # 递归路径压缩
        parent[x] = find(parent[x])
    return parent[x]
def union(a, b):
    ra, rb = find(a), find(b)
    if ra == rb: return False           # 已经在同一集合
    if rank[ra] < rank[rb]: ra, rb = rb, ra
    parent[rb] = ra
    if rank[ra] == rank[rb]: rank[ra] += 1
    return True
def connected(a, b):
    return find(a) == find(b)
# 常用于：求连通分量个数 / 判断是否成环 / 最小生成树 Kruskal

# ---------- Tarjan 求强连通分量（SCC）思路 ----------
# dfn[u] = 首次访问时间；low[u] = u 及其子树能回溯到的最早 dfn
# 当 low[u] == dfn[u] 时，栈中 u 之上的所有节点构成一个强连通分量。
★

核心要点：并查集是「加边 + 查连通」的最强武器，适合动态合并（Kruskal、LeetCode 547 省份数量、冗余连接 684）。桥 / 割点与 SCC 需要 Tarjan，核心是 low[] 的递推：low[u] = min(low[u], low[v])（树边）与 min(low[u], dfn[v])（回边）。

!

易错点：（1）并查集若不做路径压缩，最坏会退化成链，复杂度升到 O(n)；（2）Tarjan 判断「桥」条件为 low[v] > dfn[u]，是严格大于；判断割点分「根节点（需 ≥2 个子树）」与「非根（low[v] ≥ dfn[u]）」两种情况，极易混淆；（3）SCC 只对有向图定义，无向图用「连通分量」。
