17.1双指针与滑动窗口 —— 把 O(n²) 压成 O(n)

模板双指针（Two Pointers）· 对撞 / 快慢对撞有序 · 快慢链表

双指针（Two Pointers）指在数组 / 链表上同时维护两个「下标或节点指针」，让它们按某种规则协同移动，从而把两层循环的暴力 O(n²) 压缩到 O(n)。它的本质是利用数据的有序性或单调性，每次移动都成批地排除掉不可能的情况。按移动方向分两类：

  • 对撞指针（左右指针，collision pointer）：一个在头、一个在尾，向中间靠拢。用于「有序数组」上的查找、判断回文、求两数之和、接雨水等。
  • 快慢指针（fast & slow）：一个每次走 1 步，一个每次走 2 步。用于单链表找中点、判断是否有环、找环入口、找倒数第 k 个节点。
two_pointers.py
# —— 对撞指针：有序数组两数之和（LeetCode 167）——
def two_sum_sorted(nums, target):
    """数组已升序；返回两数之和为 target 的下标（1-based）。"""
    left, right = 0, len(nums) - 1
    while left < right:                    # 两端向中间靠拢
        s = nums[left] + nums[right]
        if s == target:
            return [left + 1, right + 1]
        elif s < target:                    # 和太小 → 右移左指针，让和变大
            left += 1
        else:                               # 和太大 → 左移右指针，让和变小
            right -= 1
    return []

# —— 快慢指针：单链表找中间节点（LeetCode 876）——
def middle_node(head):
    slow = fast = head
    while fast and fast.next:               # fast 每次 2 步，slow 每次 1 步
        slow = slow.next
        fast = fast.next.next
    return slow                             # fast 到底时 slow 停在中点
★

核心要点：双指针能提速的前提是数据「有序或单调」，这样才能有依据地决定哪个指针往哪动；快慢指针则利用了「快者一圈比慢者多走一步」的位移差。

!

易错点：对撞指针的循环边界——就「两数之和」而言可用 left < right；若题目允许左右指向同一元素则用 left <= right，先看清题意。快慢指针里 fast.next 必须先判空再访问 fast.next.next，否则对奇数/偶数长度链表会空指针报错。

时间（对撞）
O(n)
时间（快慢）
O(n)
空间
O(1)
适用
有序数组 / 链表

模板滑动窗口（Sliding Window）连续子数组 / 子串 · 左右指针

滑动窗口（Sliding Window）专门处理「连续子数组 / 子串」类问题：维护一个窗口 [left, right]，右端负责扩张（加入新元素），左端负责在窗口「不满足条件」时收缩（移出元素）。核心不变量是：窗口内始终满足题设约束，尽量让窗口最短或最长。

  • 适用特征：题干出现「连续」「子串 / 子数组」「最长 / 最短 / 恰好」等字眼。
  • 三种状态：固定长度窗口（定长，如找到所有异位词）、可变长度窗口（最长 / 最短，如无重复子串、最短覆盖子串）。
sliding_window.py
# —— 滑动窗口通用模板：维护 [left, right] 上的状态 ——
def sliding_window(s):
    left = 0
    for right, item in enumerate(s):        # ① 右端扩张，把 s[right] 纳入窗口
        add(item, right)                    #   更新窗口内计数/状态
        while not valid(left, right):       # ② 窗口不再满足条件 → 收缩左端
            remove(s[left])                 #   移出 s[left] 并更新状态
            left += 1                       #   左端只进不退（单调）
        update_answer(left, right)          # ③ 此时窗口合法，更新答案
    return answer

# —— 例题：最长无重复字符子串（LeetCode 3，可变长窗口）——
def length_of_longest_substring(s):
    last = {}                               # 字符 -> 它最近一次出现的位置
    left = 0
    best = 0
    for right, ch in enumerate(s):
        if ch in last and last[ch] >= left:   # 该字符在窗口内重复了
            left = last[ch] + 1             # 左端跳到重复字符之后，保证窗口无重复
        last[ch] = right                    # 记录/更新该字符的位置
        best = max(best, right - left + 1)  # 当前窗口长度
    return best
★

核心要点：right 从 0 单调走到 n-1，left 也只会单调右移，因此每个元素至多进入窗口一次、离开窗口一次，整体 O(n)——这就是滑动窗口比暴力 O(n²) 快的原因。

!

易错点：（1）收缩要用 while 而非 if——只缩一次窗口可能仍不合法；（2）收缩时一定要「先移出并更新状态，再 left += 1」的顺序，否则状态与窗口边界错位；（3）区分「最长无重复」用 last[ch] >= left 判断重复，而「最短覆盖子串」是用满足条件的字符计数来判断。

时间
O(n)
空间
O(m)
适用
连续子序列

17.2前缀和与单调结构 —— 预处理与空间换时间

模板前缀和（Prefix Sum）与差分（Difference）区间和 · 区间统一加减

前缀和（Prefix Sum / 前缀数组）是预处理技巧：pre[i] 表示原数组前 i 个元素的和，构造好后可 O(1) 求任意区间 [l, r] 的和。它用一次 O(n) 的预处理换取了频繁查询的 O(1)。差分（Difference Array）是前缀和的「逆运算」，适合「多次对区间统一加减、最后才知道每个位置的最终值」的场景。

  • 前缀和适用：频繁区间求和、连续子数组和为 K（配合哈希表，LeetCode 560）。
  • 差分适用：多次区间加 / 减，最后一次性还原（LeetCode 370、1094 等区间调度题）。
prefix_diff.py
# —— 前缀和：O(n) 预处理，O(1) 求 [l, r] 区间和（下标 0 基）——
def build_prefix(a):
    n = len(a)
    pre = [0] * (n + 1)                     # pre[i] = a[0] + ... + a[i-1]
    for i in range(n):
        pre[i + 1] = pre[i] + a[i]
    return pre

def range_sum(pre, l, r):
    return pre[r + 1] - pre[l]              # 前 r+1 个 - 前 l 个

# 连续子数组和为 K 的个数（LeetCode 560）：前缀和 + 哈希
def subarray_sum_k(a, k):
    from collections import defaultdict
    cnt = defaultdict(int); cnt[0] = 1      # 前缀和正好等于 0 的情况
    ans = cur = 0
    for x in a:
        cur += x                            # 当前前缀和
        ans += cnt[cur - k]                 # 出现多少次 cur-k 就有多少段
        cnt[cur] += 1
    return ans

# —— 差分：对区间 [l, r] 统一加 val，最后一次性还原 ——
def diff_array(n, ops):
    diff = [0] * (n + 1)                    # 多开一格，防止 r+1 越界
    for l, r, val in ops:
        diff[l] += val
        diff[r + 1] -= val                  # 在 r+1 处撤销，保证只影响 [l, r]
    res, cur = [], 0
    for i in range(n):
        cur += diff[i]                      # 走一遍前缀和即可还原
        res.append(cur)
    return res
★

核心要点：前缀和是「预处理 + O(1) 查询」的经典空间换时间；差分恰是它的逆，专门应对「区间统一操作、点最后取值」——差分数组做一次前缀和就是恢复后的原数组。

!

易错点：（1）前缀和数组长度是 n+1，pre[i] 表示「前 i 个元素和」，求 [l, r] 必须用 pre[r+1] - pre[l]，下标差一位是最高频 bug；（2）差分数组要开到 n+1，因为 r+1 可能等于 n，越界会悄悄算错；（3）前缀和默认从 pre[0]=0 开始，处理「整段从 0 开头」的子数组时别漏掉 cnt[0]。

时间（前缀和构建）
O(n)
时间（单次查询）
O(1)
时间（差分）
O(n + k)
空间
O(n)

速览单调栈 / 单调队列（Monotonic Stack / Queue）一句话回顾 · 出栈/出队结算

单调栈（Monotonic Stack）栈内元素保持单调（递增或递减），多用「下一个更大 / 更小元素」；单调队列（Monotonic Queue）队内元素单调，配合滑动窗口求窗口内最值。两者都靠「把逆序 / 无用的旧元素及时扔掉」，从而让每个元素只进一次、出一次，摊到 O(n)。

  • 单调栈：答案通常在出栈的那一刻确定——当前元素把栈里「更小（或更大）」的旧元素顶掉时，它就是那个旧元素的答案。
  • 单调队列：队首即当前窗口最值，队尾负责维护单调性；注意队列里存的是下标，以便判断是否滑出了窗口。
monotonic.py
from collections import deque

# —— 单调栈：每个元素的下一个更大元素（LeetCode 739）——
def next_greater(nums):
    n = len(nums)
    ans = [-1] * n
    st = []                                 # 存下标，维护从底到顶递减
    for i, x in enumerate(nums):
        while st and nums[st[-1]] < x:      # 栈顶比 x 小 → 被 x 顶出，答案此刻确定
            ans[st.pop()] = x
        st.append(i)
    return ans

# —— 单调队列：滑动窗口最大值（LeetCode 239）——
def max_sliding_window(nums, k):
    dq = deque()
    res = []
    for i, x in enumerate(nums):
        while dq and dq[0] <= i - k:        # 队首下标滑出了窗口，弹掉
            dq.popleft()
        while dq and nums[dq[-1]] <= x:     # 队尾不比 x 大就弹出，保持单调递减
            dq.pop()
        dq.append(i)
        if i >= k - 1:                      # 窗口已满，队首即窗口最大值
            res.append(nums[dq[0]])
    return res
★

核心要点：一句话回顾——单调栈在「出栈」时结算答案（下一个更大），单调队列在「队首」取最值（滑动窗口最值）。两者都是 O(n)，因为每个元素最多进出一次。

!

易错点：（1）弹栈比较方向容易写反——求「下一个更大」用 < / <= 弹出栈顶（越小越先被顶掉）；（2）单调队列一定存下标而非值，判过期用 dq[0] <= i - k，判单调用 nums[dq[-1]] <= x；（3）队列过期判断要在维护单调性之前，否则可能把本已过期的队首保留下来。

时间（单调栈）
O(n)
时间（单调队列）
O(n)
空间
O(n)
适用
最值 / 最近更大

17.3位运算与频率统计 —— 从「数」到「特征」

技巧位运算（Bit Operations）判奇偶 · 消1 · 异或 · 子集枚举

位运算（Bit Operations）直接操作二进制位，常数极小、无需开数组，适合「只出现一次」「找唯一 / 重复」「子集枚举」「判断 2 的幂」等题。掌握以下几条即可应付绝大多数面试题：

  • 判奇偶：x & 1 —— 最右位为 1 是奇数。
  • 消掉最后一个 1：x & (x - 1) —— 用于数 1 的个数、判断 2 的幂。
  • 取最后一个 1：x & (-x) —— 即 lowbit，用于树状数组等。
  • 异或（XOR）去重：x ^ x == 0、0 ^ x == x，成对的数异或会抵消。
  • 子集枚举：用 (1 << n) 遍历所有子集的位掩码（bitmask）。
  • 常用性质：左移 << 乘 2 的幂，右移 >> 整除 2；n & (n-1) 是否为 0 判断 2 的幂。
bit_ops.py
def is_odd(x):      return (x & 1) == 1     # 判奇偶
def lowbit(x):      return x & (-x)         # 取出最低位的那个 1
def clear_last(x):  return x & (x - 1)      # 消掉最低位的那个 1

def popcount(x):                            # 数二进制里 1 的个数（LC 191）
    c = 0
    while x:
        x &= x - 1                          # 每清一个 1 计数 +1
        c += 1
    return c

def is_pow2(x):     return x > 0 and (x & (x - 1)) == 0   # 2 的幂

def single_number(nums):                    # 只出现一次的数（LC 136）
    s = 0
    for v in nums:
        s ^= v                              # 成对的抵消，只剩落单的
    return s

def subsets(arr):                           # 子集枚举（LC 78）
    n = len(arr); out = []
    for mask in range(1 << n):             # 每个 bit 表示「选/不选」
        out.append([arr[i] for i in range(n) if (mask >> i) & 1])
    return out
★

核心要点：记住这三条就是地基——x & (x-1) 消最后一个 1、x & (-x) 取最后一个 1、x ^ x == 0。异或尤其适合「成对抵消、落单者留」的题型。

!

易错点：（1）位运算优先级低于比较与逻辑运算，写 (mask >> i) & 1 一定要加括号；（2）判断 2 的幂必须先判 x > 0，因为 0 是特例（0 可被 & (x-1) 除尽但不属于 2 的幂）；（3）`<< n` 超量级会溢出或非常慢（C++ 里用 1LL<<n，Python 大整数虽无碍但别枚举 2^30 级别的全子集）。

时间（单次）
O(1)
时间（异或去重）
O(n)
空间
O(1)
子集枚举
O(2^n)

模板频率统计（Frequency Count）与计数计数/字典 → 特征表示

频率统计的核心是：用计数器（数组或字典）记录元素 / 字符出现的次数，再把它转成可比较的特征表示（例如把计数压成字符串），从而让「两串是否由相同字母构成」「两种结构是否同构」这类问题变成 O(1) 的特征比对。特征是「计数 → 映射」：字母异位词（anagram）、同构字符串（isomorphic）都是典型。

  • 范围小（如 26 个小写字母）用定长计数数组，最快。
  • 范围大 / 未知用字典 Counter，更通用。
  • 特征可以是「排序后的字符串」「计数拼接串（如 aabb）」「每类字符编号」等，视题目而定。
freq_count.py
from collections import Counter

# 字母异位词（anagram）：字母种类与个数相同（LC 242）
def is_anagram(s, t):
    return Counter(s) == Counter(t)         # 计数字典直接比较

# 特征表示：把计数压成一个唯一键，用于任意两串的「同构」比较
def normalize(s):
    cnt = [0] * 26
    for ch in s:
        cnt[ord(ch) - 97] += 1              # 仅限小写字母
    return "#".join(str(c) for c in cnt)    # 形如 "0#2#1#..." 的特征键

# 在 s 中找所有与 p 为字母异位词的起点（LC 438，固定长滑窗 + 计数）
def find_anagrams(s, p):
    need, have = Counter(p), Counter()
    k = len(p); left = 0; res = []
    for right, ch in enumerate(s):
        have[ch] += 1
        if right - left + 1 > k:            # 窗口比 p 长 → 收缩左端
            have[s[left]] -= 1
            if have[s[left]] == 0:
                del have[s[left]]           # 归零要删掉，否则无法与 need 比较
            left += 1
        if have == need:                    # 该窗口与 p 计数一致 → 异位词
            res.append(left)
    return res
★

核心要点：「计数 → 特征」是一招通用的降维套路：把「比较两个结构是否等价」转化为「比较两个由计数生成的特征是否相等」，常与滑动窗口配合使用以维持比较范围。

!

注意：用 Counter / 计数数组时要先确定字符范围（是否仅小写字母、是否含大写或数字）；用字典做窗口时，次数归零后要 del，因为 Counter({'a':0}) == Counter() 结果是 False（Python 会保留 0 计数参与比较），这个隐藏细节常让滑动窗口差一位。
延伸：同构字符串（LC 205）是把「每个字符首次出现位置」作为特征进行双向映射。

时间（判异位词）
O(n)
时间（找所有异位词）
O(|s| + |p|)
空间
O(1) / O(m)
适用
计数 / 同构 / 子串

核心要点：选择口诀——有序就双指针，连续子串用滑窗，区间和想前缀和，区间改想差分，最近更大用单调栈，窗口最值用单调队列，成对抵消用异或，判同构用计数。先判断数据是否有序、区间是否连续、是否需要「最近 / 最值」，基本就能锁定套路。

!

提醒：套路是起点不是终点。看清约束（是否连续、是否有序、数据范围）再套模板；同一道题常有多种解法（如两数之和可对撞也可哈希），面试时先问清需求再选最合适的一种并说明取舍。
