MODULE 06 · 数据结构与算法

查找 · 二分查找

二分查找（Binary Search）以每次砍半的代价，把一个看运气的问题变成一条可证明的 O(log n) 路径；掌握好「区间不变量」，从寻找一个数到寻找第一个 / 最后一个、再到「对答案二分」，都能一眼看穿。

✓本节学习目标

  • 学完后你能说明二分查找的三个前提（有序、可 O(1) 随机访问、可比较大小），并解释为什么链表上的二分退化为 O(n)。
  • 学完后你能讲清「左闭右闭 [l, r]」与「左闭右开 [l, r)」两套区间不变量，并把区间定义、循环条件、l/r 收缩三处写对。
  • 学完后你能熟练写出「第一个等于 / 最后一个等于 / 第一个 ≥（插入位置）/ 最后一个 ≤」四种变体模板。
  • 学完后你能把「对答案二分」模型套到单调性判定问题上，写出 check(x) 判定 + 二分答案的骨架。
  • 学完后你能一眼识别 off-by-one 与死循环，并给出铁律式的修复手段。
Pre-requisites · 前置知识

掌握一门编程语言的基本语法（变量、while/for 循环、函数、对象数组）；理解「数组是按下标访问的连续存储」这一事实；会简单分析 O(1)/O(n)/O(log n) 的时间复杂度；了解「有序数组」与「大小比较」。

知识点二分查找的基本思想与前提bs-basic · LeetCode 704

二分查找（Binary Search，又称折半查找）的核心思想只有一个：每一次比较都把待查区间砍掉一半。因为序列有序，若中间元素 a[mid] 比目标大，那么目标只可能出现在左半；若比目标小，只可能出现在右半——于是我们不需要"逐个看"，而是对数级地缩小搜索空间。

它之所以能成立，靠的是下面这三个前提，缺一不可：

  • 有序：序列必须能通过比较决定"往哪一半走"。无序序列无法从一次比较推断出该区间。
  • 可 O(1) 随机访问：能按下标瞬间拿到中间元素。数组是可以的，链表不行——取中点在链表上要遍历，复杂度就退化。
  • 可比较大小：元素之间必须能比出 <、=、>。
bs_basic.py
# LeetCode 704：二分查找。在升序数组 a 中找 target，返回下标，找不到返回 -1
def binary_search(a, target):
    l, r = 0, len(a) - 1      # 左闭右闭区间 [l, r]，r 是「最后一个有效下标」
    while l <= r:             # 区间非空才继续；l > r 说明已完全排除
        mid = l + (r - l) // 2   # 防 (l+r) 溢出的标准写法
        if a[mid] < target:
            l = mid + 1       # mid 已被排除，区间右移到 mid+1
        elif a[mid] > target:
            r = mid - 1       # mid 已被排除，区间左移到 mid-1
        else:
            return mid        # 恰好命中
    return -1                 # 区间耗尽仍未找到
★

核心要点：每比较一次，候选区间长度减半，因此从 n 到 1 只需约 log₂n 次比较——这就是 O(log n) 的来源。前提（有序 + 随机访问 + 可比较）是面试常考的第一问。

!

易错点：很多同学以为二分"对任意数组都 O(log n)"。错！二分对链表取中点需要遍历，等价于 O(n) 渐进复杂度，并不比线性查找更省。另外"有序"不是"必须是严格升序"，非递减（允许相等）也 OK，但变体写法要看「等于」处理。

时间
O(log n)
空间
O(1)
前提
有序 + 随机访问

知识点区间不变量与边界写法bs-boundary · 左闭右闭 vs 左闭右开

二分最容易翻车的不是"有没有想到用二分"，而是边界到底怎么收。答案藏在区间不变量（Loop Invariant）里——「当前未排除的候选元素范围」。只要把「区间定义 / 循环条件 / l、r 收缩」三处写成同一套不变量，代码就自动自洽；哪一处偷换了一套，就会死循环或越界。

不变量区间定义循环条件命中后收缩未找到时结束
左闭右闭[l, r]，0≤l≤r≤n-1l <= rl = mid+1 / r = mid-1l == r+1
左闭右开[l, r)，0≤l<r≤nl < rl = mid+1 / r = midl == r

为什么循环条件不一样？左闭右闭的区间里 l == r 时仍有一个元素没排除，必须继续，所以是 l <= r；而左闭右开的区间里 l == r 时区间已经为空，所以是 l < r。右开区间里 r = mid 而不是 mid-1，正是因为 r 本身是"开"的、不含元素，把上界挪到 mid 即可。

bs_boundary.py
# 两种等价写法，实现同一功能（找 target 下标）。务必成对使用！
def bs_closed(a, target):          # 左闭右闭 [l, r]
    l, r = 0, len(a) - 1
    while l <= r:                  # 区间非空
        mid = l + (r - l) // 2
        if a[mid] < target:  l = mid + 1
        elif a[mid] > target: r = mid - 1
        else: return mid
    return -1

def bs_open(a, target):            # 左闭右开 [l, r)
    l, r = 0, len(a)               # r 是「上限」，取 len(a)（不含）
    while l < r:                   # 区间非空
        mid = l + (r - l) // 2
        if a[mid] < target:  l = mid + 1
        else:                r = mid   # 开区间：r 用 mid 即可
    return l if l < len(a) and a[l] == target else -1
★

核心要点：面试时讲清"我采用的是左闭右闭区间"，然后把 l<=r、l=mid+1/r=mid-1 三件套讲齐，考官就信你了。中点计算统一写 mid = l + (r-l)//2，避免 (l+r)//2 在 C/C++/Java int 相加时溢出。

⚠

常见错配：把「右闭区间配了 l<r」或「右开区间配了 r=mid-1」，都会漏掉元素或死循环。记住铁律：右闭则 -1，右开则不减；左闭右闭用 l<=r，左闭右开用 l<r。

时间
O(log n)
空间
O(1)
适用
有序数组查找

知识点变体：第一个 / 最后一个 / 插入位置bs-variants · LeetCode 34 / 35

基础二分的"找到就返回"面对重复元素时不够用——题目经常要我们找到目标值的第一个位置或最后一个位置（数组里可能有多个相同值），或返回目标应插入的位置。诀窍只有一个：命中后不要立即返回，继续收紧边界，直到把一边的重复项也排掉。你只需要回答一个设计问题：相等时往哪边走？

  • 求最后一个/第一个：把比较符号从 < 换成 <=，就决定"等于时是往左收（求第一个）还是往右收（求最后一个）"。
  • 插入位置（first ≥，即 C++ 的 lower_bound）：找到"第一个 ≥ target 的位置"，找不到就返回数组长度。这就是 LeetCode 35。
  • 第一个 > target（upper_bound）：把大于等于收紧成严格大于。
bs_variants.py
# 用左闭右开 [l, r) 统一写四个变体，只改「相等时的走向」。
# find_first: 第一个 == target（未找到返回 -1）
def find_first(a, target):
    l, r = 0, len(a)
    while l < r:
        mid = (l + r) // 2
        if a[mid] < target: l = mid + 1     # 严格小于才右移 → 找到"第一个 >=t"边界
        else:              r = mid          # 相等也左收
    return l if l < len(a) and a[l] == target else -1   # 返回值即候选位置

# find_last: 最后一个 == target
def find_last(a, target):
    l, r = 0, len(a)
    while l < r:
        mid = (l + r) // 2
        if a[mid] <= target: l = mid + 1    # 相等也右移到 mid+1 → 找到"第一个 >t"边界
        else:                r = mid
    return (l - 1) if l - 1 >= 0 and a[l-1] == target else -1

# lower_bound: 第一个 >= target（即插入位置，LeetCode 35）
def lower_bound(a, target):
    l, r = 0, len(a)
    while l < r:
        mid = (l + r) // 2
        if a[mid] < target: l = mid + 1     # 同 find_first，但返回值不校验命中
        else:              r = mid
    return l   # 若全部 < target，则 l == len(a)，正是"插到末尾"
★

核心要点：所有"第一个/最后一个"变体，都是把普通二分里"相等就返回"改成"相等继续收"，方向由你选。比较符号里是 < 还是 <=，决定了结果是"第一个"还是"最后一个"。LeetCode 34（起止）、35（插入位置）直接把这三个模板考遍。

!

易错点：求"最后一个等于"时，很多同学直接 return r 或 return mid，但循环结束时 l==r，正确候选是 l-1（因为最后一次右移后 l 指向的是"第一个 > target"）。务必结合你选的不变量推导返回值，用一张表在白板上推一遍。

时间
O(log n)
空间
O(1)
应用
LC 34 / 35

知识点二分答案（对结果二分 + 可行性判定）bs-answer · LeetCode 410

前面的二分都是在数组下标上做；二分答案（Binary Search on Answer）是另一种更强的思维：直接在"答案的取值上"二分。当我们要找"满足条件的最大/最小值"，而答案的可行性随取值呈现单调性时，就可以每次猜一个值 mid，写一个 check(mid) 判断"这个值可行吗"，从而把"求最优"变成"判定 + 二分"。

单调性是什么？例如"把数组分成 k 段，使每段和的最大值最小"。设上限为 X，段数随 X 增大只会变少（段可用更长的片段装下），所以"能否用 ≤k 段、每段和 ≤X 装完"对 X 是单调的：X 越大越容易，X 越小越难。我们就能二分 X，找"能装完的最小 X"。

bs_answer.py
# 通用骨架 + 一个实例（LeetCode 410：分割数组的最大值）
def split_array(nums, k):
    # check(x)：是否能用 <=k 段，使每段和 <= x（贪心从左往右尽量多取）
    def check(x):
        cnt, cur = 1, 0
        for v in nums:
            if cur + v > x:        # 当前段装不下，另起一段
                cnt += 1
                cur = v
            else:
                cur += v
        return cnt <= k

    lo, hi = max(nums), sum(nums)   # 答案区间：[单个元素最大值, 总和]
    while lo < hi:                  # 找满足 check 的最小 x（左闭右开，lo
★

核心要点：二分答案的三板斧——① 确定答案的取值范围 [lo, hi]；② 证明 check(x) 关于 x 单调；③ 按"求最小可行值"用 hi=mid，按"求最大可行值"用 lo=mid（后者要配合上取整 lo+(hi-lo+1)//2 防死循环）。单调性永远是第一优先级，没有单调就别二分答案。

⚠

注意复杂度：总时间 = O(log(值域跨度) × check 的代价)。check 可能是 O(n) 甚至 O(n log n)，所以别只看到"二分"就以为是 O(log n)。这类题（木头切割、跳石头、乌龟阵、LC 1011/410）是"贪心判定 + 二分答案"的黄金组合。

时间
O(log R × O(check))
空间
O(1)
适用
单调性判定

知识点常见错误与死循环排查bs-pitfalls · off-by-one 与 l=mid

二分写错通常不是"思路不对"，而是几个典型陷阱。把它们背下来，就能在面试里把 bug 当场消灭在纸上。

  • 区间不变量前后矛盾：开头声明左闭右闭，中间却用了左闭右开的收缩，结果栈溢出或越界。
  • mid 取法错误：(l+r)//2 在极端 int 下溢出；应写 l+(r-l)//2。
  • 死循环：最常见是「下取整 mid 配 l = mid」。当 l 与 r 相邻（l==r-1）且走向 l=mid 时，mid==l，区间不缩小，死循环。
  • 返回值错误：求"第一个/最后一个"时，到底返回 l 还是 r，忘掉"此时 l==r"去验证。
  • 边界遗忘：空数组、单元素、target 比所有元素小/大、重复元素全等…… 都要能跑通。
bs_pitfalls.py
# ✘ 死循环写法：mid 下取整却配 l = mid
# 当 l=0,r=1 时，mid=0，a[0]
!

易错点（死循环铁律）：只要用了 下取整 的 mid，就不要写 l = mid，否则 l 与 r 相邻时不动，死循环。要写 l = mid 就必须改上取整 mid = l + (r-l+1)//2。这条规律能救回大半二分 bug。

★

排查技巧：哪都不确定时，直接在循环里把 (l, r, mid, a[mid]) 打印出来，重点观察 l 与 r 相邻（r-l==1）那一步 mid 是否等于 l 或 r。二分手工推演时，永远把"剩余区间"画标尺。

时间
O(log n)
空间
O(1)
常见
off-by-one

知识点二分扩展：三分查找、牛顿法、平方根bs-ext · 选学

二分只适合单调（单调递增或递减）问题。若函数先增后减或先减后增（单峰），二分就失效了，这时可以用三分查找（Ternary Search）每次缩掉区间的 1/3，等价于 O(log3/2 n)。另外求函数零点或平方根还可借助牛顿法（Newton's Method，二次收敛）。

bs_ext.py
# 1) 二分求整数平方根：最大 x 使 x*x <= a（是"二分答案"的典型例子）
def my_sqrt(a):
    lo, hi = 0, a
    while lo < hi:
        mid = lo + (hi - lo + 1) // 2   # 上取整，求"最大可行" 
        if mid * mid <= a:  lo = mid
        else:              hi = mid - 1
    return lo

# 2) 牛顿法求平方根（非整数、二次收敛）
def sqrt_newton(a):
    x = a
    while abs(x*x - a) > 1e-7:
        x = (x + a/x) / 2      # 迭代公式 x_{n+1} = (x + a/x)/2
    return x

# 3) 三分查找：求单峰函数（先增后减）在 [lo, hi] 上的最大值
def ternary_search(f, lo, hi):
    while hi - lo > 1e-7:
        m1 = lo + (hi - lo) / 3
        m2 = hi - (hi - lo) / 3
        if f(m1) < f(m2):  lo = m1    # 峰值在右侧
        else:              hi = m2
    return (lo + hi) / 2
⚠

适用限制：三分只对严格单峰有效（平台段、多峰会失效）；牛顿法不保证一定收敛（对初值和函数性质敏感），且有除法、浮点误差。这三者是"选学/加分项"，面试常问的是它们的适用场景与优缺点，而不是默写实现。

三分 O(log n)
牛顿法

O(log a)
