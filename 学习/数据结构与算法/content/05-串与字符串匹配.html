05串的存储与朴素匹配
（串的基本概念 → 逐字符比对）

知识点串的基本概念与存储str-basic · 基础

串（String）是由零个或多个字符组成的有限序列，记作 S = 'a₁a₂…aₙ'。它和数组、链表一样是基础线性结构，但操作对象是「字符」，且绝大多数实用场景下我们要做的是查找子串、比较与变换，而不是插入删除，因此它衍生出一套独立的算法体系（匹配、哈希、回文等）。

  • 串长：串中字符的个数；空串串长为 0；空格串只含空格字符（串长不为 0，容易与空串混淆）。
  • 子串（substring）：串中任意连续字符组成的子序列；主串是包含子串的原始串。
  • 子串位置：子串在主串中第一次出现时，子串首字符在主串中的下标（有的教材从 1 开始，代码里从 0 开始）。
  • 模式匹配（pattern matching）：在主串中查找一个子串（又称模式串 pattern）的所有 / 首次出现位置，是本模块的核心问题。
string_basics.py
# 串的存储：Python 的 str 是「不可变」的连续数组，内部按 Unicode 编码存放
s = "数据结构"          # 串（String），len = 4
n = len(s)              # 串长：4
sub = s[1:3]            # 子串 substring（切片 [1,3)：取下标 1,2）→ "据结"
pos = s.find("据")      # 子串首次出现位置：1；找不到返回 -1
print(s[0], sub, pos)   # 数 据结 1

# 三种常见存储结构（理解即可，代码角度不太需要手写）：
# 1) 定长顺序存储：固定长度数组，超长会截断，适合长度已知的场合
# 2) 堆分配存储：动态申请内存（C 的 malloc / C++ 的 string），长度可变 —— 最常用
# 3) 块链存储：以「块」为结点的链表，适合频繁插入删除，但定位第 i 个字符是 O(n)
⚠

易错点：空串（""，长度为 0）≠ 空格串（" "，长度为 1）；子串是连续的一段，「子序列」不要求连续，两者别混。做题时注意题目说的下标是从 0 还是从 1 开始。

★

核心要点：串是「以字符为元素的线性表」，但它的主要操作是求子串 / 匹配，所以复杂度分析要围绕「比较了多少次字符」来展开。

知识点朴素匹配算法str-naive · 基础

朴素匹配（Brute-Force / Naive）是最直观的思路：从主串的每个位置 i 出发，与模式串逐字符比较；一旦失配，主串指针回退到 i+1，模式串指针回到 0，重新开始。实现极简单，但最坏情况下会做 O(n·m) 次字符比较。

  • 适合模式串很短、或主串与模式串匹配容易成功的场景；在大多数随机文本上平均接近 O(n+m)。
  • 它的「笨」在于失配后信息被浪费：已经比过的字符没被利用，主串指针也不断回退。
  • 它是理解 KMP 的跳板——KMP 正是解决了「失配后怎么少比较」的问题。
naive_match.py
def naive_contains(text, pat):
    """朴素模式匹配：在主串 text 中找模式串 pat，返回首次出现下标，找不到返回 -1"""
    n, m = len(text), len(pat)
    if m == 0:
        return 0                    # 空模式串视为出现在最前面
    for i in range(n - m + 1):      # 枚举主串中的候选起点（最多 n-m+1 个）
        j = 0
        while j < m and text[i + j] == pat[j]:   # 逐字符比对直到失配或模式匹配完
            j += 1
        if j == m:                  # 模式串全部匹配成功
            return i
    return -1

print(naive_contains("abababaca", "ababaca"))   # 输出 2
print(naive_contains("hello", "xyz"))           # 输出 -1
✕

最坏情形（必考）：当主串与模式串高度相似时，如 text="aaaa…a"、pat="aaa…ab"，每次都要比到模式的最后一个字符才失配，总共约 n·m 次比较，故最坏O(n·m)。别误写成 O(n)。

★

核心要点：朴素匹配的代价来自「每次失配后主串指针回退 i+1、模式指针归零」。若能让模式串「聪明地滑动」而不是从头再来，就能把复杂度降到线性——这就是下一节 KMP 的动机。

最坏时间
O(n·m)
平均时间
O(n+m)
空间
O(1)

05KMP 算法与字符串哈希
（线性匹配 → 概率性匹配）

重点KMP 算法与 next（前缀函数）数组str-kmp · 高频考点

KMP 算法（Knuth–Morris–Pratt，1977）把朴素匹配的"每次从头再来"优化为"按已匹配信息滑动"。核心是：失配时主串指针不回退，只把模式串向右滑动到「已经匹配好的最长相等真前缀」之后——靠提前算好的 next（也叫前缀函数 prefix function，记为 π）数组来指导回退。

next 的定义（前缀函数）：π[i] = p[0..i] 的最长相等真前缀（不等于整串本身）的长度。它刻画了「模式串失配处的前缀里，有多长一部分和串的开头相同」。下面以 p = "ababaca" 手工推导：

下标 i字符前缀 p[0..i]最长相等真前缀next[i]
0aa—（无真前缀）0
1bab—0
2aabaa1
3bababab2
4aababaaba3
5cababac—0
6aababacaa1

如何求 next：用递推。设求到 i 时当前最长真前缀长度为 k。若 p[i]==p[k]，则 k+1；否则回退到 k = next[k-1]（次长的真前缀）继续尝试，直到 k=0 或匹配成功。这一步就是"用已经算好的 next 往回找"。

kmp.py
def get_next(p):
    """前缀函数：next[i] = p[0..i] 的最长相等真前缀长度（kmp_next）"""
    m = len(p)
    nxt = [0] * m
    k = 0                        # 已匹配的最长真前缀长度
    for i in range(1, m):
        while k > 0 and p[i] != p[k]:
            k = nxt[k - 1]       # 失配：顺着 next 回退到次长真前缀
        if p[i] == p[k]:
            k += 1
        nxt[i] = k
    return nxt

def kmp_search(text, pat):
    """返回 pat 在 text 中首次出现的下标；找不到返回 -1"""
    n, m = len(text), len(pat)
    if m == 0:
        return 0
    nxt = get_next(pat)
    j = 0                        # 模式串当前已匹配长度
    for i in range(n):           # 主串指针只前进，绝不回退
        while j > 0 and text[i] != pat[j]:
            j = nxt[j - 1]       # 失配回溯：跳过不可能的可能
        if text[i] == pat[j]:
            j += 1
        if j == m:               # 匹配成功
            return i - m + 1
    return -1

pat = "ababaca"
print("next 数组:", get_next(pat))                       # [0, 0, 1, 2, 3, 0, 1]
print("匹配位置:", kmp_search("abababaca", pat))        # 2

用 "ababaca" 在 "abababaca" 里走一遍匹配：先比 text[0..4]=ababa 与模式第 0..4 位全部相等，主串指针到 i=5；此时 text[5]=b、pat[5]=c 失配，按 j=next[4]=3 回退（把模式串右滑 2 格），从 pat[3]=b 继续比对；text[5]=b 正好匹配，之后 text[6..8]=aca 与 pat[4..6] 全部相等，最终命中下标 2。整个过程主串只扫了一遍。

✕

易错点：① 有的教材把 next 定义成 next[0]=-1（严蔚敏《数据结构》那种"失配时 j 移到 next[j]"的约定），与本文"前缀函数 next[i] 记长度、失配时 j 移到 next[j-1]"的写法不同，考试要先看清题目用的是哪种约定。② 回退是 j = nxt[j-1]（不是 nxt[j]），下标别写错。③ 求 next 是用 模式串自身匹配自身，与主串无关。

★

核心要点：KMP 的两条"不回退"——主串指针绝不回退，模式串的回退由 next 精确指导。由于每个字符最多被比较两次（匹配顺利时 +1，失败时被 next 跳过），总复杂度 O(n+m)。对应 LeetCode 28「找出字符串中第一个匹配项的下标」。

预处理
O(m)
匹配
O(n)
总时间
O(n+m)
空间
O(m)

知识点KMP 的应用与变体str-kmpapp · 进阶

KMP 不止能找"首次出现"。只要在匹配成功后不回零、而是按 next 回退继续，就能不重扫主串地找到所有出现位置（含重叠）；此外，前缀函数还能揭示字符串的周期性，用于判断/求出最小循环节。

  • 所有出现位置：匹配成功（j == m）后记录起点，再令 j = nxt[m-1] 继续，即可捕捉重叠出现。
  • 最小循环节（period）：对串 s，令 unit = n - π[n-1]。若 n % unit == 0，则 s[:unit] 就是最小重复单元；否则 s 不是某个单位串的完全重复。
  • 字符串周期性（KMP 的著名应用）：正是利用"最长相等真前缀"与"剩余部分是循环节长度"的关系。
kmp_apps.py
def get_next(p):
    m = len(p); nxt = [0] * m; k = 0
    for i in range(1, m):
        while k > 0 and p[i] != p[k]:
            k = nxt[k - 1]
        if p[i] == p[k]:
            k += 1
        nxt[i] = k
    return nxt

def kmp_all(text, pat):
    """找出所有出现位置（含重叠）"""
    n, m = len(text), len(pat)
    if m == 0:
        return list(range(n + 1))
    nxt, j, res = get_next(pat), 0, []
    for i in range(n):
        while j > 0 and text[i] != pat[j]:
            j = nxt[j - 1]
        if text[i] == pat[j]:
            j += 1
        if j == m:
            res.append(i - m + 1)   # 记录起点
            j = nxt[m - 1]          # 关键：回溯到最长真前缀，继续找（可重叠）
    return res

def min_period(s):
    """若 s 可由某单位串重复构成，返回最小循环节；否则返回 None"""
    n = len(s)
    nxt = get_next(s)
    unit = n - nxt[n - 1]
    return s[:unit] if n % unit == 0 else None

print(kmp_all("abababaca", "ababaca"))   # [2]
print(kmp_all("aaaaa", "aa"))            # [0, 1, 2, 3]（重叠出现全部找到）
print(min_period("ababab"))              # ab
print(min_period("ababaca"))             # None（无法完全重复）
★

对应题目：KMP 求最小循环节 → LeetCode 459「重复的子字符串」（n % (n - π[n-1]) == 0）；找所有出现位置 → 常出现在面试手写题。记住公式：unit = n - π[n-1]，且必须满足 n % unit == 0。

⚠

易错点：「循环节」公式必须判整除；否则像 "ababcababcx" 这种即使 π 很大也不算循环串。找所有位置时成功后要 j = nxt[m-1] 而不是清零，否则会漏掉重叠出现。

找所有出现
O(n+m)
判循环节
O(m)
空间
O(m)

知识点字符串哈希（滚动哈希 / 双哈希）str-hash · 概率性算法

字符串哈希把字符串看成一个大整数再取模，从而把"比较两个串是否相等"变成"比较两个数是否相等"。最常用的是多项式哈希（滚动哈希，Rabin–Karp 思想）：令 hash(s) = Σ ord(s[i])·BASE^i mod MOD。预处理前缀哈希后，任意子串 s[l..r) 的哈希可在 O(1) 内得到，配合双哈希可显著降低碰撞。

  • 前缀哈希：h[i] = s[0..i-1] 的哈希值；h[i+1] = (h[i]·BASE + ord(s[i])) % MOD。
  • 子串哈希：hash(l,r) = (h[r] − h[l]·BASE^(r−l)) % MOD（是 O(1) 的关键）。
  • BASE 的选取：常用 131 / 13331（比字符集大即可，经典经验值），MOD 用大质数如 10^9+7 / 10^9+9。
  • 双哈希：用两个不同 (BASE, MOD)，两个哈希都相等才认为相等，把碰撞概率压到约 1/MOD²。
string_hash.py
BASE = 131
MOD = 10**9 + 7

def build_prefix(s):
    """h[i] = s[0..i-1] 的哈希；pw[i] = BASE^i"""
    h = [0] * (len(s) + 1)
    pw = [1] * (len(s) + 1)
    for i, ch in enumerate(s):
        h[i + 1] = (h[i] * BASE + ord(ch)) % MOD
        pw[i + 1] = (pw[i] * BASE) % MOD
    return h, pw

def sub_hash(h, pw, l, r):
    """子串 s[l..r) 的哈希值，O(1)"""
    return (h[r] - h[l] * pw[r - l]) % MOD

s = "abababaca"
h, pw = build_prefix(s)
# 比较 "abab" 与 "abac" 是否相等：比较区间哈希即可
print(sub_hash(h, pw, 0, 4) == sub_hash(h, pw, 2, 6))   # "abab" vs "abab" -> True

# 双哈希：用两套 (BASE, MOD)，都相等才判定相等，碰撞率 ≈ 1/MOD^2
BASE2, MOD2 = 13331, 10**9 + 9
h2, pw2 = build_prefix(s)   # 用同样的 build_prefix 换个模数即可
equal = (sub_hash(h, pw, 0, 4) == sub_hash(h, pw, 2, 6)
         and sub_hash(h2, pw2, 0, 4) == sub_hash(h2, pw2, 2, 6))
✕

易错点：① 取模后可能出现哈希碰撞（两串不同但哈希值相同），单哈希不能保证判等，严谨做法是双哈希或直接比对。② (h[r] − h[l]·pw[r−l]) 减法后要加 MOD 再取模，避免负数。③ 子串哈希是"末尾对齐"的，区间必须写成 [l, r) 半开半闭。

★

核心要点：多项式哈希的本质是「把串看作 BASE 进制整数」。一旦能 O(1) 求任意子串哈希，判断回文、比较子串、滑动窗口匹配等都能大幅提速。Rabin-Karp 就靠它把平均匹配降到 O(n+m)。物化此类题：LeetCode 187「重复的 DNA 序列」、LeetCode 1044「最长重复子串」。

预处理
O(n)
子串哈希
O(1)
空间
O(n)
风险
碰撞（双哈希可缓解）

知识点常用字符串处理技巧str-tips · 综合

面试里字符串题往往不是"纯匹配"，而是各种技巧的组合。掌握下面几类范式，很多题就能秒拼出来：

  • 双指针 / 左右指针：比对称性、去空格、原地反转常用。
  • 中心扩展（中心扩散）：求最长回文子串，枚举每个（奇/偶）中心向两边扩展，O(n²)，好写且必考。
  • 哈希计数（Counter）：判断变位词（anagram）、统计字符频次（LeetCode 242、49）。
  • 滑动窗口 + 计数：求"包含某字符集的最短子串"等（LeetCode 76）。
  • KMP / 哈希思想移植：模式匹配类、重复模式、公共前后缀都能用前面两节的方法。
  • 反转 + 处理：先整体反转、再逐段反转，是很多"反转"题的套路。
string_tips.py
# 1) 中心扩展求最长回文子串（LeetCode 5）
def longest_palindrome(s):
    n = len(s)
    best = ""
    for c in range(n):
        for l, r in ((c, c), (c, c + 1)):        # 奇数中心 / 偶数中心
            while l >= 0 and r < n and s[l] == s[r]:
                l -= 1; r += 1
            if r - l - 1 > len(best):
                best = s[l + 1:r]
    return best
print(longest_palindrome("babad"))   # "bab" 或 "aba"

# 2) 变位词判断：排序 vs 计数（LeetCode 242）
from collections import Counter
def is_anagram(a, b):
    return Counter(a) == Counter(b)   # 若长度不同，先判断再计数
print(is_anagram("anagram", "nagaram"))   # True
⚠

易错点：回文要同时考虑奇数长度和偶数长度两个中心（只写一个会漏掉 "abba" 这类偶数回文）；用 Counter 判变位词前先比对长度，能省一次统计；切片和 s[0] 访问在 Python 里是 O(1)（C 层优化），但每次拼接字符串应尽量用列表 + "".join()。

★

核心要点：拿到字符串题先想三件事——要不要用哈希（判等/计数）、能不能用双指针/滑动窗口（区间性质）、是否涉及模式匹配或重复结构（用 KMP/哈希）。多想一层，往往就从暴力升级成面试官想要的解法。
