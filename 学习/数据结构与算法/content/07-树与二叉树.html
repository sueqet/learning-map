01概念基础
树与二叉树的定义、术语与存储

知识点树的定义与基本术语树 · tree

树（Tree）是 n（n≥0）个结点的有限集合。当 n=0 时称为空树；当 n>0 时，有且仅有一个根结点（root），其余结点可划分为 m（m≥0）个互不相交的有限集合，每个集合本身又是一棵树，称为根的子树（subtree）。这是著名的递归定义：树由若干子树构成，子树又是更小的树。树的引入让我们能从"一对多"的角度组织数据（如文件系统、HTML DOM、组织架构）。

  • 结点度（degree）：该结点拥有的子树个数；一棵树中所有结点度的最大值称为树的度。
  • 叶子结点（leaf）：度为 0 的结点；内部/分支结点：度不为 0 的结点。
  • 父结点 / 子结点 / 兄弟结点（siblings）：直接相邻的上层为父、下层为子、同一父下的为兄弟。
  • 祖先 / 后代：从根到该结点的路径上的结点为其祖先；它之下的结点为其后代。
  • 层次（level）：根为第 1 层，向下逐层加 1。深度（depth） 指根到结点的层次数（结点深度）；高度（height） 指该结点到最远叶子的路径长度（树的高度等于根结点的高度）。注意：深度自顶向下数，高度自底向上数。
tree_terms.py
# 用嵌套字典（或对象）抽象一棵树，复习术语：以"文件系统"为例
tree = {
    "name": "root/",                # 根结点，第 1 层
    "children": [
        {"name": "docs/", "children": [      # 子结点，第 2 层
            {"name": "readme.md", "children": []},   # 叶子结点：度 = 0
            {"name": "notes.md",  "children": []},
        ]},
        {"name": "src/",  "children": [
            {"name": "main.py",  "children": []},
        ]},
        {"name": "LICENSE", "children": []},  # 叶子结点
    ],
}

def degree(node):                       # 结点的度 = 子树个数
    return len(node["children"])

def node_depth(node, depth=1):          # 深度：自上而下计数（根为 1）
    print(node["name"], "深度 =", depth)
    for c in node["children"]:
        node_depth(c, depth + 1)

def tree_max_depth(node):               # 树的高度：自下而上
    if not node["children"]:
        return 1
    return 1 + max(tree_max_depth(c) for c in node["children"])

print("树的度 =", max(degree(node) for node in [tree]))

# 关键二分：深度=根到结点的层数；高度=结点到最远叶子的层数。
# 树的高度 == 根结点的高度 == 最大深度（若根深度记 1）。
★

核心要点：树是递归定义的非线性结构，n 个结点的树有 n-1 条边；"深度自上而下、高度自下而上"是高频概念辨析点。亲子、兄弟、子树关系的判断都围绕"唯一路径"展开——树中任意两结点间只有一条路径。

⚠

易混点：树与图不同——树无环且连通（n 个结点恰 n-1 条边）；一棵树去掉根就是若干"互不相交"的子树，这是递归定义成立的前提。考试常见陷阱："度为 2 的树"与"二叉树"不是一回事——前者不要求孩子有序，后者严格要求左右子树有次序。

O(n)

O(h)

知识点二叉树的性质与存储结构binary tree

二叉树（Binary Tree）是一种特殊的树：每个结点至多有两棵子树（左子树、右子树），且左右子树有次序，不能颠倒。正因为"至多两个分支"，二叉树成为算法/面试中最主要的树形结构，也是堆、BST、AVL、哈夫曼树等的基础。

性质内容
性质 1第 i 层至多有 2^(i-1) 个结点（i≥1）。
性质 2深度为 k 的二叉树至多有 2^k - 1 个结点（k≥1）。
性质 3对任意二叉树：叶子数 n0 = 度为2的结点数 n2 + 1，即 n0 = n2 + 1。
性质 4完全二叉树（编号从 1 开始）结点 i 的父为 i/2 取整，左孩子 2i，右孩子 2i+1（越界则不存在）。

特殊形态：满二叉树（full/perfect）——每一层都满，即深度 k 时恰有 2^k-1 个结点；完全二叉树（complete）——除最后一层外都满，最后一层从左到右连续。满二叉树一定是完全二叉树，反之不一定。

存储结构两种：

  • 顺序存储（数组）：按"层序"编号存入数组，下标 i 与孩子关系用性质 4 计算。适合完全二叉树（无空洞）；对一般二叉树会浪费大量空位。
  • 链式存储（二叉链表）：每个结点含"数据域 + 左孩子指针 + 右孩子指针"，n 个结点的二叉链表总共有 n+1 个空指针（2n 个指针域、n-1 条边）。最常用。
binary_tree.py
# 二叉链表结点的两种写法：类式（Python 常用）

    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left      # 左孩子（可为 None）
        self.right = right    # 右孩子（可为 None）

#         1
#       /   \
#      2     3
#     / \     \
#    4   5     6
root = TreeNode(1, TreeNode(2, TreeNode(4), TreeNode(5)), TreeNode(3, None, TreeNode(6)))

# 完全二叉树的数组下标关系（数组从下标 1 开始存根）
# arr[i] 的孩子： arr[2i]、arr[2i+1]
# 求 n0 与 n2 的经典考题：设总结点数为 n，则 n = n0 + n1 + n2，且 n0 = n2 + 1
def leaf_vs_deg2(n0, n1):        # 给出 n0、n1 可直接推 n2 = n0 - 1
    n2 = n0 - 1
    return n0 + n1 + n2           # 总节点数

print("n= ", leaf_vs_deg2(4, 2))  # 4 个叶子、2 个一度结点 -> 总 4+2+3=9 个结点

# 解题技巧：同时给出"总结点数 + 叶子数/度"能唯一确定一棵树的部分形态；
# 但"知道前序+中序"才能唯一重建整棵树（见后文 tree-apply）。
!

易错点：① n0 = n2 + 1 中的 n2 是度为 2 的结点数，不是"有两个孩子的内部结点"与"所有内部结点"的混淆；② 顺序存储只对完全二叉树高效，普通二叉树用数组会产生大量空洞；③ 二叉链表 n 个结点共 2n 个指针域，其中空指针 n+1 个（常考填空）。

★

核心要点：二叉树是"每个结点至多两叉、左右有序"的树。抓住 n0 = n2 + 1、完全二叉树的 2i / 2i+1 下标关系，以及"顺序存储适合完全二叉树、链式存储为通用方案"三条线即可应对绝大多数概念题。

02遍历与应用
四种遍历算法与它的经典应用

知识点二叉树的遍历（前/中/后序：递归+迭代；层序）traversal

遍历（Traversal）指按某种规则访问树中每个结点且只访问一次，是树与二叉树最核心的考点，也是后面所有树算法的基础。二叉树遍历分三大类：深度优先（DFS）的前/中/后序遍历，与广度优先（BFS）的层序遍历。三者区别只在"根结点何时被访问"：

遍历访问顺序记忆口诀
前序遍历根 → 左 → 右根左右（先访问根）
中序遍历左 → 根 → 右左根右（根在中间）
后序遍历左 → 右 → 根左右根（最后访问根）
层序遍历按层，从左到右用队列逐层访问

递归版（简洁、易读，是面试首选写法）：

traverse_recursive.py
# 递归版：三种 DFS
def preorder(root, res):          # 前序：根左右
    if not root: return
    res.append(root.val)
    preorder(root.left, res)
    preorder(root.right, res)

def inorder(root, res):           # 中序：左根右
    if not root: return
    inorder(root.left, res)
    res.append(root.val)
    inorder(root.right, res)

def postorder(root, res):         # 后序：左右根
    if not root: return
    postorder(root.left, res)
    postorder(root.right, res)
    res.append(root.val)

# 对上面那棵树 root：前序 1 2 4 5 3 6；中序 4 2 5 1 3 6；后序 4 5 2 6 3 1
# 注意中序的"根"在中间——这正是之后重建/验证 BST 的关键线索。

迭代版（用栈模拟递归栈，考察动手能力，重点记"何时入栈/出栈"）：

traverse_iterative.py
# 迭代版：显式用栈
def preorder_iter(root):          # 前序：先压右、再压左，弹出即访问
    res, stack = [], [root] if root else []
    while stack:
        node = stack.pop()
        res.append(node.val)
        if node.right: stack.append(node.right)   # 先右后左，保证先访问左
        if node.left:  stack.append(node.left)
    return res

def inorder_iter(root):           # 中序：一路向左入栈，出栈时访问&转向右
    res, stack, cur = [], [], root
    while stack or cur:
        while cur:
            stack.append(cur)
            cur = cur.left        # 不断压入左子树，走到最左
        node = stack.pop()        # 弹出即访问
        res.append(node.val)
        cur = node.right          # 转向右子树，继续"一路向左"
    return res

def postorder_iter(root):         # 后序：可由"前序对称"得到（根右左 再 反转）
    res, stack = [], [root] if root else []
    while stack:                  # 根右左 顺序
        node = stack.pop()
        res.append(node.val)
        if node.left:  stack.append(node.left)
        if node.right: stack.append(node.right)
    return res[::-1]              # 反转 -> 左右根

# 双栈法(更标准)：s1 压根->左右；s2 记访问顺序。上面"反转法"更简洁，面试可讲两种。

层序遍历（BFS）：用队列，先入根，循环取出队头并让左右孩子入队；如需按层分组，可在每层开始时记录当前队列长度。

level_order.py
from collections import deque

def level_order(root):            # 层序：BFS + 队列（关键辅助结构）
    if not root: return []
    res, q = [], deque([root])
    while q:
        n = len(q)               # 当前层的结点个数（用于按层分组）
        level = []
        for _ in range(n):
            node = q.popleft()
            level.append(node.val)
            if node.left:  q.append(node.left)   # 左孩子先进
            if node.right: q.append(node.right)  # 右孩子后进
        res.append(level)        # res 形如 [[1],[2,3],[4,5,6]]
    return res

# 例题：求最大宽度、自底向上层序、锯齿形层序（LeetCode 102 / 103 / 107）
# 技巧：锯齿(zigzag)只需在偶数层 reverse 一下 level。
★

核心要点：前/中/后序遍历用栈，层序用队列。递归版：根的位置决定遍历类型；迭代版：前序"先压右、再压左"，中序"一路向左压栈、弹出访问后转向右"，后序"根右左再反转"或双栈。时间复杂度都是 O(n)，每个结点恰好访问一次。

!

易错点：① 迭代中序忘写 cur = node.right，会死循环或丢右子树；② 前序压栈顺序写反会得到"根右左"；③ 层序若不先记录当前层长度 n，就无法把结果按层分组；④ 只有知道两种序（且其中一种为中序）才能唯一重建一棵树。

时间
O(n)
空间（递归）
O(h)
空间（迭代/层序）
O(n)
适用
所有树题基础

知识点遍历的应用（重建二叉树、求深度、序列化/反序列化）application

掌握了遍历，就能解决大量经典面试题。这一节聚焦三处必杀技：① 由中序 + 前序/后序重建二叉树；② 求树的深度/高度；③ 序列化（serialize）与反序列化（deserialize）。它们都离不开"递归分解子问题"的思想。

① 由中序 + 前序/后序重建二叉树

重建原理：前序（或后序）的第一个（或最后一个）结点必是根；在中序序列中找到根的位置，根左侧就是左子树的中序、右侧就是右子树的中序；再根据长度切出对应的前序/后序子段，递归建左右子树。这是 LeetCode 105 / 106 的考点。

build_tree.py
def build_from_pre_in(pre, ino):
    """由前序+中序重建二叉树（LeetCode 105）"""
    if not pre: return None
    root_val = pre[0]                     # 前序第一个 = 根
    root = TreeNode(root_val)
    idx = ino.index(root_val)             # 根在中序中的位置
    root.left  = build_from_pre_in(pre[1:1+idx], ino[:idx])       # 左子树
    root.right = build_from_pre_in(pre[1+idx:], ino[idx+1:])      # 右子树
    return root

# 由后序+中序同理：根 = post[-1]（后序最后一个），再递归左右。
def build_from_post_in(post, ino):
    if not post: return None
    root_val = post[-1]                   # 后序最后一个 = 根
    root = TreeNode(root_val)
    idx = ino.index(root_val)
    root.left  = build_from_post_in(post[:idx], ino[:idx])
    root.right = build_from_post_in(post[idx:-1], ino[idx+1:])
    return root

# 关键前提：必须知道"中序"，因为只有中序能区分左右子树！
# 仅知道"前序+后序"无法唯一重建树（无法确定单子树的左右归属）。

② 求深度/高度

depth.py
def max_depth(root):              # 最大深度（LeetCode 104）
    if not root: return 0
    return 1 + max(max_depth(root.left), max_depth(root.right))

def min_depth(root):              # 最小深度：注意"空孩子不上数"（LeetCode 111）
    if not root: return 0
    if not root.left:  return 1 + min_depth(root.right)   # 只有右子树
    if not root.right: return 1 + min_depth(root.left)    # 只有左子树
    return 1 + min(min_depth(root.left), min_depth(root.right))

def node_count(root):             # 求结点数同理
    if not root: return 0
    return 1 + node_count(root.left) + node_count(root.right)

# 易错：求最小深度时，若某结点只有右孩子，不能直接取 min(0, 右深)，
# 否则会错误地"跨过空孩子"把深度算小。

③ 序列化 / 反序列化

serialize.py
def serialize(root):              # 前序序列化，用哨兵标记空结点（LeetCode 297）
    if not root: return ["#"]
    return [str(root.val)] + serialize(root.left) + serialize(root.right)

def deserialize(data):
    it = iter(data)
    def build(it):
        v = next(it)
        if v == "#": return None
        node = TreeNode(int(v))           # 遇到非#，先建根，再递归建左右
        node.left  = build(it)
        node.right = build(it)
        return node
    return build(it)

# 反序列化策略：与序列化一致即可。前序/层序都可以，但"空哨兵"必须显式写入，
# 否则无法区分"该子树结束"与"空孩子"。核心：保证递归分解是确定性的。
★

核心要点：重建树、求深度、序列化本质都是"递归分解为左/右子问题"。记住：中序 + 前序（根在头）或中序 + 后序（根在尾）都可唯一重建，而"前序+后序"不行；规模大时用哈希表把中序"值→下标"缓存，可把每次 index 查找从 O(n) 降到 O(1)。

!

易错点：① 最小深度与最大深度不同——最小深度只在"叶子"结点上取 min，不能用简单的 1+min(...)；② 重建时切分下标写错（idx、idx+1、-1）是最高频 bug；③ 序列化必须显式记录空结点，否则反序列化无法唯一还原。

03有序与平衡
二叉搜索树与AVL平衡树

知识点二叉搜索树（查找/插入/删除）BST · binary search tree

二叉搜索树（Binary Search Tree，BST）要求：对任意结点，其左子树所有结点值 < 根，右子树所有结点值 > 根，且左右子树本身也是 BST。于是BST 的中序遍历必然递增有序——这是判断/验证 BST 与把 BST 转有序序列的钥匙（LeetCode 98 / 230）。

  • 查找：比根小往左、比根大往右，O(h)。
  • 插入：从根出发按大小找空位挂接，O(h)。保证树不破坏有序性。
  • 删除（最复杂，三种情况）：① 叶子——直接删；② 只有一个孩子——用该孩子顶替；③ 有两个孩子——用中序前驱（左子树最大）或中序后继（右子树最小）替换其值，再删掉那个前驱/后继（最多只有单孩子）。
bst.py
class BST:
    def __init__(self, val=None):
        self.val = val; self.left = None; self.right = None

def search(node, x):              # 查找（LeetCode 700）
    while node:
        if x == node.val: return node
        node = node.left if x < node.val else node.right
    return None

def insert(node, x):              # 插入（LeetCode 701）
    if not node: return BST(x)
    if x < node.val: node.left  = insert(node.left, x)
    else:            node.right = insert(node.right, x)
    return node

def min_node(node):               # 找右子树最小值（后继）
    while node and node.left: node = node.left
    return node

def delete(node, x):              # 删除（LeetCode 450）
    if not node: return None
    if x < node.val:
        node.left  = delete(node.left, x)
    elif x > node.val:
        node.right = delete(node.right, x)
    else:                         # 找到要删的结点 x
        if not node.left:  return node.right   # 只右孩子 / 叶子
        if not node.right: return node.left    # 只左孩子
        succ = min_node(node.right)            # 两个孩子：取右子树最小
        node.val = succ.val                    # 用它替换值
        node.right = delete(node.right, succ.val)  # 递归删除后继
    return node

# 删除两个孩子的关键：用"前驱/后继替换"保持有序性，再把"被替换的那个点"删掉。
# 中序遍历结果：前驱 = 左子树最大者，后继 = 右子树最小者。
⚠

易错点：① BST 的查找/插入/删除只在平衡时才是 O(log n)；若按有序序列插入（如 1,2,3,...），BST 会退化成"斜树"，退化为 O(n)。所以才有下面的 AVL。② 验证一棵树是否为 BST 不能只比较"孩子与父"，而要比较"整棵左子树的最大值/右子树的最小值"，最简单可靠法是中序遍历是否严格递增。

★

核心要点：BST 的关键特性是"中序 = 有序"，由此衍生"第 k 小元素、验证 BST、把有序数组转平衡 BST（LeetCode 108）"等经典题。删除两个孩子的结点用前驱/后继值替换，再删那个单节点——务必理解"替换而非直接断链"。

知识点平衡二叉树 AVL（旋转）AVL tree

AVL 树是严密的"自平衡二叉搜索树"：任一结点的平衡因子（balance factor） = 左子树高度 − 右子树高度，取值恒为 -1 / 0 / +1。一旦某结点插入后 |bf|>1 即失衡，需要旋转恢复平衡，保证树高 O(log n)，从而查找/插入/删除都稳定在 O(log n)。

旋转共四类，按"失衡结点到新结点"的路径方向命名：

失衡类型形态（失衡方向）旋转操作
LLNode <- left <- left右旋（单旋）失衡结点右旋，新根为原左孩子
RRNode <- right <- right左旋（单旋）失衡结点左旋，新根为原右孩子
LRNode <- left <- right先左旋后右旋（双旋）先对左孩子左旋，再对失衡结点右旋
RLNode <- right <- left先右旋后左旋（双旋）先对右孩子右旋，再对失衡结点左旋
avl_rotate.py
def height(n): return n.height if n else 0

def get_bf(n):                    # 平衡因子 = 左高 - 右高
    return height(n.left) - height(n.right) if n else 0

# 右旋：LL 失衡修复。失衡结点 y，其左孩子 x 成为新根。
#      y                 x
#     / \               / \
#    x   T3    ==>    T1   y
#   / \                   / \
#  T1  T2               T2  T3
def rotate_right(y):
    x = y.left
    y.left = x.right      # T2 挂到 y 的左
    x.right = y           # y 变为 x 的右
    y.height = 1 + max(height(y.left), height(y.right))
    x.height = 1 + max(height(x.left), height(x.right))
    return x

# 左旋：RR 失衡修复。与右旋完全对称。
def rotate_left(x):
    y = x.right
    x.right = y.left      # T2 挂到 x 的右
    y.left = x            # x 变为 y 的左
    x.height = 1 + max(height(x.left), height(x.right))
    y.height = 1 + max(height(y.left), height(y.right))
    return y

# 插入后统一做一次平衡检查（返回新的子树根）
def balance(node):
    bf = get_bf(node)
    if bf > 1:            # 左子树过高
        if get_bf(node.left) < 0:           # 左孩子的右侧 -> LR 双旋
            node.left = rotate_left(node.left)
        return rotate_right(node)           # LL（含 LR 处理后的）右旋
    if bf < -1:           # 右子树过高
        if get_bf(node.right) > 0:          # 右孩子的左侧 -> RL 双旋
            node.right = rotate_right(node.right)
        return rotate_left(node)            # RR（含 RL 处理后的）左旋
    return node

# 判断技巧：失衡结点沿"新插入点"方向看——同侧(左左/右右)用单旋，
# 不同侧(左右/右左)用双旋。本质是让插入点"弯"上来成为中间层的根。
★

核心要点：判断旋转类型看失衡结点到新插入结点的相对方向——"同侧单旋、异侧双旋"。右旋处理 LL，左旋处理 RR；LR = 先左旋后右旋，RL = 先右旋后左旋。旋转后中序遍历顺序不变（仍是 BST），只调整树形让高度更平衡。

!

易错点：① 平衡因子的定义方向各教材可能相反（左高—右高 或 右高—左高），判"是否失衡"时 |bf|>1 即可，但旋转方向别记反；② LR/RL 是双旋，别只旋一次；③ 子树旋转后必须更新高度；④ AVL 的删除同样可能失衡，需从被删结点向上回溯平衡（常被忽略）。

O(log n)

O(log n)

O(log n)

O(n)

04带权树与编码
哈夫曼树与最优前缀编码

知识点哈夫曼树与哈夫曼编码Huffman tree · 最优二叉树

哈夫曼树（Huffman Tree）又称最优二叉树：给定 n 个权值（如字符出现频率）作为叶子结点，构造一棵二叉树，使带权路径长度（Weighted Path Length，WPL）最小。WPL = Σ (叶子权值 × 该叶子到根的路径长度)。它是数据压缩（如 ZIP、JPEG 常用）的基础。

构造算法（贪心）：每次从当前集合中取出权值最小的两个结点，合并成一个新结点（权值为二者之和），放回集合，重复直到只剩一个结点——它就是哈夫曼树的根。直观理解：权值越大的字符离根越近、编码越短，整体 WPL 才最小。

huffman.py
import heapq

class HNode:
    def __init__(self, val, left=None, right=None, ch=None):
        self.val = val; self.left = left; self.right = right; self.ch = ch
    def __lt__(self, o):              # 让堆按权值排队
        return self.val < o.val

def huffman(freq):
    """freq: {'a':5,'b':9,'c':12,'d':13,'e':16,'f':45} 之类（权值表）"""
    heap = [HNode(w, ch=c) for c, w in freq.items()]
    heapq.heapify(heap)
    while len(heap) > 1:
        a = heapq.heappop(heap)       # 每次取两个最小
        b = heapq.heappop(heap)
        heapq.heappush(heap, HNode(a.val + b.val, a, b))   # 合并成新结点
    root = heap[0]

    def code_map(node, code, d):      # 左 0 右 1，得到各字符编码（前缀码）
        if node.ch is not None:       # 叶子 -> 记录编码
            d[node.ch] = code; return
        code_map(node.left,  code + "0", d)
        code_map(node.right, code + "1", d)
        return d

    return root, code_map(root, "", {})

root, codes = huffman({'a':5,'b':9,'c':12,'d':13,'e':16,'f':45})
print(codes)
# 特点：任意字符的编码都不是另一个编码的前缀 -> 前缀编码(prefix code)，可无歧义解码。

# 直观求 WPL：每次合并产生的"和"累加起来 = 带权路径长度。
# 例 权值{5,9,12,13,16,45}：5+9=14, 12+13=25, 14+16=30, 25+30=55, 45+55=100
# WPL = 14+25+30+55+100 = 224（等价于 Σ 非叶结点权值，也等价于 Σ叶子权值×深度）。
# 递归求 WPL 也可写成：对叶子返回权值×深度，否则递归累加左右子树。
★

核心要点：构造哈夫曼树用贪心 + 最小堆，每次合并两个最小权值。结论：① 权值越大越靠近根，编码越短；② n 个叶子结点的哈夫曼树共 2n-1 个结点，且没有度为 1 的结点（全是叶子或度=2）；③ 所得编码是最优前缀码，一个编码不可能是另一个的前缀，因此解码无歧义。

!

易错点：① WPL 定义是"Σ 叶子权值 × 深度"，但手工计算常用"每层合并权值累加"的便捷法；② 合并时若遇到相同权值，顺序并不唯一，但不同的合并顺序可能得到不同的哈夫曼树形状，只要每次取最小两个，WPL 一定唯一且最小；③ 编码约定"左 0 右 1"或"左 1 右 0"都会改变结果，但都是前缀码且总长度相同。
