MODULE 08 · 数据结构与算法

堆与优先队列

堆（Heap）是一棵用数组承载的完全二叉树，它以近乎 O(log n) 的代价「随时取出最值」，是优先队列（Priority Queue）的经典实现，也是堆排序、TopK、第 K 大等高频面试题的地基。

✓本节学习目标

  • 学完后你能说出堆的「完全二叉树 + 父≤/≥子」两个性质，并在 0 下标数组上推演出左右孩子的下标公式。
  • 学完后你能手写 上浮（bubble up） 与 下沉（bubble down），并解释插入与「删除堆顶」为何都是 O(log n)。
  • 学完后你能区分自顶向下建堆（O(n log n)） 与 自底向上建堆（O(n)），说清后者线性时间的直觉。
  • 学完后你能用堆实现堆排序，并能在「求 TopK / 第 K 大」时正确选择大顶堆还是小顶堆并给出理由。
  • 学完后你能用 Python heapq / C++ priority_queue 的默认行为与改造方式，解决合并 K 个有序链表、数据流中位数等实际问题。
Pre-requisites · 前置知识

前置知识：会一门编程语言（示例用 Python，可联想到 C++）；理解「二叉树 / 完全二叉树」的节点与层级概念（见模块 07 树与二叉树）；熟悉数组下标；了解基本复杂度记号 O(·) 与对数的含义；最好见过「二叉树数组存储」的 2 倍下标映射。

知识点 1堆的定义与性质完全二叉树下标 · 大顶堆/小顶堆

定义：堆（Heap）在逻辑上是一棵完全二叉树（Complete Binary Tree）——除最后一层外每层填满，且最后一层节点靠左紧凑排列；在物理上用一维数组存储，因此无需指针即可在上层与孩子、兄弟间跳转。它满足「堆序性」：任一节点的值都不小于（或不大于）其孩子节点的值。若父 ≥ 子，称大顶堆 / 大根堆（Max-Heap），堆顶是全局最大；若父 ≤ 子，称小顶堆 / 小根堆（Min-Heap），堆顶是全局最小。

思想：堆只承诺「根是最值」，并不保证整棵树有序——这是堆与排序树（如二叉搜索树 BST）最本质的区别。正因为约束这么弱，堆才能用极低的代价维护「随时取最值」这一能力，成为优先队列的默认实现。

关键下标公式（0 下标）：设当前节点下标为 i，则

  • 左孩子：left = 2*i + 1
  • 右孩子：right = 2*i + 2
  • 父节点：parent = (i - 1) // 2

完全二叉树保证了堆是「平衡」的，高度为 ⌊log₂n⌋，于是任何沿树根到叶子的一条路径至多 O(log n)——这正是上浮/下沉对数复杂度的来源。

heap_props.py
# 用数组模拟一棵【小顶堆】，展示下标映射与堆序性
#         1            <- 下标 0，堆顶(最小)
#       /   \
#      3     2         <- 下标 1, 2
#     / \   / \
#    5   4 6           <- 下标 3,4,5
a = [1, 3, 2, 5, 4, 6]

# 下标映射：任意节点 i 的父、左、右
def parent(i):  return (i - 1) // 2
def left(i):    return 2 * i + 1
def right(i):   return 2 * i + 2

for i in range(len(a)):
    # 校验堆序性：父节点 <= 左右孩子（小顶堆）
    for c in (left(i), right(i)):
        if c < len(a):
            assert a[i] <= a[c], f"违反小顶堆性质: {a[i]} > {a[c]}"
print("这是一棵合法的小顶堆，堆顶 =", a[0])   # 堆顶 = 1

# 大顶堆只需把比较方向换成 a[i] >= a[c]
比较维度大顶堆（Max-Heap）小顶堆（Min-Heap）
堆序性父 ≥ 子父 ≤ 子
堆顶含义全局最大，取「最大」快全局最小，取「最小」快
用途堆排序、取第 K 小/最大优先队列、TopK 最大、Dijkstra
★

核心要点：堆 = 完全二叉树（数组承载） + 堆序性（只约束父子、不约束兄弟）。堆顶永远是最值，但堆不是有序序列——「取最值」是它的看家本领，这也解释了为何它的操作都能守住 O(log n)。

!

易错点：① 把「堆」和「二叉搜索树（BST）」混为一谈——BST 满足 左 < 根 < 右，堆只满足父子大小关系，因此 堆不能用中序遍历得到有序序列。② 下标公式记错：若用下标 0 起，孩子是 2i+1, 2i+2；若用 1 起，则是 2i, 2i+1。Python list 与大多数实现默认 0 下标，务必一致。

知识点 2插入、删除与建堆上浮 bubble up · 下沉 bubble down · 自底向上建堆

核心操作。堆只有两个「维持堆序」的原地调整动作：

  • 上浮（Sift-Up / Bubble-Up，也叫堆化升序）：新元素先放到数组末尾（即树的最后一个叶子），然后反复与父节点比较，若不满足堆序就交换，一路向上直到根或满足为止。
  • 下沉（Sift-Down / Bubble-Down）：某个节点违反堆序时，与「更合适的那个孩子」交换并逐层下移——注意大顶堆换到较大孩子、小顶堆换到较小孩子，因为要保证交换后堆序重新成立。

插入：末尾追加 → 上浮。删除堆顶：把最后一个元素移到堆顶（覆盖被删的根），再把堆大小减一，最后对根执行一次下沉。用末尾元素补根是「删除堆顶」的最关键手法——它保证了堆仍是完全二叉树，且只需一条路径的调整。

建堆：已有 n 个乱序元素，要建成一个堆。

  • 自顶向下（Top-Down）：逐个 insert，每个 O(log n)，共 O(n log n)。
  • 自底向上（Bottom-Up）：从下标 n//2 - 1 的最后一个非叶节点开始，倒序对每个节点做下沉，直到根。总代价 O(n)——因为越靠近根节点越少，而它们的下沉代价也越大，求和后正好是线性（可用 Σ n/2^(h+1) · O(h) = O(n) 证明）。
heap_ops.py
# 手写一个小顶堆(min-heap)，演示上浮、下沉、插入、删除堆顶、建堆
class MinHeap:
    def __init__(self, arr=None):
        self.a = arr if arr is not None else []
        if arr: self.build(arr)        # 若传入数组就自底向上建堆

    def _push_up(self, i):            # 上浮：新元素放末尾后向上调整
        while i > 0:
            p = (i - 1) // 2
            if self.a[p] <= self.a[i]:
                break
            self.a[p], self.a[i] = self.a[i], self.a[p]
            i = p

    def _push_down(self, i, size):    # 下沉：向下调整到 size 范围
        while True:
            l, r = 2*i+1, 2*i+2
            small = i
            if l < size and self.a[l] < self.a[small]: small = l
            if r < size and self.a[r] < self.a[small]: small = r
            if small == i: break       # 已是合法堆序
            self.a[i], self.a[small] = self.a[small], self.a[i]
            i = small

    def push(self, x):                 # 插入：加末尾 + 上浮
        self.a.append(x)
        self._push_up(len(self.a)-1)

    def pop(self):                     # 删除堆顶：末尾补根 + 下沉
        if not self.a: return None
        top = self.a[0]
        self.a[0] = self.a[-1]
        self.a.pop()
        if self.a: self._push_down(0, len(self.a))
        return top

    def build(self, arr):              # 自底向上建堆 O(n)：从最后一个非叶节点开始下沉
        n = len(arr)
        for i in range(n//2 - 1, -1, -1):
            self._push_down(i, n)

h = MinHeap()
for x in [5, 3, 8, 1, 9]: h.push(x)          # O(n log n) 逐个插入
print(h.a)                                   # 任一合法小顶堆，堆顶为 1

h2 = MinHeap([5, 3, 8, 1, 9])                # O(n) 自底向上建堆
print([h2.pop() for _ in range(len(h2.a))])  # 依次弹出：升序 1 3 5 8 9
★

核心要点：插入 = 末尾 + 上浮；删除堆顶 = 末尾元素移到根 + 下沉；二者都是 O(log n)。下标 n//2-1 是最后一个非叶节点，从这里倒序下沉即是 O(n) 的自底向上建堆。

⚑

易错点：① 删除堆顶时千万别直接删根让树出现空洞——必须「末尾补根」，这样才维持完全二叉树形态。② 下沉时要选择「正确的那一个孩子」（大顶堆挑大的、小顶堆挑小的），否则交换后仍可能违反堆序。③ 自底向上建堆是 O(n) 而不是 O(n log n)，这是面试常被追问的「为什么」。

知识点 3堆排序与 TopK / 第 K 大heapsort 稳定 O(n log n) · 大顶堆 vs 小顶堆

堆排序（Heap Sort）：先用自底向上法把数组建成大顶堆，然后反复「把堆顶（当前最大）与末尾交换，再让有效堆缩小 1 并对根下沉」，最后数组便从后往前有序。核心是「每次取最大放后面，剩下的继续维持大顶堆」，做到原地、稳定 O(n log n)、空间 O(1)。

TopK / 第 K 大：这是堆最经典的面试应用，关键在选对大顶堆还是小顶堆。求最大的 K 个 / 第 K 大，维护一个大小为 K 的小顶堆：堆顶是「当前 K 个中的最小」，凡是比堆顶大的新元素就替换进来并下沉，最终堆顶就是第 K 大，堆里就是前 K 大。反之，求最小的 K 个用大顶堆。

  • 时间：每个元素至多触发一次堆操作 O(log K)，总体 O(n log K)（数据流式且 K 固定时优于排序的 O(n log n)）。
  • 空间：O(K)。这正是 LeetCode 215 第 K 大、347 前 K 个高频元素的核心。
topk.py
import heapq

# ---------- 例1：堆排序（原地） ----------
def heap_sort(a):
    n = len(a)
    # 自底向上建大顶堆（父 >= 子）
    def sift_down(i, size):
        while True:
            l, r = 2*i+1, 2*i+2
            big = i
            if l < size and a[l] > a[big]: big = l
            if r < size and a[r] > a[big]: big = r
            if big == i: break
            a[i], a[big] = a[big], a[i]
            i = big
    for i in range(n//2 - 1, -1, -1):
        sift_down(i, n)
    for end in range(n-1, 0, -1):   # 堆顶(最大)放到末尾，堆缩小，再下沉
        a[0], a[end] = a[end], a[0]
        sift_down(0, end)
    return a

print(heap_sort([9, 4, 2, 7, 1, 8]))         # [1, 2, 4, 7, 8, 9]

# ---------- 例2：求第 K 大 / 前 K 大（LeetCode 215） ----------
def find_kth_largest(nums, k):
    # 小顶堆，只保留最大的 K 个；堆顶即第 K 大
    heap = []
    for x in nums:
        heapq.heappush(heap, x)
        if len(heap) > k:               # 超过 K 个就踢掉最小的
            heapq.heappop(heap)
    return heap[0]

nums = [3, 2, 1, 5, 6, 4]
print(find_kth_largest(nums, 2))        # 5
print(find_kth_largest(nums, 1))        # 6

最大 K 个 / 第 K 大小顶堆K堆顶 = 第 K 大
最小 K 个 / 第 K 小大顶堆K堆顶 = 第 K 小
全部元素排序大顶堆 + 逐步缩小n升序序列
!

易错点：求「最大 K 个」用小顶堆、求「最小 K 个」用大顶堆——很多同学记反。判断口诀：「我要保留的『更优』的那一端去当堆顶。」因堆顶会最先被抛弃，必须让它守住「我最不想要的那一个」，才能把更优的留在堆里。别只顾「大」字就写大顶堆。

知识点 4优先队列的实现与标准库使用Priority Queue 抽象 · heapq / priority_queue

优先队列（Priority Queue）是一个抽象数据类型（ADT，Abstract Data Type），它对外只承诺「插入一个带优先级的元素、取出优先级最高/最低的元素」，而堆是它最常用、最高效的具体实现。二者是「接口」与「实现」的关系：优先队列强调语义，堆强调数据组织。

  • Python heapq：默认是小顶堆。常用：heappush / heappop / heapify(list) 自底向上建堆 / heapreplace（弹出并压入，一步完成）/ nlargest(k, iterable) / nsmallest(k, iterable) / merge(*iterables) 合并多个有序流。
  • heapq 大顶堆技巧：堆不自带大顶堆，常用「存相反数」或「包一层取负的 (-key, value)」实现；对自定义对象可封装 __lt__ 或用 (key, idx) 兜底比较。
  • C++ priority_queue<T>：默认大顶堆（取出最大值）。要小顶堆需传 std::greater<T>：priority_queue<int, vector<int>, greater<int>> pq;。
pq_stdlib.py
import heapq

# --- 小顶堆（Python 原生） ---
pq = []
heapq.heappush(pq, 5); heapq.heappush(pq, 1); heapq.heappush(pq, 3)
print(heapq.heappop(pq))        # 1 —— 永远取最小
print(pq)                       # 剩余: [3, 5]

# --- 大顶堆：存相反数或元组取负 ---
maxp = []
for x in [5, 1, 3]:
    heapq.heappush(maxp, -x)    # 存入 -x，堆顶是"最小的 -x"即最大的 x
print(-heapq.heappop(maxp))     # 5 —— 取最大

# --- heapify: O(n) 原地建堆，无序列表直接变堆 ---
arr = [7, 2, 9, 1, 4]
heapq.heapify(arr)              # 自底向上建堆
print(arr[0])                   # 堆顶最小

# --- nlargest / nsmallest / merge 快捷接口 ---
print(heapq.nlargest(2, [4, 1, 9, 7]))   # [9, 7]  前 2 大
print(heapq.nsmallest(2, [4, 1, 9, 7]))  # [1, 4]  前 2 小
print(list(heapq.merge([1, 3, 5], [2, 4, 6])))  # 合并两个有序序列
★

核心要点：「优先队列」是接口、「堆」是实现。用标准库时记牢Python heapq 默认小顶堆、C++ priority_queue 默认大顶堆——两者方向相反，且 heapq 没有内建大顶堆，需用取负 trick；heapify 即自底向上 O(n) 建堆。

⚑

易错点：① heapq 建大顶堆别写错方向，最容易把「-x」忘记取负。② nlargest/nsmallest 内部就是堆/选择算法，处理大 K 时要留意；若 K 与 n 同阶，直接用排序更简单。③ 优先队列能在 Dijkstra / Prim / A* 中作「待扩展节点的最小堆」，是图算法（模块 09）的常客，别只当排序工具。

知识点 5对顶堆（动态中位数）与可并堆（选学）two heaps · 左偏树/斐波那契堆

对顶堆（Two Heaps，双堆法）：用两个堆把数据流劈成两半，实时维护「中位数」：左半用大顶堆（存较小的那半，堆顶为左半最大），右半用小顶堆（存较大的那半，堆顶为右半最小）。保持「左堆大小 ≥ 右堆大小，且最多差 1」，则中位数就是「左堆顶（奇数时取左）或左右堆顶平均（偶数时取两个堆顶均值）」。每次插入约 O(log n)，取中位数 O(1)。这是 LeetCode 295「数据流的中位数」的标准解。

可并堆（Mergeable Heap / 可合并堆）：普通堆合并两个堆需要重新建堆，代价高；可并堆支持快速「合并两堆」。代表有：

  • 左偏树（Leftist Tree / 左倾堆）：基于「右路径更短」的偏序合并，单次合并 O(log n)。
  • 斜堆（Skew Heap）：左偏树的无条件变体，摊还 O(log n)。
  • 斐波那契堆（Fibonacci Heap）：摊还插入 O(1)、减小键 O(1)，用于优化 Dijkstra。

思想：对顶堆是「两个堆配合，就能在流式数据上追踪分位数/顺序统计量」的代表；可并堆则是「把堆推广到支持合并」的进阶结构，笔试面试中更多作为加分知识出现。

median_stream.py
import heapq

class MedianFinder:
    """对顶堆：实时求中位数。LeetCode 295。"""
    def __init__(self):
        self.hi = []                   # 小顶堆：存较大的右半
        self.lo = []                   # 大顶堆：存较小的左半(用 -x)

    def addNum(self, x):
        # 先放入小顶堆，再平衡：保证 lo 存较小的一半且大小不小于 hi
        heapq.heappush(self.lo, -x)            # 临时进左堆
        heapq.heappush(self.hi, -heapq.heappop(self.lo))  # 把左堆最大转给右堆
        if len(self.hi) > len(self.lo):        # 右堆偏大则还一个给左堆
            heapq.heappush(self.lo, -heapq.heappop(self.hi))

    def findMedian(self):
        if len(self.lo) > len(self.hi):
            return -self.lo[0]                  # 奇数：左堆顶即中位数
        return (-self.lo[0] + self.hi[0]) / 2   # 偶数：两颗堆顶均值

mf = MedianFinder()
for x in [1, 2, 3, 4, 5]:
    mf.addNum(x)
    print(mf.findMedian())   # 1.0 1.5 2.0 2.5 3.0
★

核心要点：对顶堆的妙处在「两个堆各自守一半 + 大小只差 ≤1」，使有序结构一直落在两堆交界，从而 O(1) 取中位数、O(log n) 插入。它也是「滑动窗口中的中位数」「动态分位数」问题的通用模板。

!

易错点：① 对顶堆一定要「先取左堆最大的给右堆、再把右堆多余的还给左堆」这类平衡步骤写对，否则左堆可能存进了更大的数，中位数就错了。② 左堆用取负实现大顶堆，取出时别忘了 -。③ 可并堆是选学加分项，理解「合并」动机即可，不需现场手写左偏树。

知识点 6堆应用实战合并K个有序链表 · 前K高频 · 第K大

模式：凡遇到「在源源不断/海量数据里找最值、找 TopK、按优先级调度、合并多个有序序列、求第 K 个」，第一反应就应是堆（优先队列）。它把每次「挑一个」的代价从线性降到对数，整体复杂度从 O(n·m) 降到 O(n·log m)。

实战代表：

  • LeetCode 23 合并 K 个有序链表：把 K 个链表的头节点放进小顶堆（按节点值），每次弹出最小节点，同时把它的下一个节点压入，如此循环直到堆空。复杂度 O(N·log K)（N 为总节点数），优于两两合并的 O(N·K)。
  • LeetCode 347 前 K 个高频元素：先用 Counter 统计频次，再用大小为 K 的小顶堆按频次淘汰低频者。
  • LeetCode 703 数据流中的第 K 大：维护一个大小为 K 的小顶堆，堆顶即第 K 大；每次插入新元素做一次 push + 超限 pop。
merge_lists.py
import heapq

# LeetCode 23：合并 K 个升序链表（用小顶堆，堆里放 (值, 链表, 节点)）
def mergeKLists(lists):
    # 用 (node.val, idx, node) 三元组，idx 兜底避免比较链表对象
    heap = []
    for idx, node in enumerate(lists):
        if node:
            heapq.heappush(heap, (node.val, idx, node))

    dummy = cur = ListNode(0)
    while heap:
        val, idx, node = heapq.heappop(heap)
        cur.next = node
        cur = cur.next
        if node.next:                                  # 该链的下一个也入堆
            heapq.heappush(heap, (node.next.val, idx, node.next))
    return dummy.next

# 每个节点入堆/出堆各一次：共 N 次操作，每次 O(log K)
# 时间复杂度 O(N·log K)，空间 O(K)（只存 K 个链表头）

# 同类思想：LeetCode 378 有序矩阵第 K 小、LeetCode 632 最小区间
★

核心要点：堆解决「多个有序序列的融合」「流式 TopK」「动态第 K 大」三类问题。核心手法是「每次只取当前最优，取完把它的『下一个候选』补进来」，让堆始终维护 K 个（或有限个）候选者，从而把反复排序/扫描降为对数级挑选。

⚑

易错点：① 堆里放自定义对象（如链表节点）时，Python 无法直接比较，务必用 (key, idx, obj) 三元组给一个稳定的兜底比较键。② 合并有序序列时是「只放各序列的当前头」，不要一次把所有节点都塞进堆里（否则堆变成 O(N)）。③ 高频问题记得先统计频次，再决定堆的维护策略。
