📖 本学习地图使用说明

  • 点击知识点后面的 “去学习 →” 或知识点标题，会跳到对应的 详解网页（自动定位到该知识点）。
  • 勾选知识点前的方框即可 记录已完成，进度保存在本机浏览器（localStorage），刷新/关闭后不会丢。
  • 详解网页里每个知识点也有自己的 “已学会” 勾选框，和大纲双向同步；页面末尾还有「✎ 考核 · 答题」。
  • 带 🖥 交互演示 标记的模块，详解页里可以直接动手试：改查询看结果、切换 JOIN 看行怎么配、模拟并发看隔离级别等。
  • 熟练标准：能手写出查询、能说清执行顺序与索引是否生效、能讲出性能差异。过不了就回看详解再测一次。

🗂 说明

本文件为 index.html，详细网页统一放在 content/ 目录并按数字编号。想新增知识点，改下面 MODULES 数组并同步新建 content/ 里的详解页即可。

示例全部基于 MySQL 8.0 语法（其他数据库的差异会在页内注明）。练习用数据集统一为「电商场景」：customers / orders / order_items / products / employees，各页数据集一致，学完能连成一条线。
