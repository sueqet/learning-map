01高性价比技能推荐

按「能覆盖多少就业方向」×「学习成本」排序，覆盖越广、成本越低越值得先学

对于还没定方向的同学，先学那些几乎每个方向都用到、且面试必考的底层技能最划算。「数据结构与算法」是所有技术方向面试必考的通用底座（覆盖全部 20 个方向）；Python / SQL / Linux / Git / 网络构成普适的工程基础。下面的列表由网页内所有方向的技能要求实时统计得出。其中Python 工程化、数据结构与算法、Git / 版本协作、Linux 与命令行、SQL / 数据库已配套可交互学习页面，点卡片底部按钮即可打开对应学习地图（Python 页面内含力扣题号与可运行代码；SQL 页面内含可动手的查询练习台与连接/索引/事务演示面板）。

03维护与更新

本页为「数据驱动」单文件，更新时只需要改动数据区，无需改结构

如何更新 DATA

所有内容都集中在页面底部 <script> 里的 DATA 对象中，四块数据：

  1. meta — 页面标题、数据更新时间、声明。
  2. topSkills — 高性价比技能（第 01 区）。加/改一个技能即可，覆盖数自动统计。
  3. categories — 方向大类，用于顶部筛选。
  4. careers — 每个就业方向一条：工作内容、技能、城市+薪资、成长路径。新增方向复制一条结构即可。

保存后在浏览器刷新即可看到效果。建议每 3–6 个月更新一次薪资与热门城市。
